## 1. 프로젝트 개요

- **프로젝트명:** 인생스포
- **서비스 정의:** 990원이라는 초저가로 내 인생의 '부(富)', '귀(貴)'를 확인하는 자미두수 웹 서비스
- **핵심 가치:** "복잡한 인생 상담 필요 없다. 딱 결론만 990원에 확인해라."
- **타겟 유저:** 내 인생이 평범한지, 언제 대박이 터지는지 궁금한 2030 (스낵 컬처 소비층)
- **배포 목표일:** 2026년 1월 18일(일) - PG사 심사에 따라 변동될 수 있음

## 2. User Flow (고객 이동 경로)

`랜딩(정보입력)` -> `로딩(분석 연출)` -> `미리보기(후킹 & 결제유도)` -> `PG 결제(990원)` -> `최종 결과(상세 분석)`

## 3. 상세 기능 명세 및 페이지 기획

### 3.1. 랜딩 페이지 (Input)

- **메인 카피:**
  - "내 인생, 990원이면 스포일러 당할 수 있습니다."
  - "남들은 5만 원 주고 보는 자미두수, 커피 한 잔 값도 안 되는 가격에 확인하세요."
- **입력 폼 (Data Collection):**
  - 이름 / 생년월일 / 태어난 시간(필수, 자미두수는 시간이 생명임을 강조) / 성별 / 양음력
  - _UX 문구:_ "정확한 인생 견적을 위해 태어난 시간을 꼭 입력해주세요."
- **Action:** [내 운명 조회하기] 버튼 클릭 시 -> 로딩 페이지로 이동

### 3.2. 로딩 페이지 (Transition)

- **Duration:** 2.5초 ~ 3초 (너무 빠르면 가짜 같고, 너무 느리면 이탈함)
- **연출:**
  - 문구 롤링: "000님의 명궁 분석 중...", "재물 창고 확인 중...", "숨겨진 재능 스캔 중..."

### 3.3. 미리보기 페이지 (Teaser & Payment) - **핵심 승부처**

- **전략:** 사용자의 성향(명궁)을 먼저 맞혀 신뢰를 주고(Barnum Effect), 가장 중요한 '미래/재물'은 블러 처리하여 결제를 유도.
- **구조:**
  1. **[상단] 명궁(본성) 분석 (무료 공개):**
     - 사용자의 타고난 기질을 한 줄로 요약하여 보여줍니다.
     - _예시:_ "겉은 순한 양, 속은 야망 있는 호랑이! 🐯 남 밑에서 일 못하는 사장님 팔자시네요." (맞다는 느낌을 주어 신뢰도 상승)
  2. **[중단] 핵심 질문 던지기 (Blur 처리):**
     - **Q1. 평생 만질 돈의 그릇은?** -> "당신의 재물 창고에는 💰 **[잠겨있음]** 정도가 들어있습니다."
     - **Q2. 인생 최대의 전성기는?** -> "지금 힘들다면 버티세요. **[잠겨있음]**세 부터 인생 역전이 시작됩니다."
  3. **[하단] 결제 유도 (Floating Bottom Sheet):**
     - ~~가격 표기: ~~30,000원~~ -> **990원** (97% 할인가 강조)~~ - 고민중..
     - 버튼: **[990원에 잠금 해제하고 인생 확인하기]**
     - _심리적 트리거:_ "지금 페이지를 닫으면 이 가격으로 다시 볼 수 없습니다."

### 3.4. 결제 프로세스

- **시스템:** PG사 연동 (일반결제 및 간편결제 지원 필수)
- **상품명:** [자미두수] 인생 스포일러 열람권

### 3.5. 결과 페이지 (Result)

- **구성:** 텍스트 위주, 가독성 극대화 (참고 이미지 스타일 반영).
- **섹션 순서:**
  1. **총평 (한 줄 요약):** 예) "초년엔 고생하나 말년엔 건물주 될 팔자"
  2. **재물운 (상세):** 평생의 재물 흐름, 돈 버는 방식, 주의할 점.
  3. **직업운 (상세):** 적성, 추천 직업군, 리더형인지 참모형인지.
  4. **연애/결혼운 (상세):** 배우자 복, 결혼 시기.
  5. **건강/기타 (간략):** 조심해야 할 신체 부위 등.
- **Viral Point (공유하기):**
  - 하단에 [내 인생 요약 짤 저장하기] 또는 [친구에게 공유하고 복채 대신 받기] 버튼 배치.
  - 공유 시 썸네일: "내 인생 등급은 S급? 990원 자미두수 확인하기"

## 4. 개발 유의사항 (Tech Check)

1. **데이터 매핑:** 입력된 생년월일시를 바탕으로 명반을 도출하는 알고리즘(라이브러리 등)과 결과 텍스트 DB 매핑의 정확성 검증 필요.
2. **반응형 웹:** 모바일 트래픽이 95% 이상일 것이므로 **모바일 뷰(Mobile First)** 기준으로 퍼블리싱

## 5. 마케팅 소구점 (Copywriting Guide)

개발자가 결과 페이지에 넣을 텍스트 톤앤매너 가이드입니다.

- **Bad (딱딱함):** "자미성이 명궁에 있어 리더십이 강합니다."
- **Good (직관적/구어체):** "당신은 타고난 **'황제'**입니다. 남 눈치 안 보고 내 멋대로 해야 성공합니다. 억지로 겸손 떨면 오히려 복 나갑니다!"
