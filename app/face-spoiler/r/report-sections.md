# 관상 리포트 섹션 구조

히어로: 동물상 매칭 (캐릭터 이미지, 동물상 이름, 매칭 근거)
섹션 1: 첫인상 (헤드라인, 설명, 요약, 분위기 태그)
섹션 2: 성향과 매력 (헤드라인, 강점, 숨겨진 면, 태그)
섹션 3: 겉과 속의 괴리율 (괴리율 %, 게이지, 외면/내면 태그, 오해, 반전 매력)
섹션 4: 어울리는 사람 (헤드라인, 설명, 이상형, 공유용 한 줄 문장, 태그)
섹션 5: 조심해야 할 관상 (빌런 외형 특징 3개, 상극 이유, 충돌 장면, 대처법)
섹션 6: 궁합 동물상 (찰떡궁합 동물상 + 이유, 상극 동물상 + 이유)
섹션 7: 관상 관찰 (헤드라인, 부위별 사실 묘사, 특징 태그 8~12개)
섹션 8: 이번 주 작은 행동 (행동 제안 3개 - 제목 + 상세)
섹션 9: 공유 한 줄 (SNS 공유용 문장)
