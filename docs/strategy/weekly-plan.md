# 주간 마케팅 일정

CMO는 이 문서를 읽고 현재 요일과 시간대에 해당하는 업무를 실행합니다.

## 발행 정책

- **일일 발행 상한: 1건/일**. `safety-gate.js`가 강제하며, 초과 시 발행 중단.
- **무조건 하루 1건 발행**을 목표로 한다. 발행 누락 시 다음 슬롯에 즉시 보강.
- 외부 링크/실험은 일반 정책에 따라 자유롭게 운용 (재정지 대응 제한 폐지, 2026-05-10).

## 시간대 정의

| 시간대 | 시간 | 설명 |
|--------|------|------|
| T1 | 06:00~09:00 | 아침 (출근 전 콘텐츠 소비 시간) |
| T2 | 09:00~12:00 | 오전 |
| T3 | 12:00~15:00 | 점심~오후 |
| T4 | 15:00~18:00 | 오후 |
| T5 | 18:00~21:00 | 저녁 (퇴근 후 SNS 피크) |
| T6 | 21:00~24:00 | 밤 (운세 검색 피크 시간대) |

## 발행 시각 jitter 규칙

자동화 시그니처 제거를 위해 **모든 발행은 슬롯 내 랜덤 분(8~52분 사이)** 에 실행합니다. 정각 발행 금지.

- 슬롯 시각이 12:00이면 실제 발행은 12:08~12:52 사이 랜덤
- 매일 다른 분(minute)에 발행 (직전 7일 발행 분 분포 확인)
- jitter 계산은 `safety-gate.js`의 `computeJitterDelaySeconds`가 수행, GitHub Actions가 `sleep`으로 적용

## 주간 슬롯 가이드

매일 1건 발행을 원칙으로, 요일별 추천 슬롯·콘텐츠 유형은 다음과 같다. CMO는 슬롯이 비어있는 경우 자유롭게 보강할 수 있다.

| 요일 | 추천 슬롯 | 콘텐츠 유형 |
|------|----------|-----------|
| 월 | T5 | 공감형 (주간 시작 정서) |
| 화 | T3 | 지식형 (자미두수 미니 교양) |
| 수 | T6 | 질문형 (밤 자기 성찰) |
| 목 | T5 | 스토리형 (구체적 사례) |
| 금 | T3 | 트렌드 반응형 |
| 토 | T6 | 감성형 (주말 밤) |
| 일 | T5 | 공감형 또는 스토리형 |

## 보조 업무 (CMO/성과 분석가)

| 요일 | 시간대 | 에이전트 | 업무 |
|------|--------|---------|------|
| 월 | T1 | CMO | 주간 전략 리뷰, 지난주 성과 확인, 이번 주 우선순위 설정 |
| 수 | T3 | CMO | 중간 점검 — 성과 확인, 필요시 전략 조정 |
| 목 | T6 | 성과 분석가 | 주중 성과 중간 리포트 |
| 금 | T3 | CMO | 이번 주 콘텐츠 성과 리뷰, 다음 주 방향 초안 |
| 일 | T5 | CMO | 주간 전략 수립, 다음 주 weekly-plan 업데이트 |
| 일 | T6 | 성과 분석가 | 주간 종합 리포트 → Discord 주간 요약 발송 |

## 참고사항

- 시간대가 겹치는 에이전트는 동시 실행 가능
- 모든 발행은 jitter 규칙(슬롯 시작 + 8~52분)을 따름
