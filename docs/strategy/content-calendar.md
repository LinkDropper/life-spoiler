# 콘텐츠 캘린더

콘텐츠 라이터와 소셜 미디어 마케터가 참조하는 콘텐츠 기획 문서입니다.

## X 매일 고정: 오늘의 별자리 운세 (아침 8시)

별자리별 운세. 매일 아침 1회 발행.

### 작성 원칙

- **별자리별(12궁)** 운세를 자미두수 관점에서 해석
- 존댓말 사용
- 근거 기반: 당일 천간/지지 흐름이 각 별자리에 미치는 영향을 논리적으로 설명
- 이모지 사용 금지. 깔끔하고 가독성 좋은 텍스트 레이아웃
- "럭키 컬러", "행운의 숫자" 같은 근거 없는 점술 표현 금지
- 마지막에 자연스러운 CTA

### 형식

```
[오늘의 운세] 4월 14일 월요일

양자리 (3/21~4/19)
오늘은 업무에서 새로운 제안이 들어올 수 있습니다. 평소보다 열린 자세가 좋은 결과로 이어집니다.

황소자리 (4/20~5/20)
재정 관련 결정은 하루 미루는 게 현명합니다. 감정적 소비를 조심하세요.

...

전체 별자리 운세와 더 정밀한 자미두수 분석
→ life-spoiler.com

#오늘의운세 #별자리운세 #인생스포
```

### 주의

- 모든 해석에 자미두수 이론적 근거가 있어야 함 (당일 천간이 어떤 성에 영향을 주는지)
- 별자리마다 분량 균등하게
- 지나치게 부정적이거나 지나치게 긍정적인 해석 금지. 균형 있게.

## 블로그 콘텐츠 카테고리

### 1. 자미두수 교양 시리즈

- "자미두수가 뭔데? 사주와 뭐가 다를까"
- "12궁으로 보는 내 인생의 12가지 영역"
- "명반 읽는 법 — 별자리 운세와는 차원이 다르다"
- "자미두수 vs 사주팔자: 정밀도 비교"

### 2. 운세 트렌드 / 시즈널

- 월별 운세 하이라이트 (매월 초)
- 계절별 운세 트렌드
- "2026년 하반기, 대운이 바뀌는 사람들"
- 절기/명절 연계 콘텐츠

### 3. 자기탐구 / 공감

- "내 재물궁이 말해주는 돈과의 관계"
- "연애운이 안 풀리는 진짜 이유 — 명반으로 보면"
- "MBTI로는 모르는 나의 직업 적성"
- "전성기가 30대 후반인 사람들의 공통점"

### 4. 비교/대결 콘텐츠

- "사주 vs 자미두수: 같은 생일, 다른 결과?"
- "점집에서 들은 말 vs 자미두수 분석 결과"
- "MBTI E와 I, 자미두수로 보면?"

### 5. 사용 후기 / 케이스 스터디

- 실제 분석 결과를 익명으로 소개 (동의 필요)
- "이런 명반을 가진 사람은 ~한 경향이 있다"

## X (Twitter) 콘텐츠 유형

**작성 원칙**: 280자를 충분히 활용한다. 추상적 설명이 아니라 구체적 상황을 그려서 "나 얘기인가?" 싶은 느낌을 줘야 한다. 도입부 1~2문장에서 스크롤을 멈추게 할 것.

### A. 질문형 (공감 유도)

```
직장 다니면서도 "이게 진짜 내 길인가?" 싶은 순간, 다들 한 번쯤 있잖아요.

자미두수에서는 관록궁이라는 걸 봅니다. 타고난 일하는 방식이 적힌 궁이에요. 여기에 어떤 별이 앉아있느냐에 따라 조직형인지 독립형인지가 갈리거든요.

재밌는 건, 본인이 "난 프리랜서 체질"이라고 생각해도 명반은 정반대일 때가 꽤 많다는 거예요.

#자미두수 #직업운 #인생스포
```

### B. 지식형 (자미두수 미니 교양)

```
자미두수에는 '탐랑성'이라는 별이 있어요. 욕망과 매력의 별이라고 불리는데, 이 별이 어디에 앉느냐에 따라 완전히 다른 사람이 됩니다.

명궁에 있으면 → 첫인상이 강렬하고 사람을 끌어당기는 타입
재물궁에 있으면 → 돈에 대한 감각이 뛰어나고 투자에 관심이 많은 타입
부부궁에 있으면 → 연애에 올인하는 스타일, 감정의 기복도 큰 타입

같은 별인데 앉는 자리에 따라 성격이 이렇게 달라져요. 이게 자미두수가 사주보다 정밀하다고 하는 이유입니다.

#자미두수 #탐랑성 #인생스포
```

### C. 트렌드 반응형

```
요즘 "MBTI 뭐예요?" 다음으로 많이 듣는 질문이 "사주 본 적 있어요?"래요.

근데 사주보다 한 단계 더 정밀한 게 있다는 거 아시나요? 자미두수라고, 중국 송나라 때 만들어진 건데 MBTI가 16가지, 사주가 51만 가지라면 자미두수는 수십만 가지 조합이에요.

"같은 날 태어났는데 왜 인생이 다르지?"에 대한 답을 줄 수 있는 거의 유일한 체계입니다.

#MBTI #자미두수 #사주 #인생스포
```

### D. CTA형 (유입 유도)

```
사주팔자는 생년월일시 8글자로 봅니다. 경우의 수가 약 51만 가지예요.

자미두수는 같은 생년월일시에 114개 별의 위치와 12개 궁의 조합까지 봅니다. 경우의 수가 수십만 가지를 넘어요.

같은 날 태어났는데 인생이 다른 이유, 자미두수는 설명할 수 있어요. 990원이면 114개 별이 그리는 내 인생 시나리오를 확인할 수 있습니다.

life-spoiler.com

#자미두수 #인생스포 #운세
```

```
나쁜 게 아니에요. 오히려 자기 내면을 잘 들여다보는 사람이라는 뜻이에요.

```

```
"저 원래 회사 다니면서 늘 답답했거든요. 근데 관록궁에 파군성이 있대요. 기존 질서를 부수고 새로 만드는 별이라고. 그래서 조직 생활이 안 맞았던 거구나 싶었어요."

자미두수가 흥미로운 건, "너는 이런 사람이야"가 아니라 "네가 왜 그렇게 느끼는지"를 설명해준다는 거예요.
```
