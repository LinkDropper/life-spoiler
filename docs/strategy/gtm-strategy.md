# GTM (Go-To-Market) 전략

## 목표

**핵심 KPI: 서비스 유입 (트래픽)**

| 지표 | 측정 방법 |
|------|----------|
| 일일 방문자 수 | Analytics |
| X 프로필 → 사이트 클릭 | UTM 추적 |
| 블로그 → 사이트 클릭 | UTM 추적 |
| 공유를 통한 유입 | referral 파라미터 |

## 채널 전략

### 1. X (Twitter) — 주력 채널

**목표**: 트래픽 + 바이럴
**빈도**: 하루 2~3회
**전략**:
- 운세/자미두수 관심층 타겟팅
- 질문형 트윗으로 참여 유도
- 스레드로 자미두수 교양 시리즈
- 밤 10~12시 운세 피크타임 집중

### 2. 블로그 (브런치) — SEO + 교양

**목표**: 검색 유입 + 브랜드 신뢰
**빈도**: 주 2회 (화/목)
**전략**:
- "자미두수"/"사주" 키워드 SEO
- 에세이 톤으로 자기탐구 콘텐츠
- 매 글 하단에 자연스러운 CTA

### 3. 인스타그램 — 비주얼 + 공유

**목표**: 브랜드 인지도 + 공유
**빈도**: 추후 확대 (현재 X 집중)
**전략**:
- 카드뉴스 (자미두수 별 소개, 궁 해설)
- 스토리 투표 ("너의 재물궁 별은?")
- 릴스 (짧은 운세 해설)

### 4. 궁합 공유 — 자연 바이럴

**목표**: 오가닉 유입
**전략**:
- 궁합 결과 공유 시 상대방 자동 유입
- 공유 메시지 최적화 (호기심 유발)
- 카카오톡/LINE 공유 UX 개선

## 퍼널

```
인지 (X/블로그/인스타)
  ↓
호기심 (프로필 클릭 → 사이트 방문)
  ↓
탐색 (랜딩 페이지, 후기 확인)
  ↓
전환 (990원 결제)
  ↓
공유 (궁합 링크 공유 → 새 유저 유입)
  ↓
재방문 (올해운세/관상스포 추가 이용)
```

## 경쟁 대응

### 사주아이 대비 포지셔닝

- "사주 8자 vs 자미두수 114별" — 정밀도 차이를 반복 강조
- "긍정만 말하는 운세 vs 현실적인 인생 시나리오" — 깊이 차별화
- "복냥이" 캐주얼 vs "동양 천문학" 지적 브랜드 — 톤 차별화

### 하지 않을 것

- 경쟁사 직접 비난/비교 광고
- 과장된 적중률 주장
- 유료 광고 (현재 단계에서는 오가닉 집중)
