# 마케팅 자동화 로드맵

인생스포 마케팅 자동화 확장 계획. 현재 X 포스팅 + 메트릭 수집 + 일일/주간 브리핑이 Claude Code 원격 스케줄러(`life-spoiler-cmo`)로 자동화돼 있으며, 다음 단계 후보를 우선순위대로 정리한다.

## 현재 자동화 현황

| 항목 | 주기 | 실행 주체 |
|------|------|----------|
| X 포스트 발행 | 매일 T3/T5/T6 중 weekly-plan 배정 슬롯 | 스케줄러(Claude) |
| 일일 브리핑 Discord 발송 | 매일 09시 KST | 스케줄러(Claude) |
| 중간 메트릭 수집 | 월·목 T6 | 스케줄러(Claude) |
| 주간 리뷰 + 실험 설계 | 일 T6 | 스케줄러(Claude) |

실행 주체는 모두 원격 트리거 내 `claude-sonnet-4-6` 세션이다. 서비스 앱에서 쓰는 Gemini는 자미두수 해석 전용이며 마케팅 파이프라인에는 관여하지 않는다.

## 자동화 우선순위 Top 3

### 1순위. 주간 콘텐츠 피드백 루프 자동화

**목적**: activeUsers 상위 10% 포스트의 공통 패턴을 자동 추출해 `learned-playbook.md`에 전술로 반영. 다음 주 포스트 품질을 구조적으로 끌어올린다. "자동화의 자동화"로 기존 X 포스팅 자동화의 ROI 자체를 상승시킴.

**실행 시점**: 일요일 T6 (기존 주간 리뷰 모드에 단계 추가)

**실행 주체**: 스케줄러 세션의 Claude. 별도 모델 호출 불필요.

**절차**:
1. GA4 Data API로 지난주 utm_campaign별 activeUsers 집계
2. 상위 10% 포스트 식별 → social-tracker.csv에서 해당 트윗 본문 조회
3. Claude가 직접 훅 형식·시간대·CTA·이모지 유무 등 패턴 추출
4. `learned-playbook.md`에 신규 전술 append 또는 기존 전술 강화
5. git commit & push (develop)

**난이도**: 하. 기존 주간 리뷰 모드에 단계 추가, 신규 API·스크립트 불필요.

**예상 효과**: 매주 전술 1~2개 누적 → 4주 후 체감 가능한 포스트 품질 향상, North Star 상승 여력.

---

### 2순위. 브런치 블로그 자동 발행 파이프라인

**목적**: X는 휘발성 유입 채널, 블로그는 SEO 누적 자산. "자미두수 재물궁", "탐랑성 연애운" 같은 롱테일 키워드는 복리로 activeUsers를 끌어올리는 동력이 된다. 현재 전략 문서에 주 2회 브런치 발행 목표가 있으나 social-tracker.csv에 브런치 행이 0건으로, 사실상 미실행 상태.

**실행 시점**: 주 2회 (화·금 T3)

**실행 주체**: 스케줄러 세션의 Claude + Playwright(브런치 세션 자동화).

**절차**:
1. Claude가 weekly-plan.md + content-calendar.md에서 이번 주 블로그 주제 확인
2. Claude가 본문 2,000~3,000자 작성 (자미두수 관점 + 일반 독자용 번역)
3. 대표 이미지 생성 (별도 스크립트 호출 — 이미지 생성은 서비스용 Gemini와 분리된 채널 검토 필요)
4. Playwright로 브런치 세션 재사용해 발행
5. 발행 URL을 social-tracker.csv에 기록 (platform=brunch, status=posted)
6. 글 내 CTA 링크에 UTM 포함 (`utm_source=brunch&utm_medium=blog&utm_campaign={주제}`)

**난이도**: 중상. 브런치 공식 API 없음 → Playwright 세션 쿠키 관리 필요. 본문 작성은 Claude가 직접 수행 가능.

**예상 효과**: 3~6개월 누적 시 검색 유입(organic) 경로 확보. X 알고리즘 의존도 감소.

---

### 3순위. X 리플라이/인용 자동화

**목적**: 신규 포스트만으로는 X 알고리즘 노출이 한계에 걸린다. 자미두수·MBTI·운세·성격 관련 키워드 검색 결과에 존댓말 공감형 리플라이를 투입해 프로필 유입을 선형 확장한다. 운세 버티컬은 "답변받는 경험"이 전환 훅이라 효과가 크다.

**실행 시점**: 매일 T4 (15~18시)

**실행 주체**: 스케줄러 세션의 Claude.

**절차**:
1. X API 검색으로 운세·자미두수·MBTI 키워드 최근 24시간 트윗 조회
2. 필터링: 팔로워 50~10,000 사이, 질문형 트윗, 한국어만
3. Claude가 존댓말 공감형 리플라이 작성 (자미두수 관점 간단 언급 + 프로필 방문 유도)
4. 11개 체크리스트 변형 적용 (브랜드 보이스·금지 표현·존댓말 등)
5. 하루 **5건 상한** (스팸 신고 리스크 관리)
6. 리플라이 대상 URL과 본문을 social-tracker.csv에 type=reply로 기록

**난이도**: 중. X API 검색·필터링 로직 + 리플라이 품질 게이트 필요. 하루 상한 강제는 필수.

**예상 효과**: 프로필 방문 주 50~100건 추가 → 팔로워 전환율 5% 가정 시 주간 신규 팔로워 3~5명 확보.

---

### 4순위. 트렌드 감지 자동화 (네이버 데이터랩 + 자동완성 확장)

**목적**: 일요일 T6 주간 리뷰의 "트렌드 감지" 단계가 지금까지는 근거 없는 추정에 의존했다. 네이버 자동완성으로 시드 키워드를 동적 확장한 뒤 데이터랩 API로 개별 검색량 추이를 실측해 가설 품질을 올린다.

**실행 시점**: 일요일 T6 (기존 주간 리뷰 단계 3)

**실행 주체**: 스케줄러 세션의 Claude + `scripts/marketing/naver-trends.js`

**절차**:
1. 고정 시드 8개(`자미두수/사주/MBTI/연애운/이상형/성격유형/궁합/운세`)에 대해 네이버 자동완성으로 연관 키워드 확장 → 40~50개 풀 구성
2. 각 키워드를 데이터랩 개별 그룹으로 던져 30일 검색량 추이 조회 (배치당 5개, ~10회 API 호출)
3. 최근 7일 평균이 직전 평균 대비 **+20% 이상 AND recent7_avg ≥ 5.0**이면 `rising` (저볼륨 노이즈 필터)
4. `rising` 키워드마다 `hypothesis-backlog.md`에 가설 후보 자동 추가 (status=pending)
5. 스크립트 실패 시 해당 단계 skip

**출력 CSV 컬럼**: `keyword, source, recent7_avg, prev_avg, change_pct, rising, peak_date, peak_ratio`

**난이도**: 중. 자동완성 엔드포인트는 비공식이라 응답 스키마 변경 리스크 있음. 일 API 호출량은 데이터랩 1,000회 한도 대비 주 10회 수준.

**상태**: 2026-04-15 구현 완료 (v2 시드 확장 버전). 첫 정식 실행은 2026-04-19 일 T6.

**한계**:
- 계절성 보정 없음 (예: "신년운세"는 12월마다 자동 +100% → 가짜 rising 위험)
- 단일 소스 (구글 트렌드, 뉴스 키워드, SNS 해시태그 미연동)
- 자동완성은 네이버 종합 인기도 반영이라 타 버티컬 키워드(예: 연예인 이름)가 섞일 수 있음 → `isNoise` 필터로 일부 제거하나 완벽하지 않음

## 제외한 후보

| 후보 | 제외 이유 |
|------|----------|
| 인스타그램/릴스 자동화 | 텍스트 기반 운세 콘텐츠에 포맷 전환 비용 과도 |
| 이메일 뉴스레터 | 구독자 기반 전무 → 선행 인프라부터 필요 |
| 유료 광고 크리에이티브 자동화 | 전환 퍼널 검증 전 투입은 손실 위험 |
| Reddit/커뮤니티 답변 자동화 | 스팸 판정 리스크 높음, 수동 운영 영역 |

## 진행 순서 권장

**1순위 → 2순위 → 3순위** 순. 1순위는 저비용·기존 자동화 ROI 상승 효과라 먼저 깔고, 2순위로 유입 채널 다변화, 3순위는 볼륨 확장 단계.

## 의사결정 대기

각 항목별 착수 여부와 구현 시점은 별도 논의. 본 문서는 전략 우선순위 정리 용도.
