# 유저 후기 기능 기획서 (MVP)

> 2026-04-05 | 최소 기능 — 수집 + DB 저장 + 디스코드 알림

---

## 범위

- 결과 페이지 하단에서 후기(별점 + 텍스트)를 받아 DB에 저장
- 후기 등록 시 디스코드 웹훅으로 알림 전송
- 랜딩 페이지 노출, 모더레이션 UI, 인센티브 등은 **미구현**

---

## 1. 후기 입력 위치

**결과 페이지 하단 인라인 섹션**

```
[운세 결과 본문]
────────────────────
[후기 남기기 섹션]   ← 신규
────────────────────
[공유하기 버튼]
```

### UI 상태

- **기본**: "이 결과가 마음에 드셨나요?" + `후기 남기기` 버튼
- **탭 시**: 별점(1~5) + 텍스트 입력 아코디언 펼침
- **작성 완료**: "소중한 후기 감사합니다!" 메시지
- **이미 작성한 유저**: "이미 후기를 남기셨어요" 표시

---

## 2. 수집 정보

### 유저 입력

| 항목           | 형태      | 제약                                              |
| -------------- | --------- | ------------------------------------------------- |
| **별점**       | 1~5 별 탭 | 필수                                              |
| **후기 텍스트** | textarea  | 10~200자, placeholder: "어떤 점이 인상 깊었나요?" |

### 자동 수집

| 항목      | 출처           |
| --------- | -------------- |
| 운세 타입 | URL 경로       |
| profileId | URL 파라미터   |
| 작성 시각 | 서버 타임스탬프 |

---

## 3. 유저 플로우

```
[운세 결과 페이지 스크롤]
        │
        ▼
[후기 섹션] "이 결과가 마음에 드셨나요?"
        │
        ├─ [후기 남기기] 탭 → 폼 펼침
        │       │
        │       ├ 별점 선택 (1~5)
        │       ├ 텍스트 입력 (10~200자)
        │       │
        │       └─ [제출]
        │            ├ DB 저장
        │            ├ 디스코드 알림 전송
        │            └ 감사 토스트
        │
        └─ (이미 작성) → "이미 후기를 남기셨어요"
```

---

## 4. 데이터 모델

### reviews 테이블

```sql
CREATE TABLE reviews (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  profile_id UUID NOT NULL,
  fortune_type TEXT NOT NULL,
  rating SMALLINT NOT NULL CHECK (rating BETWEEN 1 AND 5),
  content TEXT NOT NULL CHECK (char_length(content) BETWEEN 10 AND 200),
  created_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE(profile_id, fortune_type)
);
```

### API

| Method | Path           | 설명      |
| ------ | -------------- | --------- |
| POST   | `/api/reviews` | 후기 작성 |

## 5. 디스코드 알림

후기 등록 시 디스코드 웹훅으로 전송:

```
⭐⭐⭐⭐⭐ (5점)
운세 타입: 인생운세
내용: "사주보다 훨씬 디테일하고 소름 돋았어요!"
작성 시각: 2026-04-05 16:30
```

---

## 6. 엣지 케이스

| 상황                  | 처리                                    |
| --------------------- | --------------------------------------- |
| 같은 유저가 여러 운세 이용 | 운세 타입별 1개씩 작성 가능 (UNIQUE 제약) |
| 200자 초과            | 실시간 글자 수 카운터 + 입력 차단       |
| 네트워크 오류         | 에러 토스트 + 입력 내용 유지            |
| 더블 탭               | 버튼 즉시 disabled + 서버 UNIQUE 제약   |
| 결제 없이 접근        | API에서 이용 이력 검증, 없으면 403      |
