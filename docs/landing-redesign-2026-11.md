## 설계 원칙과 근거

- **결과로 설득한다 (copywriting: Show over tell, 근거 없는 주장 금지)**: 모든 명반·해석·대운은 실제 엔진 출력이다. 지어낸 결과 문장이 없다.
- **방문자가 직접 만진다 (cro: 마찰 제거, marketing-psychology: IKEA 효과·위험 역전)**: 로그인 전에 자기 명반을 본다. 로그인 후 본편 결제 전에도 예고편이 무료라는 사실을 3곳(장면 4·6·8)에서 말한다.
- **"사주보다 정밀"을 보여준다**: 장면 3에서 시간만 바꿔 명궁이 옮겨가는 걸 직접 보게 한다.
- **대담함은 한 곳에 (frontend-design)**: WebGL은 장면 1·2에만 쓴다. 나머지는 DOM·CSS 3D로 가볍게.
- **CTA 충돌 방지**: 장면 안 CTA가 보이면 하단 고정 CTA가 내려간다.

## 성능·접근성

- `three`는 장면 1이 마운트될 때 동적 import. 화면 밖·탭 숨김 시 렌더 루프 정지.
- 모바일(768px 미만): 별 1,600개, 픽셀 비율 최대 1.5 / PC: 3,200개, 최대 2.
- 인앱 브라우저 주소창 리사이즈로 고정 구간이 튀지 않게 `ScrollTrigger.config({ ignoreMobileResize: true })`.
- WebGL 실패 시 CSS 밤하늘 + DOM 명반으로 대체.
- `prefers-reduced-motion`: 카메라 비행·반짝임·가로 감기·마퀴 정지, 필름·후기는 손으로 넘김.
- 전역 `overflow-x: hidden`이 body를 스크롤 컨테이너로 만들어 sticky를 깨뜨려서, 지원 브라우저에선 `overflow-x: clip`으로 바꿨다(`app/globals.css`).
