# 인생스포 서비스 상세 정보

- 메인: https://life-spoiler.com

- 영어: https://life-spoiler.com/en
- 일본어: https://life-spoiler.com/ja

## 상품 라인업

### 1. 인생운세 (Lifetime Fortune) — 핵심 상품

- **가격**: 990원 (정가 9,900원, 90% 할인 중)
- **입력**: 생년월일 + 출생시간 + 성별
- **분석 항목** (13가지):
  - 인생 스포일러 (타고난 기질 총평)
  - 자미두수 명반 (12궁 분석)
  - 재물운 / 직업운 / 인연운 / 건강운
  - 10년 단위 대운 시나리오 (4~99세)

### 2. 올해운세 (Yearly Fortune) — 인생운세 구매 시 무료

- 월별 운세 흐름 (12개월)
- 좋은 달 / 조심할 달

### 3. 궁합 분석 (Compatibility) — 인생운세 구매 시 무료

- 궁합 점수 (0~100점)
- 8가지 궁합 인사이트
- 4대 카테고리: 소통, 성장, 감정, 위기
- **바이럴 포인트**: 상대방에게 링크 공유 → 상대도 결과 확인 가능

### 4. 관상스포 (Face Spoiler)

- AI 기반 관상 분석
- 사진 1장으로 1분 완성
- 5,000자 이상 디테일 리포트

## 기술 차별점

| 항목 | 일반 사주 앱 | 인생스포 |
|------|------------|---------|
| 기반 이론 | 사주팔자 (천간지지 8자) | 자미두수 (114별 x 12궁) |
| 분석 변수 | ~수백 가지 | ~수십만 가지 조합 |
| 해석 방식 | 템플릿 매칭 | Gemini AI 자연어 해석 |
| 역사 | 약 1,000년 | 약 1,000년 (송나라 기원) |
