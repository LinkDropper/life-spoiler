# 인생스포 브랜드 보이스 가이드

## 톤 정의

**지적인 캐주얼** — 친구처럼 편하지만, 말하는 내용은 깊이가 있다.

### 톤 스펙트럼

```
격식 ←————————●——→ 캐주얼
얕은 ←——●————————→ 깊은
차가운 ←————●———→ 따뜻한
```

## DO & DON'T

### DO (이렇게)

- "자미두수로 보면, 너의 재물궁에 천기성이 앉아있거든. 이게 뭐냐면..."
- "솔직히 올해 하반기는 좀 조심해야 할 수도 있어"
- "114개 별이 만드는 조합은 사람마다 전부 다르다"
- "MBTI가 16가지라면, 자미두수는 수십만 가지"
- "사주 8자로는 보이지 않는 것들이 있다"

### DON'T (이러지 말 것)

- ~~"대박 운세 터졌다!!! 인생역전!!!"~~ → 과장, 자극적
- ~~"뼈 때리는 운세"~~ → 진부하고 저급한 표현
- ~~"충격! 당신의 운명은..."~~ → 낚시성
- ~~"무조건 대길합니다~"~~ → 근거 없는 긍정
- ~~"오늘의 럭키 컬러는 빨강!"~~ → 가벼운 점술 이미지

## 브랜드 용어집

| 공식 용어 | 의미 | 사용 맥락 |
|-----------|------|-----------|
| 스포일러 | 운세 결과 | "인생 스포일러를 확인하세요" |
| 예고편 | 간략한 미리보기 | "먼저 예고편부터 볼래?" |
| 본편 | 전체 상세 분석 | "본편에서 13가지를 분석했어" |
| 시나리오 | 대운/흐름 예측 | "10년 단위 인생 시나리오" |
| 명반 | 자미두수 차트 | "너만의 명반을 펼쳐볼게" |
| 별 | 자미두수의 성(星) | "114개 별이 그리는 운명 지도" |

## 채널별 톤 조정

### 블로그 (브런치)

- 에세이 톤. 자기탐구 + 교양 콘텐츠
- 1인칭 또는 2인칭. "~해본 적 있나요?"
- 2000~3000자 내외

### X (Twitter)

- 짧고 임팩트 있게. 질문형 + 공감형
- 해시태그: #자미두수 #운세 #인생스포 #MBTI
- 140자 이내 핵심 메시지

### 인스타그램

- 비주얼 중심. 카드뉴스/인포그래픽
- 캡션은 친근한 말투 + CTA
- 스토리: 투표/퀴즈 활용

## 레퍼런스 톤

참고할 만한 브랜드 톤:
- **배민** — 캐주얼하지만 센스 있는
- **뉴닉** — 쉽지만 알찬
- **캐릿** — MZ 타겟, 트렌디하면서 정보성
