# 인생스포 포지셔닝

## 한 줄 정의

> 1,000년 동양 점성술 자미두수를 AI로 해석하는 초정밀 운세 서비스

## USP (Unique Selling Proposition)

- **114개 별 x 12궁 조합** — 사주팔자(8자)보다 훨씬 정밀한 분석
- **AI 해석** — Gemini AI가 자미두수 명반을 현대적 언어로 풀어냄
- **990원** — 오프라인 점집(5만원~) 대비 압도적 가성비
- **13가지 분석 리포트** — 인생운세 + 올해운세 + 궁합 올인원

## 타겟 유저

| 속성 | 상세 |
|------|------|
| 연령 | 20-30대 |
| 성별 | 여성 중심 (남성도 유입) |
| 관심사 | MBTI, 운세, 성격 테스트, 자기이해 |
| 행동 | SNS 공유 활발, 가벼운 콘텐츠 소비 선호 |
| 니즈 | "나를 더 알고 싶다", "재미있는 자기탐구" |

## 경쟁 분석

### 사주아이 (saju-kid.com)

| 항목 | 사주아이 | 인생스포 |
|------|---------|---------|
| 기반 | 사주팔자 (8자) | 자미두수 (114별 x 12궁) |
| 가격 | 990원~ | 990원 |
| 사용자 | 150만명 | 성장 중 |
| 브랜드 | "복냥이" 캐릭터, 캐주얼 | "스포일러" 컨셉, 지적+캐주얼 |
| 강점 | 대중성, 낮은 진입장벽, 다양한 상품 | 정밀도, 차별화된 분석 체계 |
| 약점 | 지나치게 긍정적, 깊이 부족 | 인지도 낮음 |

### 인생스포의 차별화 전략

1. **정밀도 강조**: "사주 8자 vs 자미두수 114별" — 숫자로 체감되는 차이
2. **깊이 있는 분석**: 사주아이의 "긍정 위주" 약점을 공략, 현실적이고 구체적인 해석
3. **지적인 브랜드**: 싸구려 점술이 아닌 "동양 천문학 기반 자기탐구" 포지셔닝
4. **바이럴 구조**: 궁합 분석 시 상대방에게 공유 → 자연스러운 신규 유입

## 핵심 메시지

- 메인: "내 전성기, 20대일까 30대일까?"
- 서브: "사주보다 더 정밀한 자미두수. 114개 별이 그리는 당신만의 운명 지도"
- 가격: "점집 한 번 값이면 평생 운세를 본다"
