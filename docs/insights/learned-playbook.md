# 검증된 플레이북

실험 또는 상위 포스트 패턴 분석을 통해 검증된 마케팅 전술 모음. **모든 포스트 작성 시 참조.**

매주 일요일 T6에 신규 채택된 전술이 추가됨.

## 형식

```markdown
### 전술 ID: 한 줄 제목

- 출처: 실험 검증 (exp-YYYYWW-NN) 또는 상위 포스트 패턴 (YYYY-W{주차} 누적)
- 검증일: YYYY-MM-DD
- 효과 크기: activeUsers/post +N% vs 통제군
- 샘플 수: N건 (상위 포스트 패턴 전술일 경우 필수)
- 적용 조건: 어떤 시간대/콘텐츠 유형/주제일 때
- 구체 지침: 작성 시 반드시 지킬 것
- 반증 조건: 언제 이 전술을 폐기할지 (예: 효과 2주 연속 부정적일 때)
```

**출처 구분**:
- **실험 검증**: 사전 가설 + variant 대조로 +20% 이상 확인된 전술. `exp-YYYYWW-NN` 표기.
- **상위 포스트 패턴**: 4주 누적 activeUsers/post 상위 10% 포스트에서 추출된 공통 패턴. 관찰 기반이므로 실험 검증보다 약하지만 초기 데이터 누적용으로 유효.

중복 패턴은 신규 등록 대신 기존 전술의 효과 크기·검증일만 갱신한다.

## 검증된 전술

### P-001: T5 슬롯(18~21시) 우선 발행

- 출처: 상위 포스트 패턴 (2026-W17~W21 누적, daily-x-latest.csv 기반)
- 검증일: 2026-06-14
- 효과 크기: T5 포스트 평균 impressions 71 vs 비T5 43 (+65%, n=4 vs n=16)
- 샘플 수: 20건 (GA4 데이터 부재로 X impressions를 proxy로 사용)
- 적용 조건: 모든 요일, 특히 금요일 T5 효과 강함 (4/17 금 T5: 104imp)
- 구체 지침: weekly-plan.md 슬롯 배정 시 T5를 1순위로. T3/T6는 T5 부재 시 보조. 금요일 T5는 관계형(교우궁/부처궁) 주제 우선.
- 반증 조건: T5 포스트가 4주 연속 impressions 50 미만이면 재검토
- 주의: GA4 activeUsers로 재검증 필요 (현재 GA4 데이터 공백으로 impressions만 사용). PAT 갱신 후 GA4 수집 재개 시 정량 확인 필수.

### P-002: 요일/계절 맥락 도입부

- 출처: 상위 포스트 패턴 (2026-W17~W21 누적)
- 검증일: 2026-06-14
- 효과 크기: 요일/계절 트리거 도입부 포스트 평균 impressions 69 vs 일반 진술형 38 (+82%, n=6)
- 샘플 수: 20건 중 맥락 트리거 6건 식별
- 적용 조건: 금요일("금요일 저녁, 친구에게서..."), 주말 준비("이번 주말, 문을 열고..."), 봄/계절("봄이 오면...") 등 독자 현재 상황을 첫 문장에서 직접 호출
- 구체 지침: 첫 문장은 반드시 독자가 지금 있는 요일·시간·계절·감정 맥락으로 시작. 추상적 설명("자미두수에서...") 도입부 지양.
- 반증 조건: 4주 연속 맥락 트리거 포스트 impressions 비-맥락 포스트 평균 미만이면 폐기
