# 검증된 플레이북

실험 또는 상위 포스트 패턴 분석을 통해 검증된 마케팅 전술 모음. **모든 포스트 작성 시 참조.**

매주 일요일 T6에 신규 채택된 전술이 추가됨.

## 형식

```markdown
### 전술 ID: 한 줄 제목

- 출처: 실험 검증 (exp-YYYYWW-NN) 또는 상위 포스트 패턴 (YYYY-W{주차} 누적)
- 검증일: YYYY-MM-DD
- 효과 크기: activeUsers/post +N% vs 통제군
- 샘플 수: N건 (상위 포스트 패턴 전술일 경우 필수)
- 적용 조건: 어떤 시간대/콘텐츠 유형/주제일 때
- 구체 지침: 작성 시 반드시 지킬 것
- 반증 조건: 언제 이 전술을 폐기할지 (예: 효과 2주 연속 부정적일 때)
```

**출처 구분**:
- **실험 검증**: 사전 가설 + variant 대조로 +20% 이상 확인된 전술. `exp-YYYYWW-NN` 표기.
- **상위 포스트 패턴**: 4주 누적 impressions 상위 포스트에서 추출된 공통 패턴. 관찰 기반이므로 실험 검증보다 약하지만 초기 데이터 누적용으로 유효. GA4 campaign 추적 미작동 기간(2026-04~05)에는 X impressions 기준으로 대체 분석.

중복 패턴은 신규 등록 대신 기존 전술의 효과 크기·검증일만 갱신한다.

## 검증된 전술

### 전술 P01: 시즌/요일 맥락 연결

- 출처: 상위 포스트 패턴 (2026-W16~W21 누적)
- 검증일: 2026-05-24
- 효과 크기: X impressions 기준 평균 65+ (5월 일반 포스트 평균 22 대비 약 +195%, 관찰 기반)
- 샘플 수: 6건 (봄 계절 연결 2건, 금요일 저녁 2건, 주말 외출 1건, 황금연휴 예고 1건)
- 적용 조건: 현재 요일·계절·시즌과 직접 연결되는 자미두수 궁·성계 해석. 금요일 T5, 주말 T6, 계절 전환점(봄→여름, 연중 반환점 등)에 특히 적합.
- 구체 지침:
  - 첫 문장에 오늘 요일 또는 현재 시즌을 명시. "금요일 저녁", "봄이 오면", "이번 주말", "6월이 되면" 등으로 시작.
  - 해당 상황에서 작동하는 자미두수 궁(천이궁, 복덕궁, 교우궁, 질액궁 등)과 자연스럽게 연결.
  - 독자가 "지금 이 순간 나 얘기네"라고 느끼도록 구체적 상황을 묘사.
  - 이모지 사용 시 시즌과 무관한 장식용 금지 (0~1개 한도 준수).
- 반증 조건: 동일 패턴 3건 연속으로 impressions < 20일 때 일시 중단, 추가 분석 후 재적용 여부 결정.

### 전술 P02: 구체적 상황 이분법 묘사

- 출처: 상위 포스트 패턴 (2026-W16~W21 누적)
- 검증일: 2026-05-24
- 효과 크기: X impressions 기준 평균 58 (상위 3건 기준, 관찰 기반 / GA4 미측정)
- 샘플 수: 3건 (4/17 금요일 친구연락 102 imp, 4/17 금요일 밤 혼자vs함께 53 imp, 5/7 소파vs충전 19 imp)
- 적용 조건: 독자가 두 유형 중 하나에 자신을 투영할 수 있는 상황. "~한 분과 ~한 분이 있습니다" 이분법 구조.
- 구체 지침:
  - 도입부 첫 줄에서 대조되는 두 상황을 명확하게 그린다. 예: "퇴근하고 소파에 드러눕고 싶은 분과 뭔가를 해야 충전이 되는 분이 있습니다."
  - 자미두수 별 구조(음성계 vs 양성계, 태양성 vs 태음성 등)와 자연스럽게 연결.
  - CTA 없이도 독자가 자신을 투영하도록 유도. 강요하지 않고 인식시키는 톤 유지.
  - 존댓말("~있습니다", "~있어요") 필수.
- 주의: 효과 크기 편차 큼 (19~102 imp) — 요일·시간대 영향 가능성. 2주 추가 관찰 후 안정성 재평가.
- 반증 조건: 효과 크기가 지속 하락해 평균 impressions < 20이 2주 이상 지속되면 재평가.
