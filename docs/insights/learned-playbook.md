# 검증된 플레이북

실험 또는 상위 포스트 패턴 분석을 통해 검증된 마케팅 전술 모음. **모든 포스트 작성 시 참조.**

매주 일요일 T6에 신규 채택된 전술이 추가됨.

## 형식

```markdown
### 전술 ID: 한 줄 제목

- 출처: 실험 검증 (exp-YYYYWW-NN) 또는 상위 포스트 패턴 (YYYY-W{주차} 누적)
- 검증일: YYYY-MM-DD
- 효과 크기: activeUsers/post +N% vs 통제군
- 샘플 수: N건 (상위 포스트 패턴 전술일 경우 필수)
- 적용 조건: 어떤 시간대/콘텐츠 유형/주제일 때
- 구체 지침: 작성 시 반드시 지킬 것
- 반증 조건: 언제 이 전술을 폐기할지 (예: 효과 2주 연속 부정적일 때)
```

**출처 구분**:
- **실험 검증**: 사전 가설 + variant 대조로 +20% 이상 확인된 전술. `exp-YYYYWW-NN` 표기.
- **상위 포스트 패턴**: 4주 누적 activeUsers/post 상위 10% 포스트에서 추출된 공통 패턴. 관찰 기반이므로 실험 검증보다 약하지만 초기 데이터 누적용으로 유효.

중복 패턴은 신규 등록 대신 기존 전술의 효과 크기·검증일만 갱신한다.

## 검증된 전술

### T001: T5(18-21시) 공감형·지식형 포스트 우선 배치

- 출처: 상위 포스트 패턴 (2026-W16~W17 누적, 계정 정지 전 2주 관찰)
- 검증일: 2026-05-03
- 효과 크기: T5 비-CTA 공감형/지식형 평균 58.5 imp vs T6(감성형/질문형) 평균 36.3 imp (X impressions 기준 — GA4 UTM 미추적으로 activeUsers 분리 불가)
- 샘플 수: T5 4건(대운공감 53·관록궁 58·천이궁 68·교우궁 55) / T6 3건(복덕궁 50·명궁 21·부처궁 38)
- 적용 조건: 공감형·지식형 포스트, CTA/외부링크 없음, Phase 1·2 슬롯
- 구체 지침: 공감형·지식형은 T5(18-21시) 슬롯 우선 배치. T6(21-24시)은 감성형·질문형에 한정.
- 반증 조건: T5 공감형/지식형 4건 연속 impressions < 40이면 재평가. Phase 3 진입 시 실험 검증(비교 variant) 후 업그레이드 예정.
- 주의: n=4, 계정 정지 직전 2주 데이터. Phase 2 데이터 추가 후 재검증 필요. 약한 신호로 분류.
