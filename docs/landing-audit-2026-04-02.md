## High — 개선 시 전환율 상승

### H1. AIDA 흐름 깨짐 — 섹션 순서 문제

현재는 Interest(Feature) → Action(가격) → Desire(리뷰)로 순서가 역전됨.

**종합 제안 순서**:

```
Header → MainHero → FeatureSection(압축) → ReviewSection(+헤드라인)
→ ProductPreview(스크린샷) → PromotionBanner(+CTA) → FAQSection
→ DisclaimerSection → Footer → CTAButton(고정)
```

- PromotionBanner를 Review/ProductPreview 뒤로 이동 (Desire 충분히 쌓은 후 가격 노출)
- ReviewSection을 FeatureSection 직후 배치 ("실제로 이렇게 잘 맞음" 증명)
- 마케터와 기획자 간 PromotionBanner 위치 의견 분기 → A/B 테스트 대상

### ~~H2. 인터랙티브 요소 전무~~ → 기각

로그인 후 일부 컨텐츠를 무료 제공하고 있어 별도 무료 맛보기 불필요.

### H3. 사회적 증거 약함

- **마케터**: 수치 증거 없음, 리뷰 헤드라인 없음, 별점/날짜 없음
- **기획자**: 캐러셀 2초 회전 → 긴 리뷰(150자+) 읽기 불가
- **제안**:
  - 리뷰 섹션 헤드라인: "7,200명이 인생을 스포 당했어요"
  - 별점 + 날짜 추가, 회전 속도 4초로 조정

### H4. Hero 체크리스트가 "도구 설명"

- **현재**: "114개 별로 읽는 당신의 타이밍" / "12궁에 펼쳐진 별이 말하는 운의 타이밍"
- **문제**: 유저는 "내 전성기가 언제인지"에 관심, "별이 몇 개인지"에는 무관심. 1번과 2번이 "타이밍" 반복
- **제안**:
  - ~~"114개 별로 읽는 당신의 타이밍"~~ → "지금이 기회인지, 때를 기다릴 때인지"
  - ~~"12궁에 펼쳐진 별이 말하는 운의 타이밍"~~ → "돈이 들어오는 나이, 인연이 깊어지는 시기"
  - "나에게 맞는 돈 / 직업 / 인연 패턴" → 유지 (구체적이고 좋음)

### H5. ProductPreview 13개 항목 텍스트 리스트 — 피로감

- **마케터**: 항목 과다, 동일한 시각적 가중치, 핵심 가치가 묻힘
- **기획자**: 실제 결과 스크린샷 없어 990원의 가치 체감 어려움
- **제안**: 핵심 3-5개를 비주얼 카드로 강조 + 나머지 "+N개 더" 축약. 블러 처리된 결과 스크린샷 캐러셀

## Medium — 있으면 좋은 개선

### M1. "커피 한 잔 값" 메타포 2회 중복

- PromotionBanner: "커피 한 잔 값으로, 내 인생의 골든타임을 확인하세요"
- ProductPreview: "커피 한 잔 값에 이 모든 걸 받아보세요"
- **제안**: 하나를 "사주 카페 5만원 vs 인생스포 990원" 경쟁 앵커링으로 교체

### M2. FAQ 항목 부족 — 진입 장벽 해소 미흡

- 누락된 핵심 질문: "태어난 시간을 모르면 어떡하나요?" (매우 중요한 진입 장벽)

### M3. CTA "골든타임"과 Hero "전성기" 용어 불일치

- Hero: "내 **전성기**, 20대일까 30대일까?"
- CTA: "내 **골든타임** 확인하기"
- **제안**: "내 전성기 확인하기 (990원)"로 통일

### M4. PromotionBanner 긴급성 부재

- 현재: "오픈 기념 90% 할인" (기한 없음)
- **제안**: "이번 달만 90% 할인" 또는 "선착순 한정 90% 할인"

### M5. 자미두수 vs 사주 차별점 설명 부재

- 20-30대에게 "자미두수"는 생소. "사주랑 뭐가 다른데?"라는 의문 미해소
- FAQ에 설명 있으나 페이지 최하단이라 대부분 미도달
- **제안**: 간단 비교 인포그래픽을 FeatureSection 상단에 배치

### ~~M6. 뱃지 개선~~ → 기각

### M7. DisclaimerSection "FBI WARNING" 톤

- "책임지지 않습니다" 문구가 결제 직전 마지막 인상으로 남을 수 있음
- 다만 "결과가 너무 잘 맞아서 생기는 소름" 카피는 역설적 자신감으로 브랜드 톤에 부합

### M8. CompatibilitySection 주석 처리 방치

- `page.tsx`에서 import는 되어 있으나 주석 처리 상태
- 궁합 기능 출시됨 + ProductPreview에서 궁합 항목 노출 중 → 코드 제거 필요

### M9. ReviewCarousel 회전 속도

- 현재 `delay: 2000` (2초) → 긴 리뷰(150자+) 읽기 불가
- **제안**: 4초로 조정
