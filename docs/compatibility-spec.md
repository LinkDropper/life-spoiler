# 궁합 운세 기획서

## 1. 개요

### 1.1 목적

자미두수(紫微斗數) 기반으로 두 사람의 궁합을 분석하는 운세 기능을 추가합니다.
기존 평생운세/연간운세와 동일한 유료 컨텐츠 구조를 따르며, 프리뷰를 통해 궁합 결과를 맛보기로 확인한 뒤 결제 후 전체 결과를 열람합니다.

### 1.2 대상 관계

모든 관계 유형을 지원합니다.

| 유형 | key | 설명 |
|------|-----|------|
| 연인/커플 | `couple` | 연애, 결혼 관점의 궁합 |
| 친구 | `friend` | 우정, 교우 관점의 궁합 |
| 동료 | `colleague` | 업무, 협업 관점의 궁합 |
| 가족 | `family` | 가족 유대, 세대 관계 관점의 궁합 |

### 1.3 과금 모델

기존 운세와 동일합니다.
- 국내: 990원 (KRW)
- 해외: $0.99 (USD)
- 프리뷰 무료 → 결제 → 전체 결과 확인

### 1.4 지원 언어

한국어(ko), 영어(en), 일본어(ja)

## 2. 사용자 플로우

### 2.1 전체 흐름

```
프로필 목록 (/profiles)
  └→ 프로필 A 선택 → "궁합 보기" 진입
       └→ 두 번째 프로필 B 선택
            └→ 관계 유형 선택 (연인/친구/동료/가족)
                 └→ 궁합 프리뷰 페이지 (무료)
                      └→ CTA "자세한 궁합 보기"
                           └→ 결제 페이지
                                └→ 결제 완료
                                     └→ 전체 결과 페이지 (유료)
```

### 2.2 궁합 진입 방식

프로필 목록에서 프로필 A를 선택한 상태에서 "궁합 보기" 버튼을 통해 진입합니다.

1. 프로필 A가 선정된 상태에서 **두 번째 프로필 선택 화면**이 나타남
2. 기존 프로필 목록에서 B를 선택하거나, 새 프로필을 추가
3. 두 프로필이 확정되면 **관계 유형 선택 화면**으로 이동
4. 관계 유형(연인/친구/동료/가족) 중 하나를 선택
5. 프리뷰 페이지로 이동

### 2.3 pairId 생성 규칙

두 profileId를 알파벳 순으로 정렬한 뒤 해시하여 pairId를 생성합니다.
- A+B와 B+A가 동일한 pairId를 가짐 (순서 무관)
- 같은 두 사람이라도 관계 유형이 다르면 별도 결과

- 기존 `ZiweiChartGrid` 컴포넌트를 A/B 두 개 나란히 표시

- 하단 4개 항목: "???" 마스킹 (기존 연간운세 인사이트와 동일 방식)

### 5.2 섹션 상세

#### 궁합 인사이트 카드 (전체 공개)
- 프리뷰에서 "???"이던 하단 4개 항목이 실제 점수로 표시
- 8개 항목 모두 아이콘 + 라벨 + 점선 + 값 형태

#### 핵심 케미 분석
- headline (15~25자)
- content (700~800자, 4문단)
- 두 사람의 관계 역학을 스토리 형태로 풀어냄
- 왜 끌리는지, 어떤 에너지가 시너지를 내는지, 어디서 부딪히는지
- 기존 "핵심 시나리오" 섹션과 동일한 레이아웃

#### 상세 분석 (4개 카테고리)
기존 `CategoryItem` 컴포넌트와 동일한 구조. 각 카테고리는 접기/펼치기 가능.

| 카테고리 | 라벨 | 설명 |
|----------|------|------|
| 소통 & 갈등 | 💬 소통 & 갈등 | 소통 방식 차이, 갈등 발생 패턴과 해소법 |
| 재물 & 성장 | 📈 재물 & 성장 | 경제관/가치관 비교, 함께 성장할 수 있는 영역 |
| 감정 & 신뢰 | 💖 감정 & 신뢰 | 감정 교감 방식, 유대감의 깊이, 신뢰 구축 패턴 |
| 위기 & 극복 | 🛡️ 위기 & 극복 | 관계의 주요 위기 포인트, 극복을 위한 구체적 방법 |

각 카테고리 표시 항목:
- headline (15~25자)
- content (200~300자)
- tags (1~2개, # 접두사)
- score (0~100, 점수 바)

#### 종합 조언
- headline (15~25자)
- content (300~400자)
- 이 관계를 위한 실천 가능한 조언, 구체적 행동 제안

#### 하단 푸터 (고정)
- "공유하기" 버튼 (전체 너비, #ffccd9 배경)
- 클릭 시 ShareDrawer 오픈 (링크 복사, 카카오톡, LINE, 이미지 다운로드)

## 6. 관계 유형별 해석 관점

동일한 차트 데이터에 대해 AI 해석의 관점만 달라집니다.

| 섹션 | 연인 (couple) | 친구 (friend) | 동료 (colleague) | 가족 (family) |
|------|---------------|---------------|------------------|---------------|
| 핵심 케미 | 사랑의 케미, 끌림의 원인 | 우정의 케미, 함께하는 이유 | 업무 케미, 협업 시너지 | 가족 역학, 세대간 연결 |
| 소통 & 갈등 | 연애 소통, 다툼 패턴 | 대화 스타일, 오해 해소 | 업무 커뮤니케이션, 의견 충돌 | 세대 소통, 가치관 차이 |
| 재물 & 성장 | 경제관 궁합, 결혼 재정 | 성장 시너지, 함께하는 취미 | 성과 시너지, 프로젝트 궁합 | 가문 재물운, 유산/상속 |
| 감정 & 신뢰 | 감정 교감, 헌신도 | 신뢰 깊이, 비밀 공유 | 팀 신뢰, 책임 분담 | 정서 유대, 효도/존경 |
| 위기 & 극복 | 이별 위기, 권태기 극복 | 우정 시련, 소원해짐 극복 | 업무 갈등, 경쟁 관리 | 가족 갈등, 독립/의존 |
| 종합 조언 | 오래가는 사랑을 위한 조언 | 평생 우정을 위한 조언 | 최고의 파트너를 위한 조언 | 건강한 가족을 위한 조언 |

```
캐시 키 = sorted(chartHashA, chartHashB) + relationshipType + language
```

- 두 차트 해시를 정렬하여 조합 → A-B와 B-A가 동일
- 관계 유형(couple/friend/colleague/family)별로 별도 캐시
- 언어(ko/en/ja)별로 별도 캐시

### 10.2 캐시 정책

- AI 해석 성공 시 Redis에 캐시 저장
- 동일 조합 + 동일 관계 유형 재요청 시 캐시 히트
- Supabase fortunes 테이블에 영구 저장 (결제 여부와 무관)

## 12. AI 해석 컨텐츠 구조

### 12.1 7개 섹션, 4 Stage 병렬 호출

기존 연간운세(7호출, 4 Stage)와 동일한 패턴입니다.

#### Stage 1 - 병렬 2호출

| 섹션 | 분량 |
|------|------|
| 궁합 스포일러 | headline 15-25자(이모지 1개), description 30-50자, summary 300-400자 |
| 핵심 케미 분석 | headline 15-25자, content 700-800자(4문단) |

#### Stage 2 - 병렬 2호출 (Stage 1 context 전달)

| 섹션 | 분량 |
|------|------|
| 소통 & 갈등 | headline 15-25자, content 200-300자, score 0-100, tags 1-2개 |
| 재물 & 성장 | headline 15-25자, content 200-300자, score 0-100, tags 1-2개 |

#### Stage 3 - 병렬 2호출 (Stage 1+2 context 전달)

| 섹션 | 분량 |
|------|------|
| 감정 & 신뢰 | headline 15-25자, content 200-300자, score 0-100, tags 1-2개 |
| 위기 & 극복 | headline 15-25자, content 200-300자, score 0-100, tags 1-2개 |

#### Stage 4 - 순차 1호출 (전체 context 전달)

| 섹션 | 분량 |
|------|------|
| 종합 조언 | headline 15-25자, content 300-400자 |

### 12.2 프롬프트 규칙

기존 공통 규칙(`FORBIDDEN_RULES`, `INTERPRETATION_PRINCIPLES`, `STAR_INTERPRETATION_GUIDE`, `STYLE_AND_FORTUNE_GUIDE`) 공유 + 궁합 전용 추가:

- 두 사람을 "A님", "B님"으로 지칭 (실제 이름은 프론트에서 치환)
- 한 쪽에 치우치지 않고 균형 있는 해석
- 각 섹션에서 반드시 양쪽의 에너지를 모두 언급
- headline은 섹션마다 다른 문법 구조 사용

## 13. 계산 데이터 (인사이트 카드 + AI 입력)

코드 로직으로 산출하는 데이터입니다. 인사이트 카드 표시 및 AI 프롬프트 입력으로 사용됩니다.

### 13.1 총합 궁합 점수 (0~100)

base 50점에서 보정치를 합산한 뒤 0~100 범위로 클램프합니다.

| 항목 | 비교 대상 | 보정 |
|------|----------|------|
| 삼합 | 두 사람의 년지가 같은 삼합 그룹인지 | 같은 그룹 +15 |
| 육합 | 두 사람의 년지가 육합 쌍인지 | 육합 쌍 +10 |
| 오행 상생/상극 | 납음 오행의 관계 | 상생 +10, 상극 -10, 비화 +5 |
| 명궁 주성 조합 | 양쪽 명궁의 주성 성격 유형 비교 | 보완형 +15, 동질형 +5, 충돌형 -10 |
| 부처궁 교차 | A의 부처궁 주성 ↔ B의 명궁 | 있으면 +5씩 (최대 +10) |
| 사화 교차 | 화록/화기가 상대 핵심궁에 있는지 | 화록 +10, 화기 -10 |
| 도화성 | 홍란/천희/탐랑/염정 활성 여부 | 양쪽 활성 +5 |

### 13.2 카테고리 점수 (각 0~100)

| 카테고리 | 주요 비교 궁 |
|----------|-------------|
| 소통 | 교우궁 + 형제궁 주성/사화 교차 |
| 성장 | 재백궁 + 관록궁 주성/사화 교차 |
| 감정 | 부처궁 + 복덕궁 주성/사화 교차 |
| 위기극복 | 화기 충돌 지표의 역수, 명궁 보완 지표 |

### 13.3 개별 분석 항목

| 항목 | 인사이트 카드 표시 | 설명 |
|------|-------------------|------|
| 삼합 궁합 | "삼합" / "보통" | 같은 삼합 그룹이면 동물 3종 반환 |
| 육합 궁합 | "육합" / "보통" | 육합 쌍 여부 |
| 오행 궁합 | "목생화 (상생)" 등 | 상생/상극/비화/무관 |
| 명궁 성격 유형 | "보완형" 등 | 보완형 / 동질형 / 충돌형 / 중립 |
| 부처궁 교차 | (AI 프롬프트용) | 각자의 이상형과 상대 성격 비교 |
| 사화 교차 | (AI 프롬프트용) | 사화가 상대 궁에 미치는 영향 |
| 도화성 | (AI 프롬프트용) | 연애 관련 별 활성 여부 |

## 15. 주의사항

- **토큰 관리**: 두 차트 데이터가 들어가므로 프롬프트당 관련 궁만 선택적 전달
  - 소통 섹션 → 교우궁/형제궁만
  - 감정 섹션 → 부처궁/복덕궁만
- **균형 해석**: AI가 한 쪽에 치우치지 않도록 프롬프트에서 명시
- **관계 유형 분기**: 시스템 프롬프트는 공유, 유저 프롬프트에서 관계별 관점 지시
- **순서 무관**: A-B와 B-A는 동일한 결과를 보장 (pairId, 캐시 키 모두 정렬 기반)
