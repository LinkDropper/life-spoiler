# 현재 v2 구조 vs reference 톤·구성 차이 분석

## 1. 구조적 차이

| 항목 | 현재 v2 | reference (overall + score + detail) |
|---|---|---|
| **히어로** | 동물상 (강아지/고양이/...) | 한 줄 인상 정의 ("차분하고 단정한 정석형") |
| **점수** | 없음 (Intensity strong/balanced/subtle만) | **부위별 정량 점수 (8.2, 8.7, 8.8...)** + 종합 점수 |
| **부위 분석** | observation 섹션 — 사실 묘사 + features 배열 (한자 코드) | 부위별로 점수 + 해석 + 한 줄 평 (서사형) |
| **성향** | traits.strengths + traits.hiddenSide | overall.md의 "전체 인상" + 항목별 풀이 (눈/코/입/턱) |
| **분야 디테일** | relationship 1개 섹션 (관계만) | **연애운 + 재물운 + 직장운** 3개 섹션, 각각 깊게 |
| **공유 자산** | shareLine 1줄, shareableQuote 1줄 | 부위마다 한 줄 평 + 분야마다 한 줄 총평 + 캐릭터 별명 + 키워드 5개 |
| **부가 섹션** | villain, gapAnalysis, compatibility, actions | 없음 — 본질에 집중 |

## 2. 톤·문체 차이

### 현재 v2 톤 (브랜드 보이스 = 존댓말 + 친근 상담사)
```
"이마가 넓고 눈빛이 또렷한 편이라, 회의에서 자연스럽게 방향을
제시하는 순간이 생겨요. 단, 말이 빨라지면 설득력이 떨어질 수
있어서 핵심 문장을 먼저 천천히 꺼내는 게 유리해요."
```
- ✅ 부위 조합 근거 명시 (이유→결과→행동)
- ✅ 단정 회피 ("~한 편이라", "~할 수 있어요")
- ❌ **모든 문장이 "근거 + 결과 + 단서" 패턴 → 리듬이 단조롭고 교과서적**
- ❌ "회의에서", "팀이 멈춰 있을 때" 같이 직장 시뮬레이션이 많아 **재미보다 자기계발서 느낌**

### reference 톤 (반말 + 캐주얼 관상가)
```
"눈매가 날카롭게 치켜올라간 느낌보다는 차분하고 정돈된 눈이야.
관상에서는 이런 눈을 보통 관찰력, 침착함, 속도보다 정확성 쪽으로
보기도 해."
```
- ✅ "관상에서는 ~ 쪽으로 보기도 해" — **상담가 인용 화법**으로 권위와 친밀감 동시 확보
- ✅ "느낌이 있어", "한방형보다 누적형" — **비유와 대조**가 풍부
- ✅ 한 줄 평("말은 적어도, 보고 있는 건 많은 눈.")이 캡션처럼 떨어져서 인용 가치 높음
- ❌ 반말 → **인생스포 브랜드 보이스(존댓말 필수) 위반**, 그대로 차용 불가

### 톤 번역 규칙 (reference → 인생스포)
| reference (반말) | 인생스포 변환 (존댓말) |
|---|---|
| ~로 보여 / ~로 읽혀 | ~로 보여요 / ~로 읽혀요 |
| ~야 / ~지 | ~예요 / ~죠 |
| ~봐 / ~해 | ~봐요 / ~해요 |
| 네 사진 인상으로 보면 | 사진 속 인상으로 보면 (지칭 회피) |

## 3. 콘텐츠 깊이 차이

### 현재 v2 — "관계" 섹션 (relationship)
- 220~300자 본문 1개
- 어울리는 사람 유형 1줄
- 공유 인용구 1줄
- 태그 2~4개
- → **990원의 가치를 만들기엔 얕고, 사용자가 진짜 궁금한 것을 파편적으로 다룸**

### reference — "연애운" 섹션 (detail.md)
- 연애 스타일 해석 (4~5줄)
- 진짜 연애에서 어떻게 작동하는지 시뮬레이션 (4~5줄)
- **강점** (3개 글머리표)
- **주의점** (3개 글머리표)
- **한줄 총평** (인용구)
- **캐릭터 별명** + 부연 설명
- → **하나의 분야를 충분히 풀어내고, 강점/주의점이 균형 있어 신뢰감**

→ **차이의 본질**: reference는 "사용자가 가장 궁금해하는 3개 분야(연애·돈·일)"를 깊게 파고 들어가는데, 현재 v2는 9개 섹션에 흩뿌려서 어디 하나 깊지 않음.

## 4. 사용자 관점에서의 가치 차이

### 현재 v2를 본 사용자의 반응 (예상)
- "동물상이 강아지상이래." → 라벨만 기억
- "이마가 어떻고 눈이 어떻고..." → 부위 얘기는 많은데 점수가 없으니 좋다는 건지 나쁘다는 건지 모호
- "빌런 관상이 뭐야?" → 신선하지만 "그래서 뭐?" 결론 부재
- "괴리율 47%" → 숫자가 갑자기 나와서 어색
- "이번 주 작은 행동" → 자기계발서 같다, 분위기 깸

### reference를 본 사용자의 반응 (예상)
- "내 눈이 8.7점이래!" → **구체적·정량적 평가에 만족**
- "관상가가 말하길 ~한 사람이래" → **권위 인용으로 신뢰감**
- "연애에서 늦게 뜨거워지지만 오래 가는 타입이래" → **본인 경험과 매칭, 공유 욕구 발생**
- "캐릭터 별명: 무심한 듯 다정한 타입" → **친구한테 보내주고 싶은 한 마디**

## 5. 중복·낭비 진단

| 현재 섹션 | 진단 | 처리안 |
|---|---|---|
| `firstImpression` | 가치 있음 — 한 줄 정의로 더 강화 | **유지·재정의** (히어로로 격상) |
| `observation` | features 배열이 너무 학술적, 사용자가 안 읽음 | **부위별 점수표가 흡수** |
| `traits` (strengths + hiddenSide) | 가치 있음, 그러나 "분야별 디테일"과 일부 중복 | **종합 인상 분석으로 통합** |
| `relationship` | 가치 있음 — 단, 깊이 부족 | **연애운으로 확장** |
| `villain` | 신선하지만 본질 X, 공유 가치 낮음 | **삭제** |
| `gapAnalysis` | 가짜 정량(%)이 신뢰도 깎음 | **삭제, 종합 인상 본문에 녹임** |
| `compatibility` | 12종 enum 강제라 깊이 없음 | **삭제 또는 연애 섹션 흡수** |
| `actions` | 자기계발서 톤, 관상 본질 이탈 | **삭제** (강점/주의점이 대체) |
| `shareLine` | 가치 있음 — 강화 필요 | **유지** (캐릭터 별명과 통합 가능) |

## 6. 결론

**현재 v2는 "관상학적 정교함"을 추구하다 사용자가 실제로 궁금해하는 핵심을 놓쳤다.**
reference는 정반대로, 사용자가 궁금해하는 3개 분야(연애·돈·일)를 깊게 파면서 부위별 점수로 게임화 + 한 줄 평으로 공유 자산 + 캐릭터 별명으로 정체성을 부여한다.

→ **개편 방향: 학술 → 엔터테인먼트, 폭 → 깊이, 라벨 → 서사.**
