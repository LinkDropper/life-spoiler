## 한 줄 요약

> **"동물상 + 분석 카탈로그"에서 → "한 줄 정의 + 부위별 점수 + 관심사 디테일"로.**
> 사용자가 가장 궁금해하는 **"내 얼굴이 몇 점이고, 연애·돈·일에서 어떤 흐름인지"**를 정면에서 답한다.

## 핵심 개편 방향 (5가지)

### 1. 동물상의 비중을 줄이고, "한 줄 인상 정의"를 히어로로 격상
- 현재: 동물상이 히어로(`AnimalHero`) 영역을 통째로 차지 → 강아지상/고양이상이라는 라벨이 모든 인상을 압축해버림
- 개편: **"차분하고 단정한 정석형 인상"** 같이 reference처럼 한 줄로 인상을 정의하는 카피를 히어로로
- 동물상은 보조 라벨(작은 칩)로 강등. 캐릭터 이미지는 결제 후 본편에서만

### 2. 부위별 점수표 도입 (게임화)
- reference의 가장 강력한 무기: **이마 8.2 / 눈 8.7 / 코 8.8 ...** 같은 정량 점수
- 사용자가 "내 얼굴이 어디가 뭐가 좋다는 거지?"에 즉답 받음
- 부위별로 **점수 + 짧은 해석 + 한 줄 평** 3중 구조 → 인용·캡처 친화
- ⚠️ 윤리 리스크: 점수가 낮으면 미추 평가로 받아들여질 수 있음 → **점수 분포는 7.0~9.5 구간으로 강제 캘리브레이션**, 점수의 의미를 "이 부위가 인상에 얼마나 또렷하게 기여하는가"로 정의 (미추가 아님)

### 3. 관심사별 디테일을 메인 콘텐츠로 (연애/재물/직장)
- 990원의 가치를 만드는 핵심: 사용자가 진짜로 궁금해하는 것 = **연애·돈·일**
- 현재 `traits` + `relationship` + `actions`는 두루뭉술하고 추상적
- 개편: **연애운 / 재물운 / 직장운** 3개 섹션을 본편의 중심으로
  - 각 섹션: 해석 본문 + **강점** + **주의점** + **한 줄 총평** + **캐릭터 별명**

### 4. "한 줄 평"과 "캐릭터 별명" 도입 — 공유 자산 늘리기
- reference의 시그니처: 부위마다 따옴표 한 줄 평 ("말은 적어도, 보고 있는 건 많은 눈.")
- 분야마다 캐릭터 별명 ("무심한 듯 다정한 타입")
- 종합 키워드 5개 압축 ("신뢰감 / 안정감 / 신중함 / 꾸준함 / 후반상승")
- → 인스타·X에 그대로 캡처해서 올리기 좋은 단위로 콘텐츠 분해

### 5. 기존 기능형 섹션은 정리·통합
- **villain (빌런 관상)** : 흥미는 있지만 사용자 본인 분석에서 다른 "가상의 인물 묘사"로 빠지는 게 어색 → **삭제**
- **gapAnalysis (괴리율 %)** : 가짜 정량 느낌이 강함 → **삭제**, "겉과 속의 차이"는 종합 인상 본문 안에 자연스럽게 녹임
- **compatibility (찰떡/상극 동물상)** : 12종 enum 강제 매칭이 깊이 없음 → **삭제 또는 축소**, 연애 섹션의 "어울리는 사람" 단락으로 흡수
- **observation (관찰)** : 사실 묘사만이라 재미 없고 학술적 → **부위별 점수표가 흡수** (점수의 근거 = 관찰)
- **actions (이번 주 작은 행동)** : 자기계발서 톤이라 분위기 깸 → **삭제**, 각 분야 섹션의 "강점·주의점"이 그 역할 대체

## 신규 리포트 구조 미리보기

```
┌─ 히어로 (무료 프리뷰)
│  ├─ 한 줄 인상 정의 ("차분하고 단정한 정석형 인상")
│  ├─ 핵심 키워드 5개 (#신뢰감 #안정감 #신중함 #꾸준함 #후반상승)
│  ├─ 💬 자주 듣는 말 ("'조용한데 은근 강하다'는 말, 들어보셨죠?")
│  ├─ 🔍 자주 받는 오해 ("'차가워 보인다'는 오해, 거리가 먼 부분이에요")
│  └─ 동물상 칩 (보조)
│
├─ 종합 점수 (무료 프리뷰)
│  ├─ 종합 점수 (예: 8.6 / 10)
│  └─ 종합 인상 첫 단락 티저 ("볼수록 신뢰감이 생기는 타입")
│  ─── [990원 결제 게이트] ───
│
├─ 본편 1 — 부위별 점수표 (8개)
│  └─ 이마 / 눈 / 눈썹 / 코 / 입 / 턱·하관 / 광대 / 전체 균형감
│     · 점수 + 해석 (3~5줄) + 한 줄 평
│
├─ 본편 2 — 종합 인상 분석
│  └─ 한 줄 요약 → 7~10개 핵심 특성 (글머리표)
│
├─ 본편 3 — 분야별 디테일
│  ├─ 💕 연애운  (해석 + 강점 + 주의점 + 한 줄 + 캐릭터 별명)
│  ├─ 💰 재물운  (동상)
│  └─ 💼 직장운  (동상)
│
└─ 푸터 — 캐릭터 별명 + 한 줄 압축 + SNS 공유 카드
```

1. ✅ **점수 시스템 도입**: 7.0~9.5 구간 강제 + "이 부위가 인상에 얼마나 또렷하게 기여하는가" 정의 명시
2. ✅ **villain / gapAnalysis / compatibility / actions 4개 섹션 모두 삭제**
3. ✅ **동물상은 칩으로 강등** (히어로 메인이 아님)
4. ✅ **프리뷰에 종합 점수 노출** (유입 고리)
