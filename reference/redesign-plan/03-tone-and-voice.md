# 톤·문체 가이드 — reference 매력을 인생스포 보이스로

## 핵심 원칙

> reference의 **상담가 화법 + 비유적 대조 + 시그니처 한 줄 평**을 살리되,
> **존댓말("~요", "~예요") 체로 번역**한다.

## 1. reference 톤의 시그니처 패턴 (살릴 것)

### 패턴 A — "관상가 인용" 화법
> "관상에서는 이런 눈을 보통 관찰력, 침착함, 속도보다 정확성 쪽으로 보기도 해."

**효과**: 권위(전통 관상학) + 단정 회피("~로 보기도 해요") 동시 확보
**v3 변환**:
> "관상에서는 이런 눈을 보통 **관찰력, 침착함, 속도보다 정확성** 쪽으로 보기도 해요."

**프롬프트 지시**:
- `regionScores.interpretation`과 `interestAreas.body`에 **"관상에서는 ~"** / **"관상적으로는 ~"** / **"관상학적으로 보면 ~"** 화법을 한 섹션당 최소 1번 이상 사용
- 단, 같은 패턴이 **3섹션 연속 반복되면 실패** (다양성 확보)

### 패턴 B — "A보다 B" 비유적 대조
> "초반에 엄청 화려하게 치고 나가는 타입이라기보다 시간이 갈수록 평가가 좋아지는 상."
> "벼락부자형보다, 알짜배기 실속형 재물운."
> "강렬한 한 방보다, 전체 밸런스로 이기는 상."

**효과**: 사용자가 자신을 다른 타입과 비교해서 "아, 나는 이쪽이구나" 자기 정체감 확립
**v3 활용**:
- `oneLiner`, `oneLineVerdict`, `scoreOneLiner` 모두 **"A보다 B" 대조 패턴을 30~40% 채택**
- 너무 많이 쓰면 단조롭다 — 나머지는 단순 정의문, 비유, 인용형 등으로 분산

### 패턴 C — 따옴표 한 줄 평 (시그니처)
> "말은 적어도, 보고 있는 건 많은 눈."
> "진짜 평가는 후반부에 올라가는 얼굴."

**효과**: 캡션·인용·캡처 가능한 단위 — SNS 친화
**v3 활용**:
- `regionScores.regions[].oneLiner`는 **반드시 마침표로 끝나는 완결 문장**
- 18~30자, 명사구로 끝나는 시 패턴 ("~하는 눈.", "~하는 얼굴.", "~하는 상.")
- 어색한 "~예요" 강제 금지 — **이 필드 한정 명사구로 끝맺음 허용** (예외 규칙)

### 패턴 D — 의인화·비유적 정체화
> "조용한 강자형 관상"
> "무심한 듯 다정한 타입"
> "겉은 담백, 속은 은근 깊은 쪽"

**효과**: 단어 라벨 → 캐릭터 정체성 → 공유 욕구
**v3 활용**:
- `signature.oneLineDefinition`, `interestAreas.areas[].characterNickname`, `closing.finalNickname`이 모두 이 패턴
- "~형", "~타입", "~쪽" 어미를 활용
- 형용 + 형용 충돌 패턴 권장 ("조용한 + 강자", "무심한 + 다정한")

### 패턴 E — 글머리표 패턴 (강점·주의점·해석)
reference detail.md:
```
연애운에서 강점
바람기보다 안정감
감정 롤러코스터를 덜 만드는 편
오래 갈수록 진가가 드러남
```

**v3 활용**:
- `interestAreas.areas[].strengths/cautions` 각 3개 — reference와 동일 형식
- 어미 통일: 강점은 "~편이에요" 또는 명사형, 주의점은 "~수 있어요" (회피적 단정)

## 2. 반말 → 존댓말 변환 규칙

| reference (반말) | v3 (존댓말) | 비고 |
|---|---|---|
| ~로 보여 | ~로 보여요 | 가장 자주 쓰는 변환 |
| ~로 읽혀 | ~로 읽혀요 | |
| ~야 | ~예요 / ~이에요 | 받침 따라 분기 |
| ~지 / ~지 않아 | ~죠 / ~지 않아요 | |
| ~봐 / ~봐도 | ~봐요 / ~봐도 | |
| ~해 / ~한 편이야 | ~해요 / ~한 편이에요 | |
| 네 사진 인상으로 보면 | 사진 속 인상으로 보면 | "네/당신" 지칭 회피 (현 v2 정책 유지) |
| 그래서 | 그래서요 ❌ → "그래서" | 접속사는 그대로 |

**금지**: "~합니다" 격식체 — 너무 딱딱해서 reference의 친근함 상실

## 3. 인생스포 브랜드 가드 (유지)

`brand-voice.md`와 `text-report.ts`의 FORBIDDEN_RULES에서 **유지되는 규칙들**:

### 윤리 가드 (절대 유지)
- 외모 평가 어휘 금지 ("예쁘다/잘생겼다/매력적이다")
- 인종·민족·국적 언급 금지
- 나이·체중·건강 추론 금지
- 자녀·출산·범죄·정신 상태 추론 금지
- 성별·젠더 추정 금지

### 표현 가드
- 한자 관상 용어 금지 (印堂/山根/臥蠶/관골 등) — 일상 표현으로
- 측정 수치 노출 금지 (각도, 비율, 퍼센트) — "~한 편" 정성 표현으로
- 단정 금지 ("당신은 반드시 ~합니다" → "~한 경향이 있어요")
- "이 분", "당신은" 지칭 금지 — 주어 없이 시작
- 도입부·맺음말 금지 ("안녕하세요", "리포트를 작성했어요" 등)

### 금지 표현 (브랜드 보이스)
- "뼈 때리는", "소름 돋는", "충격적인", "대박"
- "인생역전", "운명을 바꿔라", "럭키 컬러"
- "99% 적중!", "충격! 당신의 운명은..."
- 느낌표/물음표 연속 사용
- 이모지 과다 (포스트당 최대 1~2개, 본문 내 0개)

## 4. 새로 추가되는 톤 가이드

### A. 점수 해석 톤
점수가 8.7점이라면:
- ❌ "당신의 눈은 8.7점으로 매우 우수합니다" — 평가·서열적
- ❌ "거의 만점에 가까운 좋은 눈" — 미추 평가
- ✅ "차분하게 정돈된 인상이 또렷하게 잡혀요" — 인상 기여도
- ✅ "관상에서는 이런 눈을 ~ 쪽으로 보기도 해요" — 권위 인용

**점수의 의미 정의 (프롬프트에 명시)**:
> "점수는 이 부위가 사용자의 인상에 얼마나 또렷하게 기여하는가의 척도입니다.
>  미추(美醜) 평가가 아닙니다. 7.0 미만은 사용하지 않습니다."

### B. 강점·주의점의 균형
- 강점은 자랑스럽지 않게, **담백하게**
- 주의점은 단점 지적이 아니라 **"이런 패턴이 있어서 이런 상황에서 손해볼 수 있어요"** 식의 친구의 조언 톤

reference 예시:
> 연애운에서 주의점
> - 표현이 부족해 오해받을 수 있음
> - 속마음을 너무 늦게 보여주면 타이밍 놓칠 수 있음
> - 좋아해도 티가 적어서 손해볼 수도 있음

→ 모두 "~수 있음" 회피 단정으로 수위 조절. v3에서도 동일 톤.

### C. 캐릭터 별명 작명 톤
- 형용 + 형용 충돌형: "무심한 듯 다정한", "조용한 강자", "허세 없는 실속파"
- ~형/~타입/~쪽 어미
- **분야별로 캐릭터 변주**:
  - 연애: "타입" (관계성)
  - 재물: "~파" 또는 "~왕" (정체성)
  - 직장: "~플레이어" 또는 "~형" (역할)
- ❌ "츤데레형", "리더형" 같은 인터넷 밈/유형 라벨 금지 (현 v2 정책 유지)

## 5. 톤 자가 검증 체크리스트

리포트 생성 후 자기검증 항목:
1. ☐ 모든 문장이 존댓말("~요", "~예요" 체)인가?
2. ☐ "관상에서는 ~", "관상적으로는 ~" 화법이 4섹션 이상에 1번씩 등장하는가?
3. ☐ "A보다 B" 대조 패턴이 oneLiner류 카피의 30~40%를 차지하는가?
4. ☐ 동일한 시작 패턴이 3섹션 연속되지 않는가?
5. ☐ 부위 점수가 모두 7.0~9.5 구간 안에 있는가?
6. ☐ 캐릭터 별명에 인터넷 밈 유형 라벨("츤데레", "INTJ" 등)이 없는가?
7. ☐ 한자 관상 용어가 출력에 섞이지 않았는가?
8. ☐ 외모 평가, 성별·인종·나이·건강 어휘가 없는가?
9. ☐ 따옴표 한 줄 평이 캡처 가능한 단위로 떨어지는가? (마침표로 끝남)
10. ☐ 강점·주의점이 모두 정확히 3개씩인가?

## 6. 톤 비교 — 같은 대상, 두 표현

### 예: "차분한 눈매" 해석

**현재 v2 (학술·자기계발서 톤)**:
> "차분한 눈빛과 단정한 눈매가 인상을 정돈된 방향으로 끌고 가요. 회의나 발표에서 상대의 말을 끝까지 듣는 자세가 자연스럽게 배어 있어서, 즉답보다 한 박자 늦은 정확한 답이 신뢰를 만들 수 있어요. 단, 침묵이 길어지면 무관심으로 오해받을 수 있어 첫 마디를 짧게 던지는 습관이 도움이 돼요."

**v3 (reference 톤 + 존댓말)**:
> "눈매가 날카롭게 치켜올라간 느낌보다는 차분하고 정돈된 눈이에요. 관상에서는 이런 눈을 보통 **관찰력, 침착함, 속도보다 정확성** 쪽으로 보기도 해요.
>
> 사람을 처음 볼 때 한 번 보고 판단하는 편이고, 감정에 휩쓸리기보다 상황 파악을 먼저 하는 쪽이에요."
>
> *— "말은 적어도, 보고 있는 건 많은 눈."*

→ **v3가 더 짧지만 reference의 시그니처 패턴(관상가 인용 + 글머리표 + 한 줄 평)을 모두 살림**.

## 정리

| 살릴 것 | 버릴 것 |
|---|---|
| 관상가 인용 화법 ("관상에서는 ~ 쪽으로 보기도 해요") | 회의/발표 시뮬레이션식 자기계발서 톤 |
| "A보다 B" 비유적 대조 | 모든 문장 "근거+결과+단서" 패턴 단조로움 |
| 따옴표 한 줄 평 (마침표 끝맺음 명사구 허용) | shareableQuote 같은 추상적 인용구 |
| 캐릭터 별명 ("조용한 강자형") | 동물상 라벨 단독 강조 |
| 강점·주의점 글머리표 패턴 | "이번 주 작은 행동" 같은 자기계발 처방 |
| 핵심 키워드 5개 압축 | intensity 3단계 추상 라벨 |
