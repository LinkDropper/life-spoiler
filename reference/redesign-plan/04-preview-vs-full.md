# 프리뷰(무료) vs 본편(990원) 분리 전략

## 원칙

> **프리뷰는 "내가 누구인지의 정체성"까지 확인하게 한다.**
> **본편은 "그래서 연애·돈·일에서 어떻게 살까"의 답을 준다.**

프리뷰가 빈약하면 결제 클릭이 안 일어나고, 너무 풍부하면 결제할 이유가 사라진다. 균형점은 **"내 캐릭터를 알았으니 이제 행동 지침이 궁금해지는 지점"** 에서 컷.

## 본편 화면 구성 (스크롤 순서)

1. **Hero** (`signature` 전체) — 프리뷰와 동일
2. **종합 점수 + 인상** (`overallScore` 전체)
   - 종합 점수 + scoreOneLiner
   - summary 2단락 전체
   - highlights 6~10개 모두 펼침
3. **부위별 점수표** (`regionScores` 전체)
   - 8개 부위 카드, 각 카드: 라벨 + 점수 + interpretation + bullets 3개 + 한 줄 평 (따옴표 카드)
4. **분야별 디테일** (`interestAreas`)
   - 💕 연애운 카드: oneLineDefinition → body → 강점/주의점 → oneLineVerdict → 캐릭터 별명 + 부연
   - 💰 재물운 카드 (동일 구조)
   - 💼 직장운 카드 (동일 구조)
5. **마무리** (`closing`)
   - finalNickname (큰 카피) + finalNote
   - shareLine + SNS 공유 버튼
6. **본편 액션 영역** (`FaceReportActions` — 기존 컴포넌트 재사용)
   - 다운로드 / 공유 / 다시 분석

## 결제 동기 — 어디서 "결제 클릭"이 일어날 것인가

| 트리거 | 메커니즘 |
|---|---|
| **`commonlyHeardPhrase`** | **"어 진짜 그런 말 들어봤어!" → 자기인식 폭발 → 결제 임박** |
| **`commonMisread`** | **"내가 그렇게 보인다고? 그럼 진짜 나는?" → 반전 욕구** |
| 종합 점수 노출 | "8.6점이라고? 부위별로는 뭐가 높은지 궁금해" |
| 부위 라벨만 노출 | "8개 부위가 분석된대. 내 코는 몇 점일까?" |
| 핵심 키워드 5개 | "이게 나라는 거지? 그럼 연애에서는 어떨까?" |
| 분야 라벨 3개 | "💕💰💼 — 본편에서 디테일이 나온대" |
| highlights 잠금 표시 | "+ 6개의 인상 특성" — 정보 격차로 호기심 자극 |

## 주의: 프리뷰 분량의 함정

너무 길면 → 사용자가 "충분히 봤다"고 느끼고 닫음.
**프리뷰 총 글자 수 가이드: 430~580자** (자기인식·반전 트리거 2줄 추가분 반영)
- 추가된 `commonlyHeardPhrase` + `commonMisread`는 짧지만 **밀도 높은 훅**이므로 분량 증가 부담보다 전환율 이득이 큼
- 단, summary·highlights는 **잠금 라벨 직전까지만** — 본편 가치 보존

## 본편 등록 후 OG 카드 (공유)

기존 `ShareableQuoteCard` 컴포넌트의 카드 디자인을 재활용하되, 노출되는 카피는:
1. `closing.finalNickname` (큰 카피) + `signature.oneLineDefinition`
2. 또는 `closing.shareLine` (한 줄 SNS용)

→ 사용자가 "어떤 카드를 공유할지" 선택할 수 있게 **카드 슬라이더** 추가 검토.

## A/B 테스트 후보 (개편 후 검증)

| 변수 | A | B |
|---|---|---|
| 종합 점수 노출 | 프리뷰에 노출 | 점수도 잠금 |
| highlights 잠금 | 처음 2개 노출 | 모두 잠금 |
| 분야 라벨 | 3개 모두 노출 | 1개만 티저 노출 |

→ 어느 패턴이 결제 전환율(`paid_at` 채워진 비율)이 높은지 측정.
