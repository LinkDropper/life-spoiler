## 3. 가장 심각한 문제 — 점수 편차 (7.8 ~ 8.2, 편차 0.4)

### 3.1 현상
| 인물 | 점수 | 동물상 |
|---|---|---|
| 1번 | 8.1 | 여우상 |
| 2번 | 8.2 | 강아지상 |
| 3번 | 7.8 | 사슴상 |

"완전히 다른 인물 3명"이 0.4 편차 안에 몰림. 구간은 7.0~9.7로 넓혀 놨는데도.

### 3.2 원인 분석

**원인 A — Gaussian fit의 구조적 한계**
```typescript
const gaussianFit = (x, center, width) => exp(-((x-center)/width)²)
```
- 한국인 `foreheadWidthRatio`는 0.85~0.95 좁은 분포. `width: 0.06` gaussian은 중심(0.9)에서 살짝 떨어진 값도 fit 0.4~0.7로 수렴.
- 즉, **측정값 분포가 좁으니 fit도 좁게 나와 점수도 좁음**.

**원인 B — fitToBaseScore 선형 매핑의 한계**
```typescript
fitToBaseScore(fit) = 7.2 + fit × 2.3
```
- 대부분 fit이 0.4~0.7 → 점수 8.1~8.8. 넓게 퍼지지 않음.

**원인 C — balance 가중치 (0.35)가 평균 끌어당김**
```typescript
deriveTotalScore = othersAvg × 0.65 + balance × 0.35
```
- balance 점수는 7.8 + fit × 1.7이라 범위가 더 좁음 (8.4~8.9 수렴).
- 이 값이 35% 비중이니 **총점을 8.0~8.5로 끌어당기는 자석 역할**.

**원인 D — 8개 부위 독립 평균**
- 각 부위 fit이 독립적으로 0.4~0.7 정도면, 평균의 법칙으로 총점은 더욱 중앙값에 수렴.
- 8개가 모두 한쪽으로 쏠리는 경우는 매우 드물어 점수 편차가 구조적으로 억제됨.

### 3.3 결론
**Gaussian fit + 선형 매핑 + balance 가중치 + 평균의 법칙** 네 개가 결합되어 **"모든 얼굴이 8.0~8.5로 수렴하는 구조적 함정"**을 만들고 있음. Threshold를 몇 번 더 조정해도 근본 해결 불가.

## 4. 텍스트 수렴 — Gemini의 관상학 학습 편향

### 4.1 현상 (result4.md 전체에서 반복된 어휘)
```
"안정" 5회  "꾸준" 4회  "조화/조화롭" 5회
"부드럽" 9회  "통찰" 3회  "차분" 4회

"관상학에서는 ~ 보기도 해요" 3/3 섹션
"~로 풀이하기도 해요" 3/3 섹션
```

### 4.2 원인
Gemini가 한국어 관상 텍스트로 학습한 결과 **"관상 = 안정/꾸준/조화/통찰"** 라는 강한 어휘 연관을 가지고 있음. hint를 수치로 바꿔도, animal type("여우상"/"강아지상"/"사슴상") 단서만 주면 이 어휘 세트로 자동 확장.

### 4.3 근본 해결 방향 옵션

**옵션 α — Stage A 프롬프트의 강제 Reframing** (2시간, 리스크 낮음)
- "관상학에서는 ~"/"~로 풀이하기도 해요"/"~로 보기도 해요" 등 상담가 인용 화법을 **전체 응답에 2회로 상한** (현재는 권장).
- animal type 단어 자체를 Stage A 프롬프트에서 제거 (Stage C에만 주입).
- **어휘 블랙리스트를 Option II에 추가**: "안정, 조화, 부드럽, 통찰, 차분, 또렷, 꾸준, 신중, 관찰력, 판단력" 각 2회 상한.
- 문장 시작 강제 어휘군: 색·질감·비례·윤곽·피부결·음영·표정·각도·대칭 중 하나로 시작하도록 lane 재설계.

**옵션 β — hint 완전 제거** (1시간, 리스크 중)
- Stage A에서 수치 hint 블록도 제거. animal 이름과 점수만 제공.
- "이미지만 보고 창작"을 엄격히 지시.
- 단점: LLM이 점수와 모순되는 해석을 낼 수 있음 (이마 9.2인데 "흐릿한 이마"라 쓰는 경우).
- 대응: 고·중·저 점수 구간만 animal-level로 전달 ("이마 강", "턱 약" 식 3-bucket).

**옵션 γ — 부위 조합 강제** (1시간, 리스크 낮음)
- Stage A에 "3개 부위 조합 관찰 필수" + "각 인물 고유의 부위 조합을 택하라"를 하드룰로.
- 예: animal="fox" + 부위 조합(ex. 눈+턱+이마)을 code가 결정해서 주입 → 매 인물이 다른 조합으로 진입.

## 5. 점수 편차 — 근본 해결 옵션

### 옵션 A — **평균-표준편차 확장 매핑** (추천 · 1~2시간)
현재 `fitToBaseScore(fit) = 7.2 + fit × 2.3`을 비선형 확장:
```typescript
// fit를 0.4 이하와 0.7 이상에서 극단으로 보냄
const expandedFit = (fit - 0.5) × 2.5 + 0.5  // 기울기 2.5배
const clamped = clamp(expandedFit, 0, 1)
return 7.2 + clamped × 2.3
```
- 효과: 평균대(0.4~0.6)였던 fit이 0.0~1.0 양극으로 펼쳐져 점수 편차 1.5+ 달성 기대.
- 리스크: 극단값이 너무 자주 나올 수 있어 시뮬레이션 필요.

### 옵션 B — **balance 가중치 0.35 → 0.15** (30분, 저리스크)
- balance의 평균 수렴 효과를 줄임.
- 총점 편차가 다른 7개 부위 편차에 더 민감해짐.

### 옵션 C — **동물상 보정 점수** (2시간, 중리스크)
- 여우상은 눈·턱 가중치 높게, 호랑이상은 턱·광대 가중치 높게 식으로 **animal별 가중치 테이블** 적용.
- 같은 얼굴이라도 animal type에 따라 점수 편차가 구조적으로 분화됨.
- 단점: 설계 리소스 크고 검증 어려움.

### 옵션 D — **Rank-based 정규화** (반나절, 고리스크)
- 과거 사용자의 측정값 분포를 DB에 쌓고, 새 얼굴의 각 측정값이 상위 몇 %인지 계산 → 점수로 매핑.
- 효과 극대. 점수 편차가 사용자 분포 전체에서 퍼짐.
- 단점: 초기 샘플 필요 + 인프라 구축.

## 6. 근본 제안 — 3단계 조합

사용자의 "제발 근본적으로 개선되고 결과가 다채롭게 나왔으면" 요청에 대응해 **즉시 실행 + 중기 실험** 세트로 제안.

### Phase 17 (즉시, 2~3시간)
**점수 편차 확보**
1. 옵션 A: `fitToBaseScore`를 비선형 확장 (평균-표준편차 확장 매핑)
2. 옵션 B: `deriveTotalScore`의 balance 가중치 0.35 → 0.15

**텍스트 다양화**
3. 옵션 α: Option II 블랙리스트 대폭 확장 + 상담가 화법 2회 상한 + Stage A에서 animal 단어 제거

### Phase 18 (다음 단계, 반나절)
**구조적 다양화**
4. 옵션 γ: Stage A에 "부위 조합 강제 주입" — 매 인물마다 다른 3개 부위 조합을 code가 결정해 hint로 전달

### Phase 19 (실험 단계, 1일)
**LLM 자유도 확대**
5. 옵션 β: Stage A hint 블록 완전 제거 A/B 실험
6. 결과 비교 후 유지/폐기 결정

## 7. 결론 — 사용자 직감의 확증

> "3명이 완전 다른데 점수도 거의 비슷하고 텍스트도 어느 정도 비슷하다"

이 체감은 **구조적 사실**. Patch(Phase 15, 16, 16.1, 16.2)로 어느 정도 개선은 됐지만, **Gaussian fit + 선형 매핑 + balance 가중치 + LLM의 관상학 편향 어휘** 네 개가 결합되어 "8.0~8.5 수렴 + 안정/꾸준/조화 어휘 수렴"이 반복 재생산되고 있음.

**Phase 17 + 18을 연달아 실행해야 근본 해결 가능**. Phase 17만으로도 체감 개선 폭이 클 것으로 예상.
