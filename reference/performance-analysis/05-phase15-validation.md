## 🟡 여전히 남은 문제

### 1. [전체 균형감] 섹션의 새 수렴 패턴 — "하관이 넉넉"

| 인물 | [전체 균형감] 본문 첫 문장 |
|---|---|
| 1번 | 얼굴 전체적으로 이목구비가 조화롭게 배치되어 있고, **특히 하관이 넉넉하게 잡혀 있어요** |
| 2번 | 얼굴 전체적으로 이목구비가 조화롭고, **특히 하관이 넉넉하게 받쳐주는 느낌** |
| 3번 | 얼굴 전체적으로 **하관이 안정적으로 넓게 잡혀 있어** 균형감이 좋아요 |
| 4번 | 얼굴의 각 부위가 전체적으로 조화로운 가운데, **특히 넉넉한 하관이 안정감** |
| 5번 | 얼굴형이 세로로 살짝 긴 듯하면서도 **턱과 입매가 넉넉하게** 자리 잡아 |

→ **4/5**가 "하관이 넉넉·받쳐주는" 패턴으로 수렴.

**원인 추정**: Balance scorer의 7구간 분기 중 **"하부형(lower > 0.37)"** 조건이 의외로 자주 걸림.
- 한국인 samjeong.lower 평균 분포: 0.33~0.38
- `lower > 0.37` 임계점이 **평균 상단**에 있어 실제로 약 40~50%가 이 구간에 걸림
- 따라서 "하부(턱)가 넉넉해 행동·실행이 묵직하게 받쳐주는 균형" hint가 4/5에 선택됨

**추가 요인**: `balanceFit` 조건 순서상 하부형 체크가 상부형 바로 다음이라 중간 구간이 지나치게 빨리 고갈.

### 2. "묵직" 어휘 반복 (4/5)

- "묵직한 실행력" / "묵직하게 받쳐주는" / "묵직한 힘"
- Balance hint 중 "하부형" 설명에 "묵직하게" 들어가 있어 LLM이 그 뉘앙스를 그대로 전파
- 또한 `fitToBaseScore` 및 reference 톤에 "묵직" 표현이 잦음

### 3. [전체 균형감] bullets도 추상 반복

5명 모두 비슷한 bullets:
- "조화와 균형을 중시" / "맡은 바 책임을" / "내면의 단단함"
- "실천하는 힘이 묵직하게" / "전반적으로 흔들림 없는 인상"
- "지속적인 성장을 추구" / "차분하면서도 단단한 매력"

→ bullets 3개 × 5명 = 15줄 중 **"흔들림 없는·꾸준한·단단한"**이 반복.

### 4. LLM의 "결론 톤" 편향

[종합인상] 첫 문장은 잘 다양화됐지만 **마지막 문장**은 여전히 "관상에서는 이런 인상을 꾸준하게 성장하는 상으로 보기도 해요" 같은 클리셰로 수렴.

## 🔬 근본 원인 재분석

Phase 15로 **region hint 자체는 다양화됐지만**, 아직 남은 문제 2가지:

### 원인 A: Balance hint 분기 임계값이 한국인 평균과 어긋남

Balance scorer 현재 로직:
```typescript
if (upper > 0.37) { ... 상부형 }
else if (lower > 0.37) { ... 하부형 }   ← 한국인 40~50% 걸림
else if (middle > 0.37) { ... 중안형 }
else if (faceRatio > 1.25) { ... 세로형 }
else if (faceRatio < 0.98) { ... 원형 }
...
```

`lower > 0.37`이 너무 느슨해서 "하부형"에 사진이 대거 쏠림.

### 원인 B: LLM의 재수렴 경향

hint가 여러 종류 있어도 LLM은:
- 같은 톤(묵직·안정·포용)으로 확장 해석하는 경향
- 섹션 마무리 문장을 "꾸준·조화·균형"으로 닫는 버릇

이는 **모델 수준의 문제** (Gemini 2.5 Flash의 보수성).

## 🛠 Phase 16 제안 (선택)

### 옵션 I — Balance scorer 임계값 재조정 (30분, 가장 효과적)

```typescript
// 현재: lower > 0.37 에 다수 걸림
// 제안: 임계값 조정 + 조건 우선순위 변경

if (m.faceRatio > 1.20) { ... 세로형 }               // 세로가 긴 경우 먼저
else if (m.faceRatio < 1.00) { ... 원형 }             // 둥근 얼굴
else if (upper > 0.38) { ... 상부형 }                 // 더 엄격
else if (lower > 0.40) { ... 하부형 }                 // 0.37 → 0.40 (실제 넉넉한 경우만)
else if (middle > 0.37) { ... 중안형 }
else if (Math.abs(upper - lower) < 0.02) { ... 균형형 } // 더 엄격
else if (Math.abs(upper - middle) < 0.02) { ... 상중균형형 }  // 추가
else { ... 보완형 }
```

→ 분기 8개로 확장, 임계값 조정으로 각 구간 분포 균등화.

### 옵션 II — "묵직" 등 반복 어휘 블랙리스트 (15분)

프롬프트에 추가:
```markdown
### ⚠️ 다음 어휘는 리포트 전체에서 3회 이하로 사용:
- "묵직한/묵직하게"
- "안정적"
- "조화롭게"
- "꾸준"
- "포용"

4회 이상 등장하면 실패 — 다른 표현으로 교체.
```

validator에 카운트 체크 추가 가능.

### 옵션 III — 마무리 문장 다양화 강제 (15분)

Stage A `summary` 마지막 문장 규칙 추가:
```markdown
- 마지막 문장은 "~로 보기도 해요", "~상으로 풀이해요" 같은 결론 클리셰로 끝내지 말 것.
- 대신 **구체적 결과 장면** 또는 **대조형 평가**로 마무리.
  - 예: "회의 중 한 마디로 분위기를 정돈하는 순간이 자주 있을 타입"
  - 예: "어수선한 자리에서 오히려 눈에 띄지 않지만, 마무리 단계에 이 사람을 찾게 되는 결"
```

### 옵션 IV — bullets 다양성 validator (30분)

현재 bullets가 사진별로 비슷한 어휘 반복 → `highlights 반대 결 축` 검증과 유사한 방식으로 bullets에 추가:
- 전체 bullets에서 "꾸준/단단/조화/균형" 등 5대 클리셰 어휘 합산 8회 이하로 제한
