## 3. 미달 (추가 조정 필요)

### 3.1 🔴 점수 편차 1.0 — 목표 1.5+ 여전히 미달

| 인물 | 점수 |
|---|---|
| 1번 | 7.3 |
| 2번 | 8.2 |
| 3번 | 7.2 |

Phase 17.3의 비선형 계수 강화(2.5→3.0) + Gaussian width 20% 축소는 편차를 0.9 → 1.0 (+11%)만 확장. 목표치의 67% 수준.

**원인 분석**:
- **평균의 법칙이 너무 강함**: 8개 부위 fit이 양극으로 흩어져도 평균 내면 +/-가 상쇄되어 총점은 중간대로 회귀.
- 예: 1번 얼굴이 "이마 9.2, 눈 7.0, 코 9.0, 입 7.2..."처럼 극단이 섞여도 평균이 8.2
- 현재 편차 확대는 **개별 부위 점수의 편차**에만 작용하고, 총점 계산은 그 편차를 다시 평균화로 **소멸**시킴.

**필요한 해결책**: 단순 평균이 아닌 "편차 보정" 또는 "정규화 변환"이 총점 계산 단계에 들어가야 함.

### 3.2 🟡 [종합인상] 첫 문장 — "이마가 시원하게 드러나" 2/3 재발

```
1번: "이마가 시원하게 드러나면서도 적당한 넓이를 지녀"
3번: "이마가 시원하게 드러나고 눈매가 차분하게 정돈"
```

Phase 18 조합 강제가 1번/3번 모두 forehead를 **강점 1**로 할당한 결과. LLM이 이마 강점을 살려야 하니 "이마가 시원하게 드러나"로 시작 수렴. **조합 강제 패턴이 새 동질화 벡터**가 됨.

### 3.3 🟡 "부드럽" 5회 — 새 수렴 어휘

| 인물 | "부드럽" 등장 |
|---|---|
| 1번 | 0회 |
| 2번 | 3회 ("부드럽고", "부드럽게", "부드러운데") |
| 3번 | 2회 ("부드럽게", "유연하면서도") |

블랙리스트 상한 4회라 3회는 통과하지만 3번까지 합치면 5회로 상한 위반 수준. 다만 섹션별 개별 체크라 걸리지 않음.

**원인**: 2번은 얼굴형(둥근) 분기 → "둥글게 감싸는" → LLM이 "부드러운 곡선" 자연 유도.
Phase 17.4 분기 hint 문구 자체에 "부드럽게 감싸는"이 포함돼 있어 LLM이 재사용.

### 3.4 🟡 [종합균형감] 마무리 한 줄 — "A한데, B" 역설 3/3 (의도된 결과지만 체감 수렴)

```
2번: "부드러운데, 내면의 심지는 곧고 단단해요."
```

패턴 자체를 로테이션하거나 "단단" 같은 공통 수식어 상한 추가 필요.

## 5. 추가 제안

### 🥇 Phase 17.6 — 총점 편차 보정 (25분, 저리스크)
`deriveTotalScore`에 **편차 보정항**을 추가해 극단이 섞인 얼굴의 총점이 중앙값으로 회귀하지 않도록.

```typescript
const othersScores = others.map((r) => r.score);
const maxScore = Math.max(...othersScores);
const minScore = Math.min(...othersScores);
const spread = maxScore - minScore;
// spread가 클수록(강점과 약점이 극명할수록) 총점이 평균에서 멀어짐
const spreadBonus = spread > 1.2 ? (othersAvg - 8.2) * 0.5 : 0;
const raw = othersAvg * (1 - balanceWeight) + balance.score * balanceWeight + spreadBonus;
```
효과: 편차 큰 얼굴의 점수가 평균에서 ±0.3~0.5 이동. 편차 1.0 → **1.5+** 달성 가능.
