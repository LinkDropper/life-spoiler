## 2. 명확한 성공 (유지할 것)

### 2.1 🏆 [종합인상] 첫 문장 분화 — Phase 18 조합 강제의 대성공
이전 "눈꼬리+눈매" 3/3 수렴이 **완전히 해소**. 3명 모두 다른 부위 조합으로 시작:

```
1번 → "콧대 중간이 곧게 뻗어 내려오고 이마가 시원하게 드러나"     [콧대+이마]
2번 → "이마에서 턱으로 이어지는 얼굴선이 부드러운 곡선을 그리면서"  [윤곽]
3번 → "눈매가 가늘고 길게 뻗어 있어, 주변을 예리하게 관찰하는 힘"  [눈+이마]
```
Phase 18의 `buildRegionCombinationBlock`이 점수 기반 상위 2 + 하위 1 조합을 강제 주입 → 매 인물이 서로 다른 해석 축으로 진입함. **구조적 개선의 명백한 증거**.

### 2.2 블랙리스트 어휘 수렴 해소
result4에서 10회 이상 등장하던 "꾸준/안정/통찰/또렷" 세트가 result5에서는 대부분 1회 이내로 급감:
- "통찰" **0회** (이전 3회)
- "꾸준" **1회** (이전 4회)
- "안정" **1회**
- "또렷" **1회**

Phase 17 블랙리스트 확장 + Soft 재시도 feedback 루프가 기대대로 작동.

### 2.3 상담가 화법 과다 해소
Phase 17 상한(Stage A 2회, B 4회, C 3회)이 기능. 각 인물 텍스트에서 "관상학에서는 ~", "관상적으로는 ~" 출현 빈도가 1~2회로 수렴.

### 2.4 animal-classifier 에러 재현 안 됨
Phase 17.2의 재시도 확장(5회) + feedback 주입 + Fallback이 제공된 상태라 사용자가 에러로 차단되는 리스크가 크게 감소.

## 3. 미달 (추가 조정 필요)

### 3.1 🔴 점수 편차 0.9 — 목표 1.5+에 못 미침
| 인물 | 점수 |
|---|---|
| 1번 | 7.6 |

Phase 17의 비선형 매핑(`(fit - 0.5) × 2.5 + 0.5`)이 효과는 있었지만 충분치 않음. 원인 추정:

### 3.2 🔴 [종합균형감] "중안 긴" 2/3 수렴 재발
result4 3/3 → result5 2/3로 **개선이 아니라 유지**. Phase 16.1에서 `middle > 0.365 → 0.385` 상향이 부족했던 것.

```
1번: "중안(눈부터 코끝까지)의 길이가 다른 부위보다 살짝 긴 듯한"
3번: "얼굴 전체적으로 중안부가 길어 차분하게 주변을 관찰"
2번: "턱과 입매 쪽 선이 살짝 더 뚜렷" [다른 분기 ← 유일하게 다름]
```

한국인 `samjeong.middle` 실측 분포 중심이 0.37~0.39에 있어 0.385 threshold도 여전히 catchment가 큼. 추가 상향 또는 우선순위 재조정 필요.

const expanded = clamp(centered * 3.0 + 0.5, 0, 1);  // 2.5 → 3.0

**추가**: 각 부위 Gaussian `width`를 추가 20% 축소 → 평균대에서 fit 편차 커짐.

### Phase 17.4 — [종합균형감] 우선순위 재설계 (45분)
```typescript
// 현재: middle 우선 → 상/하 상대차 → 얼굴형 → 미세 편향
// 변경: 얼굴형(faceRatio) 먼저 → 상/하 상대차 → middle → 미세 편향

if (m.faceRatio > 1.22) { ... 세로형 }
else if (m.faceRatio < 0.97) { ... 둥근형 }
else if (upperLowerDiff > 0.03) { ... 상부 우세 }
else if (upperLowerDiff < -0.03) { ... 하부 우세 }
else if (middle > 0.40) { ... 중안 긴 (threshold 0.385 → 0.40 상향) }
else if (upperLowerDiff > 0.012) { ... 미세 상 }
else if (upperLowerDiff < -0.012) { ... 미세 하 }
else { ... 고른 균형 }
```
얼굴형이 먼저 걸러지니 중안 catchment가 1/3 이하로 감소할 것으로 예상.
