```

"벼락부자형보다, 알짜배기 실속형 재물운."   ← scoreOneLiner
```

그런데 본편의 재물운 `oneLineVerdict`가:
```
"벼락부자형보다, 알짜배기 실속형 재물운."   ← interestAreas[money].oneLineVerdict
```

→ **완전히 동일한 문구**. LLM이 Stage A의 `overallScore.scoreOneLiner`와 Stage C의 `areas[money].oneLineVerdict`를 구분하지 못하고 같은 "reference 예시 카피"를 양쪽에 베껴넣음.

**의미 오염**: 종합 점수 옆에 재물운 카피가 뜨면 "이 점수가 재물운 점수인가?"로 오독됨.

**원인 추정**:

- LLM이 창작하지 않고 예시를 그대로 출력

**수정 방향**:
- Stage A 프롬프트: `scoreOneLiner` 예시를 "강렬한 한 방보다, 전체 밸런스로 이기는 상" 같이 **종합 인상 맥락**으로만 한정

### 3. 부위별 `oneLiner` 패턴 획일화
현재 8개 oneLiner:
- "생각의 깊이가 남다른 이마를 가졌어요."
- "결코 물러서지 않는 눈매를 가졌어요."
- "자신만의 질서를 지키는 눈썹이에요."
- "현실 감각이 탄탄한 코를 가졌어요."
- "신뢰를 주는 차분한 입매를 가졌어요."
- "온화함과 포용력을 지닌 턱이에요."
- "자연스럽게 빛나는 사회적 존재감이에요."
- "안정감 있는 밸런스가 돋보이는 얼굴이에요."

→ **6/8이 "~한 [부위]를 가졌어요/이에요"** 종결어미. 시그니처 한 줄 평이라고 보기엔 단조로움.

**reference 시그니처 (대조)**:
- "말은 적어도, 보고 있는 건 많은 눈."  ← 대조+명사구
- "진짜 평가는 후반부에 올라가는 얼굴." ← 주어+동사 명사구
- "가볍게 던지는 말보다, 묵직하게 남기는 말." ← A보다 B 대조
- "순간 임팩트형보다, 쌓아 올리는 커리어형." ← 대비형

다양한 문법·리듬이 있는 반면, 현재 결과는 같은 공식을 반복.

**수정 방향**:
- 프롬프트 Stage B에 **"8개 oneLiner는 최소 4종 이상의 서로 다른 문법 구조"** 강제
- 금지 패턴: 같은 종결어미가 3회 이상 연속
- 예시를 "~을 가졌어요" 외 다양한 형태로 추가:
  - A보다 B 대조형: "급발진보다, 한 박자 늦는 눈."
  - 명사구형: "말보다 행동이 먼저인 턱."
  - 역설형: "조용한데, 보는 눈은 정확하다."

### 4. `commonlyHeardPhrase` 훅이 약함
```
"'묵묵히 자기 할 일 잘하는 사람'이라는 말, 자주 듣지 않나요?"
```

- 따옴표 안 문장이 길고 형식적
- "묵묵히 자기 할 일 잘하는 사람"은 너무 포괄적 — 누구에게나 해당될 수 있음
- reference의 감정 폭발 트리거("조용한데 은근 강하다" 같은 짧고 구어적) 강도 부족

**개선안 예시**:
- "'있는 듯 없는 듯한데, 없으면 티 난다'는 말, 들어보셨죠?"
- "'화 안 내고 다 들어주는데, 선은 분명하다'는 말, 익숙하시죠?"
- "'은근 고집 있다'는 말, 가까운 사람한테 들은 적 있으실걸요?"

→ **짧고**, **대비가 있고**, **본인만의 경험에 꽂히는** 표현.

### 5. 분야별 `body`가 같은 색
**연애운**: "서두르기보다, 천천히 스며드는 관계를 선호하는 타입"
**재물운**: "기본기가 탄탄한, 꾸준히 쌓아가는 실속형 재물운"
**직장운**: "묵묵히 내실을 다지는, 믿음직한 일꾼 타입"

→ 3개 모두 **같은 "느리고 꾸준한" 변주**. 분야별 고유 뉘앙스 부재.

**reference detail.md 대조**:
- 연애: "아무한테나 쉽게 마음 열지 않음 / 썸이 느릴 수 있음 / 표현이 요란하지 않음" ← **관계 시뮬레이션**
- 재물: "갑자기 대박보다 조용히 모으는 타입 / 소비도 완전 충동보다 계산이 있는 타입" ← **돈의 흐름**
- 직장: "조직 안에서 튀기보다 신뢰 쌓는 타입 / 승진운 초반 주목형 아닌 후반 평가상승형" ← **역할 시뮬레이션**

reference는 각 분야에서 **그 분야 고유의 구체적 상황**(연애 초반 썸, 돈 다루는 태도, 조직에서의 위치)을 묘사하는데, result1은 전부 "꾸준하고 믿음직한 타입"이라는 같은 문장을 3번 반복.

**수정 방향**:
- 프롬프트 Stage C에 **분야별 상황 템플릿 예시 추가**:
  - 연애: 썸 초반·감정 표현 장면
  - 재물: 소비/투자 판단 장면
  - 직장: 회의/협업/평가 장면
- 3개 분야의 body는 **겹치는 형용사 3개 이상 금지** (예: "꾸준", "신뢰", "차분" 동시 등장 금지)

### 7. 설계 구조는 정상
- ✅ 8개 부위 전부 렌더 (순서 이마→눈→눈썹→코→입→턱→광대→균형감)

- ✅ 프리뷰 티저 구조: 종합 점수 노출 + highlights 2개만 + 잠금 라벨
- ✅ 부위별 점수 7.5~9.5 구간 준수 (8.1~9.0)
- ✅ 종합 점수 8.7 — 안전한 대역

### 8. 윤리 가드 유지
- 외모 평가 어휘 없음
- 성별·나이·건강·인종 추론 없음
- 한자 관상 용어 노출 없음
- 측정 수치(°, 비율) 노출 없음

### 9. 관상가 인용 화법 출현
- "관상에서는 ~" 패턴이 여러 부위·분야에서 등장
- 권위와 친밀감의 동시 확보는 성공

### 10. `characterNickname` 일부는 성공적
- 재물운 "차곡차곡 적금왕" ← **강함** (형용 + 왕 패턴)
- 연애운 "천천히 스며드는 타입" ← OK (reference 톤)
- 직장운 "성실한 일꾼 타입" ← **약함** (평이, 너무 뻔함)
