## 💡 사용자가 제안한 `oneLineDefinition` 예시의 훌륭함

사용자가 더 재미있게 표현하면 좋겠다고 한 예시들:

1. **"급발진과는 거리가 먼, 브레이크 성능 좋은 신중파 인상"** — 자동차 비유로 현대적
2. **"한마디로 '인간 안전벨트' 같은 안정감 있는 상"** — 의인화 + 사물 비유
3. **"괜히 옆에 있으면 마음이 차분해질 것 같은 묘한 든든함의 소유자"** — 감각·체험 묘사
4. **"돌다리도 두드리고, 두드린 뒤 한 번 더 체크할 것 같은 신중한 분위기"** — 속담 + 반복 유머
5. **"분위기만으로 '일단 진정하고 생각해보자'를 말해주는 상"** — 대사 인용·인격화

### 왜 이게 현재 결과보다 나은가

**현재 출력 (평이)**:
> "안정감 있는 인상과 신중함이 돋보이는 상"

→ 문제: 관상 책에 나올 법한 교과서적 표현. 누구에게나 해당될 법한 "안전한 칭찬". SNS에 캡처해서 공유하고 싶은 임팩트 없음.

**사용자 제안 (재밌음)**:
> "급발진과는 거리가 먼, 브레이크 성능 좋은 신중파 인상"

→ 장점:
- **A보다 B 대조** (급발진 vs 브레이크) 내장
- **현대적 비유** (자동차) — 2020년대 한국어 사용자 감각
- **구체적 이미지** — "신중함"을 추상어가 아닌 브레이크로 치환
- **위트** — "브레이크 성능 좋은" 같은 유머 섞임
- **공유 욕구** — 친구에게 "너 관상 이렇대" 캡처해서 보내고 싶음

### 이 톤을 프롬프트에 반영해야 할 대상

현재 프롬프트의 `oneLineDefinition` 예시:
```
- reference 스타일: "차분하고 단정한 정석형 인상", "조용한 강자형 관상"
- 명사구 + 형(型) 패턴 권장.
```

→ "정석형 관상", "강자형 관상" 같은 **기존 관상학 라벨**만 예시로 들다 보니 LLM이 안전한 명사구로만 수렴. 사용자가 원하는 **위트·현대 비유·유머**가 프롬프트 어디에도 언급 안 됨.
