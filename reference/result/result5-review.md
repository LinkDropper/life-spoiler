## 🟡 여전히 아쉬운 점

### 1. ⏳ 시간·축적 은유 우회 (금지 규칙 일부 뚫림)

프롬프트 금지 어휘가 그대로 출력됨:

| 위치 | 문장 | 금지어 |
|---|---|---|
| 재물 `oneLineVerdict` | "**차곡차곡** 쌓아가는, 든든한 재물운." | 🔴 "차곡차곡" + "쌓아가는" |
| 직장 `nicknameSubtext` | "기본에 충실하며 맡은 바를 **꾸준히** 해내 동료들의 든든한 지지를 받아요." | 🟡 "꾸준히" (시간 경과) |
| `finalNote` | "**시간이 갈수록** 그 진가를 드러내는 매력이 있습니다. 묵묵히 자신의 길을 걸으며 신뢰를 **쌓아가는** 모습이 인상적이에요." | 🔴 "시간이 갈수록" + "쌓아가는" |

→ **nicknameSubtext 3개 + finalNote = 4문장 중 3곳**에서 시간·축적 은유 등장. 프롬프트의 "최대 2개 상한" 규칙 **위반**.

**원인 추정**: LLM이 금지 어휘 리스트를 완전히 준수하기 어려움. "의미 수준 금지"가 충분히 명시됐는데도 안전한 톤(시간=신뢰)으로 수렴.

**개선 제안 (Phase 10)**:
- 프롬프트에 **대안 은유 사용을 의무화** ("시간·축적 은유 0개 사용 + 대안 은유 풀에서 최소 2개 사용")
- validator에 시간·축적 은유 **프로그램적 검출** → 3개 이상 시 재호출

### 2. 🎭 `oneLineDefinition` 레인 고유 위트 부족

**할당**: 감각·체험 묘사형 (여우상 index 2)

**실제**: "옆에 있으면 진중함이 느껴지고, 오래 보면 깊은 속내를 헤아리게 되는 인상"
- ✅ 체험 프레임 ("옆에 있으면", "오래 보면") 채택됨
- 🟡 "진중함", "속내" 같은 관상학 어휘가 중심
- 🟡 reference 예시 ("괜히 옆에 있으면 마음이 차분해질 것 같은 **묘한 든든함의 소유자**")의 **감각적 디테일** 부재

**비교**:
- reference 수준: 감각 프레임 + 감정 디테일 + 인격화
- result5: 감각 프레임 ○ + 감정 디테일 △ + 인격화 ×

→ 레인 프레임은 채택됐으나 **레인 안에서의 위트·유머**가 부족. 여전히 "~인상"으로 끝나 건조.

### 3. 📉 `commonMisread` 미완결 종결

"'다가가기 어렵다'는 오해, 실제로는 따뜻한 마음이 숨어 있다는 **점**"
- "~점" 명사구로 종결 — **미완결 어미**
- 기존 패턴 "~부분이에요" / "~부분이죠" 같은 완결 어미가 더 자연스러움

### 4. 🔄 `coreKeywords` 일부 재사용

현재: ["진중함", "안정", "깊이", "균형", "**신중함**"]
- 과거 금지 세트: ["신뢰감", "안정감", "**신중함**", "꾸준함", "후반상승"]
- "신중함" 겹침 🟡

### 5. ✨ 전반적 톤 — 여전히 "안정·신중" 지배

highlights 8개:
- 생각의 힘, 추진력, 현실 감각, 신중함, 포용력, 사회적 존재감, 균형 잡힌 매력, **차분한 카리스마**

→ "추진력"과 "차분한 카리스마"(약간의 반전) 정도가 반대 결. 나머지 6개는 안정·신중 축.

### 6. 🔨 `oneLiner` 패턴 상한 살짝 초과

- A보다 B: 4개 (이마, 코, 턱, 균형감) ← 상한 3개 살짝 초과
- 명사구 결말: 2개 (눈, 광대)
- 역설: 1개 (눈썹)
- 일상 어미: 1개 (입)
- 관점·시간: 0개... 아니 코가 관점·시간형이었으니 코가 관점·시간에 해당

재분류:
- A보다 B: 3개 (이마, 턱, 균형감 — 균형감은 할당 위반)
- 관점·시간 + A보다 B 복합: 1개 (코)
- 명사구 결말: 2개 (눈, 광대)
- 역설: 1개 (눈썹)
- 일상 어미: 1개 (입)

→ 가장 문제는 균형감이 할당된 "역설·반전"이 아닌 "A보다 B"로 작성된 점.

## 💡 남은 과제 (Phase 10 제안)

### P1 (권장)

#### 1. 시간·축적 은유 programmatic 검출 + 재시도
프롬프트 금지만으로는 LLM이 완전 회피 못함.
- `gemini.v3.ts`에 validator 추가: `nicknameSubtext 3개 + finalNote`에서 "시간이 갈수록/쌓아가는/차곡차곡/꾸준히/오래 볼수록" 등장 횟수 카운트
- 3회 이상 검출 시 **Stage C 재호출**

#### 2. `oneLineDefinition` 레인별 "나쁜 예 + 좋은 예" 극명 대비
현재 프롬프트는 레인별 설명 + 창작 공식만 제공. LLM이 안전한 관상학 어휘로 수렴.
- 각 레인마다 **나쁜 예 1개 + 좋은 예 1개**를 극명하게 대비:
  - ❌ "옆에 있으면 진중함이 느껴지는 인상" (레인 프레임은 맞지만 건조)
  - ✅ "옆에 있으면 괜히 안심되는 기분, 말 안 해도 전해지는 묘한 든든함"

#### 3. `highlights` 반대 결 2개 이상 강제 검증
현재 1개만 있으면 통과. 2개 이상 강제 + 반대 결 리스트 구체화 (유머/감수성/호기심/순발력/변덕 등).

### P2 (여유 시)

#### 4. `commonMisread` 완결 어미 강제
"~점" 같은 명사구 종결 금지 → "~부분이에요", "~점이에요" 완결형으로.

#### 5. `coreKeywords` 과거 세트 전체 금지
"신중함" / "안정감" / "꾸준함" 중 **최대 2개까지만** 허용. 나머지는 새 단어로.
