## ✅ Phase 10 성공 항목

### 1. `commonMisread` 완결 어미 — **완전 반영**

- result5: "'다가가기 어렵다'는 오해, 실제로는 따뜻한 마음이 숨어 있다는 **점**" (미완결)
- result6: "'다가가기 어렵다'는 오해, 실제로는 따뜻한 마음이 숨어 있다는 **점이에요**." (완결)

→ 프롬프트 지시가 LLM에 정확히 전달됨. 🟢 **해결**

### 2. 시간·축적 은유 validator 정상 작동

`nicknameSubtext 3개 + finalNote` 내 시간·축적 은유 카운트:
- 연애 nicknameSubtext: "**함께하는 시간**을 통해 진가를 발휘하는 온기." → 1회
- 재물 nicknameSubtext: "한 번 더 생각하는 습관에서 오는 든든함." → 0
- 직장 nicknameSubtext: "함께 있을 때 느껴지는 든든한 존재감." → 0
- finalNote: "**함께하는 시간**을 통해 진가를 발휘하며…" → 1회

**합계 2회** → 허용치(2회) 이하 → validator 통과.
→ Phase 10에서 추가한 validator가 **의도대로 작동**. 🟢

### 3. `oneLineDefinition` 레인별 good/bad 대비의 효과

- result5: "옆에 있으면 진중함이 느껴지고, 오래 보면 깊은 속내를 헤아리게 되는 인상" (체험 프레임은 맞지만 "진중함·속내" 관상학 어휘로 채움)
- result6: **"옆에 있으면 '이 사람, 꼼꼼하게 일처리 잘하겠다' 싶어지는 얼굴"** (체험 프레임 + **따옴표 대사 인용** 포함)

→ good example("대화 1분이면 '이 사람 믿어도 되겠다' 싶어지는 얼굴")의 **패턴을 정확히 학습해 변주**. 🟢 **대폭 개선**

단, 대사 내용이 "꼼꼼하게 일처리"로 업무 중심 — 좀 더 일상적 감각(편안함·안정감)으로 확장 여지.

### 4. `coreKeywords` 다양화

- result5: ["진중함", "안정", "깊이", "균형", "신중함"] (신중함 과거 수렴 어휘)
- result6: ["꼼꼼함", **"추진력"**, "균형", "성실", "신중함"]

→ **"추진력"(반대 결·활동성 축) 포함** 🟢
→ "신중함" 1개 수렴 어휘(규칙: 최대 1개 → 준수). "성실"도 "성실함" 변주로 볼 수 있어 경계선 🟡

### 5. 분야 간 카피 오염 — 유지

- 연애 oneLineVerdict: "함께할수록 깊어지는 신뢰의 연애운." ✅
- 재물 oneLineVerdict: "차곡차곡 쌓아가는 실속형 재물운." ✅
- 직장 oneLineVerdict: "묵묵히 인정받는 꾸준함의 직장운." ✅

→ 각 분야 고유 키워드. Phase 9의 격리 유지.

### 6. `characterNickname` 신선도 향상

## 🔴 Phase 10 실패 항목

### 1. `highlights` 반대 결 2개 이상 강제 — **완전 실패**

프롬프트 규정 (Phase 10에서 추가):
> "반대 결 최소 2개 이상 필수 포함: 활동성/유머/감수성/순발력/호기심/표현력 중 최소 2개"

**실제 8개 highlights**:
1. 안정적 사고 — 주류 (안정)
2. **추진력** — 반대 결 ✅ (활동성)
3. 정돈된 매너 — 주류
4. 현실 감각 — 주류
5. 신중한 표현 — 주류 (신중)
6. 온화한 포용 — 주류 (포용)
7. 조화로운 존재감 — 주류 (조화·균형)
8. 전체적 균형 — 주류 (균형)

→ **반대 결 1개만** 포함. 규칙(최소 2개) **위반**.

**원인**:
- validator가 없어 LLM의 자기검증에만 의존
- LLM은 자기 출력을 교차 검증하지 못함
- 프롬프트만으로는 반대 결 2개 강제 불가능

**수정 방향 (Phase 11)**:
- `validateSignatureOverall`에 반대 결 카운트 로직 추가
- 반대 결 축 키워드 사전(활동성: 추진력·실행력·속도감·행동력 / 유머: 위트·여유 등)을 위반 시 에러 throw

### 2. `oneLiner` A보다 B 패턴 여전히 4개

**실제 패턴 분포**:
1. 이마: "급변함보다, 차분한 성찰이 돋보이는 이마." → A보다 B
2. 눈: "진한 몰입감이 느껴지는 눈." → 명사구
3. 눈썹: "정돈된 듯, 굳건한 자기 신념." → 역설 (경계선)
4. 코: "지금보다, 나중에 더 단단해지는 코." → 관점·시간 (A보다 B 구조이기도)
5. 입: "한 번 보면 진심이 읽히는 입매예요." → 일상 어미
6. 턱: "강함보다, 포용을 택하는 턱." → A보다 B
7. 광대: "은은한 존재감이 빛나는 광대." → 명사구
8. 균형감: "화려함보다, 꾸준함이 돋보이는 상." → A보다 B (할당은 **역설**, 🔴 위반)

"A보다 B" 계열이 **4개 (이마, 코, 턱, 균형감)**. 프롬프트 상한 3개 위반.

**원인**: 균형감의 역설 할당을 LLM이 다시 A보다 B로 전환. Phase 9에서도 동일 문제 발생.

**수정 방향 (Phase 11)**:
- Stage B 응답 validator에서 각 부위 oneLiner의 문법 패턴 **프로그램적 검출**
- "A보다 B" 개수가 3개 초과 시 재시도

### 3. 시간·축적 validator 범위 제한

validator는 `nicknameSubtext + finalNote`만 검사 → 다음 필드는 통과:
- 재물 `oneLineVerdict`: "**차곡차곡 쌓아가는** 실속형 재물운." 🔴
- 재물 `oneLineDefinition`: "현실 감각을 바탕으로 **쌓아가는** 안정형 재물." 🔴
- 연애 `oneLineDefinition`: "가까워질수록 진가를 발휘하는 신뢰형 관계." 🟡 ("가까워질수록" 시간 의미)

**수정 방향 (Phase 11)**:
- validator 검사 범위 확장: `oneLineVerdict × 3 + oneLineDefinition × 3 + body × 3` 포함
- 의미 수준 패턴 추가: "가까워질수록", "함께할수록"

### 4. `finalNote`와 연애 `nicknameSubtext`의 은유 중복

- 연애 nicknameSubtext: "**함께하는 시간을 통해 진가를 발휘**하는 온기."
- finalNote: "**함께하는 시간을 통해 진가를 발휘**하며…"

→ **거의 동일 은유** 반복. Phase 8~9에서 금지 규정을 넣었는데 LLM이 자기검증 못함.
