## 🟡 잔존 미세 이슈

### 1. 재물 `oneLineVerdict` 과거 복붙 어휘 재등장

"**벼락부자형보다, 알짜배기 실속형 재물운**을 지닌 당신."
- Phase 9 이후 과거 복붙 금지 리스트에 등록된 문장과 동일
- 프롬프트 금지 리스트에 있었으나 LLM이 교정하지 않음

**영향**: 복붙이지만 연애나 직장 분야로 흘러가진 않음(분야 격리는 정상). 맥락상 재물에 맞는 카피라 큰 문제는 아님.

**수정 방향 (Phase 13 P2)**: validator에 분야별 고정 금지 문구 사전 추가 → 발견 시 재시도.

### 2. `oneLineDefinition` 레인 할당 모호

- 여우상(index 2)에 할당된 레인: **감각·체험 묘사형**
- 실제 출력: "가까이서 보면 '이 사람 꽤 깊이 있네' 하고 느끼게 되는 얼굴"

분석:
- "가까이서 보면" → 체험 프레임 ✅
- "'이 사람 꽤 깊이 있네' 하고" → **대사 인용형** 섞임 🟡
- "느끼게 되는" → 감각·체험형 ✅

→ 두 레인이 섞인 하이브리드. 둘 다 reference 톤에 가깝지만 레인 할당 원칙에 엄격하진 않음.

**영향**: 품질 자체는 **좋음**. 다만 레인 결정성 원칙(같은 동물상은 같은 레인)이 느슨해질 수 있음.

### 3. 연애 `oneLineVerdict` 시간 어휘 남음

"불꽃형 연애보다, **오래 가는** 신뢰형 관계를 맺는 당신."
- "오래 가는" = 시간 은유
- 하지만 전역 상한 6회 이하라 validator 통과
- 의미상 연애운에 자연스러운 표현이라 허용 가능 🟡

### 4. `shareLine` 2문장 구성

"겉은 차분, 속은 깊은 여우상. **믿음직한 당신의 모든 순간을 응원해요**."
- 1문장 명사구 임팩트 원칙에서 둘째 문장이 설명적
- 프롬프트의 권장 예시("겉은 차분, 속은 단단한 ~상.")도 1문장 명사구

**영향**: 가독성·공유성 살짝 떨어짐. 이전 result5의 "겉은 차분, 속은 단단한 여우상."이 더 시그니처적.

### 5. `finalNote` 어미 "~입니다" 격식체 섞임

"…믿음직한 사람**입니다**."
- 브랜드 가이드: "~합니다/~입니다" 격식체 금지 (친근함 상실)
- 나머지 문장은 "~이에요" 체라 이 한 부분만 튐

**수정 방향**: 프롬프트 재확인 + 간단한 정규식 validator 추가 가능 (Phase 13 P3).

## 💡 Phase 13 제안 (선택사항, 9/10 도달)

### P1 (즉시 개선 가능)

#### 1. `finalNote`·`summary` 격식체 ("~입니다") 금지 validator
정규식 `/~?입니다\b|~?합니다\b/` 매치 시 throw.
프롬프트에도 있지만 LLM이 가끔 어기므로 programmatic 강제.

#### 2. 분야별 `oneLineVerdict` 과거 복붙 문구 사전 추가
```typescript
const LEGACY_VERDICT_PHRASES = {
  money: ["벼락부자형보다, 알짜배기 실속형 재물운"],
  love: ["불꽃형 연애보다, 오래 가는 신뢰형"],
  career: ["말보다 결과로 인정받는 직장운"],
};
// 각 분야 oneLineVerdict에서 해당 문구 그대로 포함 시 throw.
```

#### 3. `shareLine` 1문장 원칙 validator
`.split(/[.!?]\s/)`로 문장 수 카운트 → 2문장 이상 시 throw.

### P2 (우선순위 낮음)
