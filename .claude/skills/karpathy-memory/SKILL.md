# Memory Skill

## 목적

대화에서 축적된, 코드/CLAUDE.md/rules 어디에도 없는 맥락을 MEMORY.md에 기록하여 세션 간 전달한다.

## 기록할 것

- 사용자 프로필 (역할, 선호, 소통 스타일)
- 의사결정 배경 (왜 그 기술/설계를 선택했는지)
- 실험 결과 및 학습 (A/B 테스트, 마케팅 성과 등)
- 프로젝트 마일스톤, 일정, 진행 상황
- 외부 리소스 위치 (Linear 보드, Slack 채널, 대시보드 URL 등)

## 기록하지 않을 것

- 코드를 읽으면 알 수 있는 것 (구조, 패턴, 아키텍처)
- CLAUDE.md나 rules 파일에 이미 있는 것 (컨벤션, 스타일, 금지사항)
- git log로 파악 가능한 것 (최근 변경, 누가 뭘 바꿨는지)
- 현재 대화에서만 필요한 일시적 정보

## 규칙

- 기록 전 "이 정보가 코드/rules에 이미 있는가?" 자문한다. 있으면 기록하지 않는다.
- 기존 메모리와 중복되면 새로 만들지 않고 업데이트한다.
- 오래되어 현재와 맞지 않는 메모리는 삭제한다.
