# Memory Skill

## 목적

대화에서 축적된, 코드/CLAUDE.md/rules/CONTEXT.md 어디에도 없는 맥락을 기록하여 세션 간 전달한다.

## 구조

```
MEMORY.md                    # 라우터 — 상황별 참조 파일 안내
.claude/memory/              # 세부 메모리 파일
```

- **MEMORY.md**: 어떤 상황에 어떤 파일을 읽어야 하는지만 기록 (내용 X)
- **.claude/memory/*.md**: 주제별 실제 맥락 (한 파일 = 한 주제)

## 기록할 것

- 의사결정 배경 (왜 그 기술/설계를 선택했는지)
- 수정 원칙 (반복된 실수에서 배운 교훈)
- 실험 결과 및 학습 (A/B 테스트, 마케팅 성과 등)
- 프로젝트 마일스톤, 일정, 진행 상황
- 외부 리소스 위치 (Linear 보드, Slack 채널, 대시보드 URL 등)
- 사용자 프로필 (역할, 선호, 소통 스타일)

## 기록하지 않을 것

- 코드를 읽으면 알 수 있는 것 (구조, 패턴, 아키텍처)
- CLAUDE.md, rules, 또는 CONTEXT.md 파일에 이미 있는 것
- git log로 파악 가능한 것 (최근 변경, 누가 뭘 바꿨는지)
- 현재 대화에서만 필요한 일시적 정보
- 보안 민감 정보 (API Key, 비밀번호, 개인정보 등)

## 규칙

- 기록 전 "이 정보가 코드/rules/CONTEXT.md에 이미 있는가?" 자문한다. 있으면 기록하지 않는다.
- 새 주제는 `.claude/memory/`에 파일을 만들고, MEMORY.md에 라우팅 항목을 추가한다.
- 기존 주제와 겹치면 해당 파일을 업데이트한다. 새 파일을 만들지 않는다.
- 오래되어 현재와 맞지 않는 메모리는 삭제한다.
