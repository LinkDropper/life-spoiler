카피 검수 요청에 "N개 문구가 한 화면에 나란히 표시된다"는 조건이 있으면,
개별 문구 하나하나는 브랜드보이스/의미상 문제가 없어도 **전체를 나열했을 때
문장 종결 패턴이 기계적으로 반복되는지**를 별도로 확인해야 한다.

실제 사례(친구 우주 궁합 한줄평 24개, [[project-friend-universe-compatibility]]):
개별 검토로는 안 걸렸지만 24개를 나란히 놓고 보니 15/24가 "~사이예요."로
시작하고 22/24가 "~ㅂ니다/습니다/입니다"로 끝나는 동일 2문장 템플릿이었다.
개별 리뷰만으로는 이 패턴이 드러나지 않는다 — 반드시 전체를 한 화면에
모아 놓고(또는 종결 어미만 뽑아서) 봐야 보인다.

**Why:** 사용자가 명시적으로 "한 화면에 나란히 표시되므로 특히 신경 써서
봐달라"고 요청했고, 실제로 22/24가 동일 종결형이라는 정량적 근거가 나왔다 —
이 체크를 생략했으면 놓쳤을 문제.

**How to apply:** 매트릭스형/리스트형 카피(등급표, 한줄평, 태그 등) 검수 시
1) 전체 문구를 한 번에 나열해 종결 어미·문장 길이·오프닝 패턴을 비교하고,
2) 반복이 심하면(대략 60% 이상 동일 패턴) 개별 문구 문제와 별도로
"구조 다양화" 섹션을 만들어 대안 템플릿 2-3개 + 대표 rewrite 예시를 제시한다.
전부 다시 쓰기보다 템플릿 로테이션 가이드를 주고 나머지는 같은 원칙 적용을
권고하는 방식이 효율적이었다(24개 전부 rewrite는 요청 범위를 벗어남).
