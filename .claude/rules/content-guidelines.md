# 콘텐츠 가이드라인

## 블로그 작성 규칙

### 구조

1. 제목: 호기심 유발, 30자 이내
2. 도입: 공감 또는 질문으로 시작 (3줄 이내)
3. 본문: 2000~3000자, 소제목으로 구분
4. CTA: 글 하단에 자연스럽게 인생스포 링크 (UTM 포함)

### 발행 순서 (반드시 준수)

1. 본문 완성
2. 이미지 생성 (Gemini)
3. 발행

**절대 빈 초안을 먼저 만들지 않는다.**

### SEO

- 제목에 핵심 키워드 포함 (자미두수, 운세, 사주 등)
- 첫 문단에 키워드 자연스럽게 포함
- 소제목(H2, H3) 활용

## X (Twitter) 작성 규칙

### 형식

- 280자 이내 (한국어 기준 약 140자)
- **존댓말 사용** ("~요", "~습니다")
- 해시태그: 2~4개 (고정 + 로테이션)
- 링크 포함 시 UTM 필수

### 콘텐츠 품질 기준

- **모든 글은 근거/데이터 기반**. 자미두수 이론, 통계, 트렌드 등 출처가 있는 정보만 작성.
- 감으로 쓴 무지성 글 금지. "~라고 합니다"가 아니라 왜 그런지 설명할 수 있어야 한다.
- 요즘 트렌드에 맞는 문체. 올드하거나 진부한 표현 사용하지 않는다.

### 이모지 규칙

- 의미 없는 장식용 이모지 금지
- 사용하더라도 포스트당 최대 1개, 맥락에 맞을 때만

### 시간대

- 주요 발행: T3(12~15시), T5(18~21시), T6(21~24시)
- 밤 시간(T6)은 운세/감성 콘텐츠 집중

### 중복 방지

- 같은 내용을 다른 표현으로 반복하지 않는다
- 최근 7일 이내 유사 주제 트윗이 있으면 다른 주제를 선택
- social-tracker.csv를 반드시 확인한 후 작성

## 이미지 규칙

- 블로그 대표 이미지: Gemini로 생성
- 테마: 우주/별/밤하늘, 보라+남색 계열
- 텍스트 오버레이 지양 (AI 생성 이미지의 텍스트는 부정확)
- 비율: 블로그 16:9, 소셜 1:1

## 법적 주의

- "100% 정확합니다" 등 적중률 보장 금지
- "재미로 보는 운세" 뉘앙스 유지
- 의료/법률/투자 조언으로 오해되는 표현 금지
