# UI 접근성 & 다국어 규칙

`app/**/*.tsx`, `components/**`, `messages/translations.json`을 건드릴 때 참조한다. `designer` 에이전트를 거치지 않고 다른 에이전트(예: `fullstack`)가 직접 UI를 만들 때도 동일하게 적용된다.

## 접근성 (a11y)

- 색상 대비 4.5:1 이상
- 터치 타겟 44x44px 이상
- 의미 있는 aria 레이블 부여
- 키보드 네비게이션으로 모든 인터랙션 가능해야 함
- 로딩/에러/빈 상태에도 스크린리더가 상태를 인지할 수 있어야 함

## 다국어 (KO/EN/JA)

- 텍스트 길이 차이를 고려해 고정 너비가 아닌 유연한 레이아웃 사용 (EN/JA가 KO보다 길어지는 경우가 흔함)
- `messages/translations.json`에 세 언어 모두 동일한 키 구조로 추가 (하나만 추가하고 누락 금지)
- 하드코딩된 한국어 문자열을 컴포넌트에 직접 넣지 않음 — 반드시 translations 경유

## 반응형

- 모바일(375px) 기준으로 먼저 검토, 그 다음 태블릿/데스크톱
- 주 유입 경로가 인스타그램/카카오톡 공유이므로 모바일 퍼스트 원칙 준수
