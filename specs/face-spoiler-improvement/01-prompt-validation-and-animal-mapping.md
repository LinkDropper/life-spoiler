# Phase 1 — 관상 프롬프트 검증 + 동물상 12종 매핑 자문

> 작성자: gwansang-expert (관상학 도메인 전문가)
> 대상 파일: `libs/face-spoiler/prompts/text-report.ts`, `libs/face-spoiler/types.ts`, `libs/face-spoiler/gemini.ts`
> 목적: (1) 현재 AI 관상 분석 파이프라인의 관상학 정합성·윤리 가드·해석 로직 검증, (2) 한국 대표 동물상 12종을 관상학적 부위 조합에 매핑하는 룩업 테이블 정의, (3) Phase 2 기획 단계로 넘길 권고사항 정리.
>
> **중요 원칙**
> - 이 문서에는 전통 관상학 설명을 위해 한자 용어(印堂·山根·臥蠶 등)를 사용하되, **최종 출력 프롬프트에는 여전히 노출 금지** 룰을 유지한다. 한자는 내부 가이드 문서에만.
> - 동물상은 **시각적 인상의 비유**일 뿐, 인종·민족·국적·외모 등급과 어떤 방식으로도 연결되지 않는다.
> - 모든 해석·매핑은 **2개 이상 부위 조합**에 근거한다. 단일 부위 단독 판단은 금지.

## 1. 현재 프롬프트 검증 결과

### 1-1. 잘 설계된 점 (유지 권고)

현재 `text-report.ts`는 flash-lite 친화적으로 매우 조밀하게 설계되어 있고, 관상학 원리와 윤리 가드레일의 균형도 준수한 편이다. 다음 요소들은 Phase 2/3에서 재설계하더라도 **그대로 계승**해야 한다.

1. **5개 모듈 분리 구조 (FORBIDDEN / INTERPRETATION / OBSERVATION / GUIDE / STYLE)**
   - flash-lite처럼 instruction-following이 약한 모델에는 "주제별 블록 분리 + 반복 강조"가 매우 효과적. 그대로 유지.
2. **이유 → 결과 → 행동 3원칙**
   - 관상학 해석이 점괘가 아닌 "관찰 기반 행동 제안"으로 착지하게 만드는 핵심 장치. 룩업 테이블을 바꾸더라도 이 3원칙은 보존.
3. **부위 조합 앵커링 (최소 2개 부위)**
   - 단일 부위 해석은 전통 관상학에서도 금기(相不獨論). 이 원칙이 프롬프트에 명시된 것은 도메인적으로 정확하다.
4. **충돌 패턴을 "결함 아닌 개성"으로 처리**
   - 각진 턱 + 처진 눈썹 같은 모순 조합을 양면성으로 풀어주는 지침은 현대적 해석 방향으로도 올바르다.
5. **자기검증 루프 ("다른 사람에게도 그대로 쓸 수 있으면 실패")**
   - 일반론 방지의 가장 강력한 가드. headline·tags·summary 전체에 반복 적용되는 점 우수.
6. **12개 관찰 체크리스트 (OBSERVATION_PROTOCOL)**
   - 해석 전에 관찰 단계를 강제하는 흐름은 관상학의 `觀 → 析 → 解 → 勸` 순서와 일치.
7. **삼정(三停) 균형 해석**
   - 상정/중정/하정을 인생 시기(초년/중년/말년)와 매칭하는 것은 전통 관상학의 핵심 골격이며, 이를 `observation` 섹션의 4단락째에 고정 배치한 구조는 잘 설계되어 있다.
8. **윤리 가드레일의 7가지 항목 구성**
   - 미추/인종/나이/체형/건강/정신/범죄를 열거식으로 차단하고, "단정 금지 → ~로 보여요" 같은 톤 규칙을 병행하는 것은 실무적으로 효과적.

### 1-2. 보완 필요 항목 (Phase 2/3에서 반드시 손볼 것)

#### (A) 룩업 테이블이 "이분법적 축"만 다룬다 — 전통 관상학의 3~5단계 질감이 빠짐

현재 `FACE_PHYSIOGNOMY_GUIDE`는 거의 모든 부위를 **"A형 vs B형"의 2개 축**으로만 서술한다. 예컨대 눈썹은 `일자 vs 아치 vs 올라감 vs 처짐`의 4분류지만, 실제 관상학에서는 이를 다음과 같은 **다축 조합**으로 본다.

| 축 | 현재 반영? | 설명 |
|---|---|---|
| 농도 (진한 편/옅은 편) | O | |
| 방향 (올라감/수평/처짐) | O | |
| 길이 (길다/짧다) | O | |
| **결의 정돈성 (가지런함/거칠음)** | **X** | 전통 관상학에서는 "눈썹 결이 가지런한가"가 정서 안정·인내심의 핵심 지표 |
| **눈과의 거리 (눈썹이 눈에 가까운가/떨어진가)** | **X** | 성격의 급함·느긋함을 가르는 중요 지표. 지금 프롬프트엔 없음 |

이 보완은 눈썹뿐 아니라 **모든 부위에 동일하게 필요**하다. 특히 코(산근의 높낮이), 입(입꼬리의 대칭), 턱(하악각의 각도), 광대(옆으로 퍼짐 vs 앞으로 나옴)가 단순화되어 있다.

**권고**: Phase 2 룩업 테이블 재설계 시 부위별로 **3~5개의 독립 축**을 정의하고, 각 축마다 3단계(강/중/약) 값을 지정한다. 모델은 그중 2~3개 축을 임의 선택해 조합을 만든다.

| 관상학 용어 | 일상 표현 | 현재 반영 | 의미 |

| 山根(산근) | "콧대가 시작되는 부분", "콧대 뿌리" | **X** | 초중년의 기운 흐름, 의지·건강의 관문 (단, 건강 추론은 금지 — "기운 흐름"으로만) |

#### (C) `FACE_PHYSIOGNOMY_GUIDE`가 "조합 해석 원칙"을 형식적으로만 다룬다

현재 마지막 섹션 "조합 해석 원칙"은 5줄로 짧다. 그러나 모델이 실제로 룩업 테이블에서 단일 부위 해석만 뽑아 쓰는 가장 큰 원인이 여기에 있다. **구체적 조합 예시**가 너무 적기 때문이다.

```
현재: "두 부위가 같은 방향", "두 부위가 충돌 방향" 추상 설명만 존재
필요: 부위 쌍별 구체 조합 예시 10~15개 (예: "넓은 이마 + 또렷한 눈빛 = 통찰",
     "각진 턱 + 처진 눈썹 = 외강내유", "도톰한 입술 + 짧은 인중 = 순발력형 감성")
```

**권고**: Phase 2에서 `COMBINATION_PATTERNS` 블록을 별도 신설. 10~15개의 명시적 부위쌍 패턴을 제공하되, 각각 "방향 일치형 / 충돌형 / 3부위 상승형"의 세 유형으로 분류한다. 이는 flash-lite의 few-shot 역할을 한다.

#### (D) 관상학 12궁 개념이 완전히 누락

전통 관상학의 **12궁(十二宮)** — 명궁/재백궁/형제궁/전택궁/남녀궁/노복궁/처첩궁/질액궁/천이궁/관록궁/복덕궁/부모궁 — 은 얼굴 부위를 인생의 12개 영역에 매핑하는 핵심 프레임워크다. 현재 프롬프트는 이 매핑이 전혀 없다.

| 관상 12궁 | 얼굴 부위 | 현재 섹션 매핑 |
|---|---|---|
| 명궁(命宮) | 미간(印堂) | — |
| 재백궁(財帛宮) | 코끝(準頭) | wealth |
| 형제궁(兄弟宮) | 눈썹 | — |
| 전택궁(田宅宮) | 눈꺼풀·눈썹과 눈 사이 | — |
| 남녀궁(男女宮) | 눈 밑(臥蠶) | — (자녀 해석 금지로 비활성 권장) |
| 노복궁(奴僕宮) | 턱 양쪽 | — |
| 처첩궁(妻妾宮) | 눈꼬리(奸門) | relationship |
| 질액궁(疾厄宮) | 콧대 뿌리(山根) | — (건강 추론 금지로 비활성 필수) |
| 천이궁(遷移宮) | 관자놀이 | — |
| 관록궁(官祿宮) | 이마 중앙 | career |
| 복덕궁(福德宮) | 이마 위쪽·천창 | — |
| 부모궁(父母宮) | 이마 좌우 | — |

> ⚠️ **자미두수 12궁과 절대 혼동 금지**. 관상학 12궁은 얼굴 부위 매핑이며, 자미두수 12궁은 생년월일시 기반 명반 배치다. 코드상으로는 `libs/face-spoiler/`와 `libs/zi-wei-dou-shu/`가 완전히 분리되어 있는데, Phase 2에서 문서/타입 이름을 정할 때 "12궁" 용어를 face-spoiler 쪽에 쓰면 혼동 위험이 크다. **face-spoiler 쪽은 "관상 부위 맵(PhysiognomyRegions)" 같은 중립 이름을 권장**한다.

**권고**: 12궁을 전부 노출할 필요는 없다. 현재 섹션(personality/career/wealth/relationship)과의 매핑을 명시적으로 작성하고, 건강·자녀 관련 궁은 **의도적으로 비활성화**한다는 것을 프롬프트에 못박는다.

```
career  → 관록궁 (이마 중앙) + 명궁 (미간)
wealth  → 재백궁 (코끝) + 천창 (이마 모서리, 축적) + 콧방울
relationship → 처첩궁 (눈꼬리) + 형제궁 (눈썹 결) + 와잠 (애정 표현의 부드러움으로만)
personality  → 명궁 (미간) + 얼굴형 기조 + 삼정 균형
observation  → 12부위 체크리스트 기반
비활성화 → 질액궁(건강), 남녀궁(자녀/출산), 부모궁(가족 추정)
```

#### (E) 해석 로직의 미세한 결함

1. **"감정 대비" 규칙이 Lukewarm hedge(애매한 완곡화)로 흐를 위험**
   - 지금 규칙: "긍정 뒤에는 조건, 부정 뒤에는 대처법". 그 자체는 옳다.
   - 문제: flash-lite는 이 규칙을 "모든 문장에 but을 붙이는" 식으로 과잉 적용하기 쉽다. 결과적으로 모든 문장이 "~한 편이지만, 과하면 ~"의 단조로운 리듬으로 수렴.
   - **권고**: "6단락 summary 중 **최소 1개 단락은 조건 없는 순수 긍정 묘사 허용**"이라는 예외를 둬서 리듬을 다양화. "매 문장 hedge 금지" 지침 추가.

2. **score(0~100)의 의미가 정의되어 있지 않음**
   - 프롬프트에는 "본문과 일치" 정도만 적혀 있다.
   - 문제: 0~100 분포 기준이 없으면 모델은 **거의 모두 70~85에 몰린다**. 실측 시 확인 필요.
   - **권고**: score 분포 가이드 추가. 예시 — "50대: 균형은 있으나 특정 기운이 불분명, 70대: 핵심 기운이 뚜렷함, 85+: 해당 영역의 부위 조합이 3개 이상 같은 방향으로 몰림". 본문 길이·강도와의 일치 규칙을 숫자적으로 정의.

3. **`observation` 섹션이 `personality` 등과 중복 서술로 수렴할 위험**
   - 현재 구조: observation 4단락(상/중/하/균형) + 다른 4개 섹션 각 3단락. 총 관찰 서술이 반복됨.
   - 특히 personality 1단락 "관찰된 부위 조합에서 나오는 기질의 특성"은 observation과 거의 같은 내용이 될 수 있다.
   - **권고**: Phase 2에서 **observation은 "사실 묘사만"**, 다른 섹션은 **"해석만 (관찰 재서술 금지)"** 으로 역할 분리. 중복 제거로 실질 글자 수를 감각·행동·장면 묘사에 재배치.

4. **headline 문법 다양성 규칙이 형식주의로 흐를 위험**
   - 규칙: 각 섹션 headline이 서로 다른 문법 구조. 원칙은 좋다.
   - 문제: 6개 섹션 × 다른 구조 = 모델이 억지 구조를 만들어 "?로 끝나는 질문형" 헤드라인이 어색해지는 사례 발생 가능.
   - **권고**: "최소 3종 이상 문법 구조 사용" 정도로 완화. 6종 전부 다를 필요는 없음.

#### (F) 윤리 가드레일의 미세한 공백

현재 `FORBIDDEN_RULES`는 강하지만, 다음 4개 케이스가 빠져 있거나 약하다.

1. **표정 상태를 성격으로 단정 금지**
   - 사진 한 장의 표정(웃는 상태/굳은 상태)은 일시적이다. 관상학적으로는 **골격·비율**이 우선, 표정은 참고만.
   - 현재 프롬프트는 이걸 명시하지 않아서 "웃고 있는 사진"은 무조건 긍정, "굳은 표정"은 부정으로 해석될 수 있다.
   - **추가 룰**: "표정은 일시적 상태. 성격 판정의 주 근거로 삼지 말 것. 골격·비율·윤곽 우선."

2. **화장·보정·필터 효과를 타고난 특징으로 단정 금지**
   - 눈썹 문신, 입술 오버라인, 뷰티 필터 등은 관찰에서 걸러야 한다.
   - **추가 룰**: "화장·보정·필터로 강조된 부분이 있을 가능성을 전제. 인공적 흔적이 강하게 보이는 부위는 해석 근거에서 제외."

3. **성별·젠더 추정 금지**
   - 현재 룰에는 인종·나이만 있고 성별이 빠져 있다.
   - **추가 룰**: "성별·젠더 추정 및 성별 기반 해석 금지. 중성적 톤 유지."

4. **동물상(Phase 2/3 도입 예정) 관련 사전 가드**
   - 동물상 도입 전에 **윤리 전제**를 프롬프트에 반드시 포함해야 한다.
   - **추가 룰**: "동물상은 **시각적 인상의 비유**일 뿐이며, 인종·민족·국적과 어떤 방식으로도 연관되지 않는다. 동물상 설명 시 '야생적', '이국적', '서양적/동양적' 같은 인종 연상 표현 금지. 동물 자체의 습성·이미지로만 묘사."

### 1-3. 위험 신호 (즉시 차단 필요 — 향후 운영 중 발견되면 바로 반영)

다음 케이스는 현재 프롬프트로도 **이미 실제로 새어 나올 수 있는 출력**이다. Phase 3에서 샘플 검증 시 반드시 회귀 테스트 포인트로 사용.

- `wealth` 섹션에서 "코가 낮아서 돈이 새어나간다" 같은 **인과적 단정**
- `relationship` 섹션에서 와잠을 자녀운으로 해석 → "자녀운이 좋다" 류 출력
- `observation` 섹션에서 "피부가 맑아 보여요" → 외모 평가
- `personality` 섹션에서 "얼굴이 둥글어 친근한 인상" → 미추 평가 경계선
- `career` 섹션에서 "리더형입니다" → 유형 라벨링 (이미 금지돼 있으나 반복 검증)

### 1-4. 스키마 수준의 보완 포인트 (`types.ts`)

현재 `FaceReportData`는 life-spoiler와 구조적으로 매우 유사하다. Phase 2에서 동물상을 도입하려면 다음이 필요하다.

1. **`animalMatch` 필드 신설**: 기본(대표) 동물상 + 보조(서브) 동물상 + 매칭 근거 부위 리스트.
2. **`observation.features` 구조화**: 현재는 `content: string` 한 덩어리. 동물상 매칭·UI 시각화·향후 재해석을 위해 관찰된 12개 부위를 **구조화된 배열**로 따로 저장할 필요가 있다 (`{ region, axis, value, confidence }`).
3. **`FaceReportSection.tags` 타입**: 현재 `[string, string]` 튜플. 향후 3~4개로 늘릴 가능성을 고려해 `string[]` + `minItems/maxItems` 제약으로 완화 검토.

이 부분은 Phase 2의 PRD·스키마 재설계 단계에서 planner/fullstack이 확정할 사안이며, 본 문서는 **제안만** 한다.

## 2. 동물상 12종 룩업 테이블

한국 대중 문화에서 통용되는 대표 12종 — **강아지, 고양이, 여우, 사슴, 토끼, 곰, 호랑이, 늑대, 말, 햄스터, 부엉이, 원숭이** — 을 관상학적 부위 조합으로 매핑한다.

### 공통 전제

- 동물상은 **시각적 인상의 은유**다. 사람의 외모 서열/등급/인종과 무관하다.
- 매칭은 **최소 2개 부위 조합**으로만 이뤄진다. 단일 부위(예: "큰 눈이면 강아지")는 금지.
- 각 사람에게 **대표 1종 + 보조 1종**을 매칭하는 구조를 권장. 100% 단일 매칭은 오차가 크다.
- **혼동이 발생하면 "얼굴 전체 기조(얼굴형)"가 tie-breaker**. 세부 부위는 그 다음.
- 동물상 묘사 시 **"야생적", "이국적", "섹시한", "귀엽다/예쁘다" 등 평가·인종 연상 어휘 금지**. 동물 자체의 습성·분위기로만.

### 관상학 ↔ 동물상 매핑 원칙

전통 관상학에는 **"수상(獸相)"** 또는 **"물형상법(物形相法)"** 이라는 분류법이 있다. 사람의 얼굴을 동물의 기상(氣象)에 비유해 기질을 파악하는 방식으로, 이는 미추 평가가 아닌 **"어떤 기운의 동물에 가까운가"** 를 보는 은유적 도구다. 현대 서비스의 12종 동물상은 이 전통의 대중화된 버전으로 볼 수 있으며, 따라서 **관상학 해석과 자연스럽게 결합 가능**하다.

### 동물상 12종 상세

각 항목은 다음 5개 필드를 가진다.

1. **얼굴형 특징** (부위 조합, 최소 3개 부위)
2. **인상 키워드** (3~5개)
3. **관상학적 해석 방향** (기질·운세 경향, 연결되는 관상 개념)
4. **AI 분류 시각 가이드** (Gemini가 이미지에서 관찰해야 할 구체적 특징)
5. **충돌 가능성** (혼동 쌍 + 구분 기준)

---

#### 1) 강아지상 (친근·충성·수용)

1. **얼굴형 특징**
   - 전체 윤곽: **둥근 편(원형)** 또는 둥근 계란형
   - 눈: **크고 둥글며 위아래가 비슷한 비율**, 쌍꺼풀이 있거나 부드럽고 눈빛이 말갛음
   - 눈꼬리: **수평~살짝 내려간 편** (처진 듯한 부드러움)
   - 입꼬리: **자연스럽게 올라간 편**
   - 코끝: **둥글고 콧방울이 부드럽게 퍼진 편**
   - 광대: **평평하거나 부드럽게 흐름**
2. **인상 키워드**: 친근·온기·수용·편안함·진심
3. **관상학적 해석 방향**
   - 얼굴형(원형) + 처진 눈꼬리 + 둥근 코끝의 조합은 관상학의 **복덕궁·재백궁 풍요 조합**. 인간관계에서 신뢰를 쌓는 힘이 강하고, 대인운(人緣)이 두터운 기운.
   - 단점: 거절 어려움, 경계 약함 → 행동 조언은 "거절의 기술"·"내 시간 지키기"로 연결.
4. **AI 분류 시각 가이드**
   - "둥근 얼굴 윤곽 + 크고 둥근 눈 + 올라간 입꼬리 + 둥근 코끝" 4요소 중 **3개 이상**이 동시에 관찰되면 강아지상. 눈빛은 "맑고 직진"이되 공격성이 없는 것이 핵심.
5. **충돌 가능성**
   - **vs 곰상**: 얼굴이 둥근 점은 같으나, 곰상은 **이목구비가 더 크고 둔중**하며 윤곽 경계가 굵다. 강아지상은 경계가 **부드럽고 가볍다**.
   - **vs 햄스터상**: 강아지상은 **얼굴이 비교적 크고 눈이 상대적으로 정비율**, 햄스터상은 **볼이 도드라지고 얼굴 하단이 통통**.

---

#### 2) 고양이상 (시크·독립·섬세)

1. **얼굴형 특징**
   - 전체 윤곽: **하관이 좁아지는 역삼각/다이아몬드 편** 또는 갸름한 계란형
   - 눈: **가로로 긴 편, 눈꼬리가 올라가 있음**, 쌍꺼풀 유무와 무관하나 **눈빛이 또렷하고 살짝 차분**
   - 눈과 눈 사이: **보통~약간 좁은 편**
   - 코: **콧대가 곧고 코끝이 살짝 뾰족한 편**, 콧방울은 좁은 편
   - 입: **작거나 중간**, 입꼬리는 **단정하거나 미세하게 올라감**
   - 광대: **세밀하게 드러나되 과하지 않음**
2. **인상 키워드**: 시크·독립·섬세·예리·자기중심
3. **관상학적 해석 방향**
   - 역삼각 얼굴형은 **지성·분석력·창의성**. 올라간 눈꼬리는 **자존심·경쟁심**의 지표.
   - 조합 해석: 지적이되 사교에 에너지를 낭비하지 않고, **자기 영역을 정확히 지키는 기운**. 관상학의 **명궁(미간) 정돈형**.
   - 단점: 거리감, 친밀감 표현 부족 → 행동 조언은 "먼저 한 걸음 표현하기".
4. **AI 분류 시각 가이드**
   - "하관이 좁은 윤곽 + 올라간 눈꼬리 + 곧은 콧대" 3요소 **동시 관찰**이 핵심. 입 크기는 보조 지표.
5. **충돌 가능성**
   - **vs 여우상**: 가장 헷갈리는 쌍. 둘 다 올라간 눈꼬리, 하관이 좁다. **구분 기준**: 여우상은 **눈꼬리가 더 길게 찢어지며 입꼬리도 살짝 올라간 장난기**가 있다. 고양이상은 **입이 작고 단정**하며 눈빛이 차갑다.
   - **vs 사슴상**: 눈이 큰 점은 비슷하나 사슴상은 **눈이 둥글고 순하며 눈과 눈 사이가 넓다**. 고양이상은 **길고 좁다**.

---

#### 3) 여우상 (매혹·영민·장난기)

1. **얼굴형 특징**
   - 전체 윤곽: **갸름한 역삼각** 또는 길쭉한 다이아몬드
   - 눈: **가늘고 길며 눈꼬리가 뚜렷이 올라감**, 눈매가 **약간 찢어진 느낌**
   - 눈썹: **옅거나 가는 편, 살짝 아치**
   - 코: **콧대가 가늘고 콧끝이 뾰족한 편**
   - 입: **얇거나 중간, 입꼬리가 한쪽 또는 양쪽으로 살짝 올라감** (장난기)
   - 광대: **옆으로 날카롭게 드러난 편**
2. **인상 키워드**: 매혹·영민·장난기·재치·화술
3. **관상학적 해석 방향**
   - 가는 눈매 + 올라간 눈꼬리 + 가는 콧대의 조합은 **영민함·상황 판단·설득력**. 관상학의 **관록궁·천이궁** 활발 기운. 이동·교류·화술로 기회를 만드는 타입.
   - 단점: 진정성 오해, 말이 앞섬 → 행동 조언은 "말보다 1초 기다리기"·"신뢰 쌓기 장기전".
4. **AI 분류 시각 가이드**
   - "가로로 긴 가는 눈매 + 뚜렷이 올라간 눈꼬리 + 가는 콧대 + 옆으로 드러난 광대" 조합. **눈매의 '길이'**가 고양이상과의 결정적 차이.
5. **충돌 가능성**
   - **vs 고양이상**: 위 고양이 항목 참조. **여우=길고 찢어진 눈매, 고양이=정제된 아몬드형**.
   - **vs 늑대상**: 둘 다 영민하고 날카로운 인상이나, **늑대상은 전체적으로 남성적 각도**(턱·눈썹)가 강조되고 **여우상은 가는 선·갸름함**이 지배적.

---

#### 4) 사슴상 (순수·청량·이상)

1. **얼굴형 특징**
   - 전체 윤곽: **세로로 긴 편(장형)** 또는 긴 계란형
   - 눈: **크고 둥글며 눈동자가 촉촉**, 눈과 눈 사이가 **넓은 편**
   - 눈썹: **옅고 길며 아치형**
   - 코: **긴 편, 콧대가 곧고 가늘며 코끝이 살짝 뾰족**
   - 입: **작거나 중간, 얇거나 정제된 입술**
   - 턱: **뾰족한 편, 짧지 않음**
   - 목선: (관찰 가능 시) 가늘고 길다는 느낌
2. **인상 키워드**: 순수·청량·이상·여림·우아
3. **관상학적 해석 방향**
   - 세로 장형 + 넓은 미간 + 큰 눈의 조합은 **이상·사색·감수성의 기운**. 관상학의 **상정 발달형** — 초년의 지성·감수성이 두드러지고, 시야가 넓으며 이상이 높다.
   - 단점: 현실 마찰에 여림, 상처 쉽게 받음 → 행동 조언은 "작은 루틴으로 땅에 발 붙이기".
4. **AI 분류 시각 가이드**
   - "긴 얼굴 + 크고 둥근 눈 + 넓은 미간 + 가는 콧대" 4요소 중 **3개 이상** 관찰. 눈과 눈 사이의 **넓음**이 강아지상과의 핵심 차이.
5. **충돌 가능성**
   - **vs 강아지상**: 강아지=둥근 얼굴, 사슴=긴 얼굴. 눈은 둘 다 크나 **얼굴형 기조**로 구분.
   - **vs 토끼상**: 둘 다 큰 눈·여림. **토끼=전체적으로 동글동글+인중 짧음**, **사슴=세로로 길고 우아함**. 토끼는 하관이 작고 이목구비가 모여 있음, 사슴은 이목구비 간격이 여유롭다.

---

#### 5) 토끼상 (귀염·순발·보호욕)

1. **얼굴형 특징**
   - 전체 윤곽: **둥글고 짧은 편**, 혹은 둥근 계란형
   - 이마: 중간 넓이, **둥근 편**
   - 눈: **크고 동그랗게 열려 있음**, 눈망울이 커 보임
   - 코: **짧은 편, 코끝이 둥글고 콧방울이 좁다**
   - 인중: **짧은 편** (이목구비가 가운데로 모여 보이는 효과)
   - 입: **작고 도톰한 편**, 입꼬리 단정
   - 턱: **둥글고 짧은 편**
2. **인상 키워드**: 귀염·순발·보호욕·호기심·천진
3. **관상학적 해석 방향**
   - 짧은 코 + 짧은 인중 + 큰 눈 조합은 **순발력·즉흥·감정 반응이 빠른 기운**. 관상학의 **중정 압축형** — 행동이 즉각적이고 감정 표현이 솔직.
   - 단점: 참을성 부족, 쉽게 흔들림 → 행동 조언은 "결정은 하루 묵혀보기".
4. **AI 분류 시각 가이드**
   - "둥근 얼굴 + 큰 눈 + 짧은 인중 + 작은 입" 조합. **인중의 짧음**이 사슴상과 구분하는 핵심.
5. **충돌 가능성**
   - **vs 사슴상**: 위 사슴 항목 참조.
   - **vs 햄스터상**: 둘 다 둥글고 귀여운 인상. **햄스터=볼이 도드라지고 얼굴 하단 통통**, **토끼=얼굴 전체가 균등하게 둥글고 눈이 더 크다**.

---

#### 6) 곰상 (듬직·포용·느긋)

1. **얼굴형 특징**
   - 전체 윤곽: **크고 둥글며 이목구비가 굵다**. 둥근 방형 또는 큰 원형
   - 이마: 넓고 평평~둥근 편
   - 눈: **중간~크기가 있으되 눈두덩이가 두껍고 눈빛이 순하다**
   - 눈썹: **진하고 굵은 편**
   - 코: **크고 코끝이 둥글며 콧방울이 넓은 편**
   - 입: **크고 도톰한 편**
   - 턱: **넓고 둥글며 두께가 있음**
2. **인상 키워드**: 듬직·포용·느긋·신뢰·안정
3. **관상학적 해석 방향**
   - 넓은 이마 + 큰 코 + 넓은 턱의 조합은 관상학의 **삼정 균형 + 모든 궁이 크고 두터움**. 재물·복덕·말년운이 풍요로운 전통적 길상(吉相)에 가까운 구조.
   - 단점: 행동이 느리고 변화를 꺼림 → 행동 조언은 "작은 실험을 주 1회".
4. **AI 분류 시각 가이드**
   - "얼굴 전체가 크고 이목구비가 굵음 + 진한 눈썹 + 넓은 코 + 두꺼운 턱" 조합. **윤곽의 두께감**이 강아지상과의 결정적 차이.
5. **충돌 가능성**
   - **vs 강아지상**: 위 강아지 항목 참조.
   - **vs 호랑이상**: 둘 다 크고 굵은 이목구비. **호랑이=눈빛이 날카롭고 광대가 또렷**, **곰=눈빛이 순하고 광대가 부드럽다**.

---

#### 7) 호랑이상 (카리스마·추진·권위)

1. **얼굴형 특징**
   - 전체 윤곽: **넓고 각진 편(방형)** 또는 큰 직사각형
   - 이마: **넓고 각진 편**
   - 눈썹: **진하고 굵으며 살짝 올라감**
   - 눈: **크고 눈빛이 강하며 또렷함**, 흰자 대비 눈동자가 선명
   - 코: **높고 크며 콧대가 굵은 편**
   - 광대: **또렷하고 앞쪽으로 솟은 편**
   - 턱: **각지고 넓은 편**
2. **인상 키워드**: 카리스마·추진·권위·결단·위엄
3. **관상학적 해석 방향**
   - 관상학의 **호랑이상(虎相)** 은 전통적으로 "장수(將帥)의 상"으로 분류되는 강한 길상. 넓은 이마(관록궁) + 높은 코(재백궁) + 또렷한 광대(권위)의 삼각 조합은 **리더십·사회적 영향력** 기운.
   - 단점: 압박감, 타인에 대한 기대치가 높음 → 행동 조언은 "말의 크기를 한 단계 낮추기".
4. **AI 분류 시각 가이드**
   - "각진 넓은 얼굴 + 진하고 굵은 눈썹 + 또렷한 눈빛 + 솟은 광대" 조합. **눈빛의 강도**가 곰상과의 결정적 차이.
5. **충돌 가능성**
   - **vs 곰상**: 위 곰 항목 참조.
   - **vs 늑대상**: 둘 다 날카로운 인상. **호랑이=얼굴이 넓고 광대가 옆으로 크다**, **늑대=얼굴이 더 좁고 길며 턱이 뾰족~V형**.

---

#### 8) 늑대상 (예리·독립·집중)

1. **얼굴형 특징**
   - 전체 윤곽: **길고 좁은 편** (긴 방형 또는 긴 역삼각)
   - 이마: 중간 넓이, **각진 편**
   - 눈썹: **진하고 직선적, 살짝 올라감**
   - 눈: **가늘고 길며 눈매가 날카롭고 눈빛이 예리**
   - 코: **길고 곧은 콧대, 코끝이 뾰족한 편**
   - 턱: **좁거나 V형**, 하관이 날카로움
   - 광대: **세로로 길게 드러남**
2. **인상 키워드**: 예리·독립·집중·야성·냉정
3. **관상학적 해석 방향**
   - 긴 얼굴 + 곧은 콧대 + V턱 조합은 **집중·완벽주의·한 길 파는 기운**. 관상학의 **중정·하정 긴장형**으로, 목표에 한번 꽂히면 깊이 파고드는 타입.
   - 단점: 냉정함이 거리감으로 오해, 휴식 부족 → 행동 조언은 "의도적 여백 만들기".
4. **AI 분류 시각 가이드**
   - "긴 좁은 얼굴 + 날카로운 눈매 + 곧은 긴 콧대 + V형 턱" 조합. **얼굴의 좁고 긴 기조**가 여우상/호랑이상과의 차이.
5. **충돌 가능성**
   - **vs 여우상**: 위 여우 항목 참조.
   - **vs 호랑이상**: 위 호랑이 항목 참조.

---

#### 9) 말상 (열정·에너지·직진)

1. **얼굴형 특징**
   - 전체 윤곽: **세로로 매우 긴 편(장형)**
   - 이마: **넓고 긴 편**
   - 눈: **중간 크기, 눈빛이 또렷하고 에너지가 강함**
   - 코: **길고 곧은 편**
   - 입: 중간~큰 편, 입술은 정돈된 편
   - 인중: **긴 편**
   - 턱: 중간~긴 편
2. **인상 키워드**: 열정·에너지·직진·성실·활기
3. **관상학적 해석 방향**
   - 긴 얼굴 + 긴 코 + 긴 인중 조합은 **지속력·인내·성실의 기운**. 관상학의 **상·중·하 삼정이 전부 길게 발달**한 구조로, 한 목표를 오래 밀고 가는 힘이 강하다.
   - 단점: 유연성 부족, 방향 전환이 느림 → 행동 조언은 "주 1회 '멈춰서 돌아보기' 시간".
4. **AI 분류 시각 가이드**
   - "세로로 매우 긴 얼굴 + 긴 코 + 긴 인중" 3요소 **동시 관찰**. 다른 동물상보다 **세로 비율**이 압도적으로 크다.
5. **충돌 가능성**
   - **vs 사슴상**: 둘 다 긴 얼굴. **사슴=눈이 크고 둥글며 전체 인상이 여림**, **말=눈 크기가 중간이고 전체 인상이 단단하고 에너지가 강함**.
   - **vs 늑대상**: 말=긴 얼굴이지만 하관이 뾰족하지 않음, 늑대=V형 하관이 핵심.

---

#### 10) 햄스터상 (앙증·천진·온화)

1. **얼굴형 특징**
   - 전체 윤곽: **둥글고 아래가 통통**한 편
   - 볼: **도드라지게 통통**, 이목구비가 얼굴 중앙으로 **모여 있음**
   - 눈: **작거나 중간**, **동그랗고 반짝**
   - 코: **작고 짧으며 코끝 둥글다**
   - 입: **작고 도톰**, 입꼬리 단정
   - 턱: **짧고 둥글**
2. **인상 키워드**: 앙증·천진·온화·부드러움·편안
3. **관상학적 해석 방향**
   - 통통한 볼 + 작은 이목구비 + 짧은 턱 조합은 관상학의 **중정 압축·하정 완만형**. 정서 안정·평화로운 분위기 기운. 사람을 편하게 만드는 복덕 기운.
   - 단점: 결단 느림, 주도권 잡기 주저 → 행동 조언은 "작은 결정부터 먼저 내리기".
4. **AI 분류 시각 가이드**
   - "통통한 볼 + 작은 이목구비 + 짧은 코 + 짧은 턱" 조합. **볼의 통통함**이 결정적 지표.
5. **충돌 가능성**
   - **vs 토끼상**: 위 토끼 항목 참조.
   - **vs 강아지상**: 강아지=얼굴이 균등하게 둥글고 이목구비가 비교적 크다, 햄스터=볼이 특히 도드라지고 이목구비가 상대적으로 작다.

---

#### 11) 부엉이상 (관조·지성·신비)

1. **얼굴형 특징**
   - 전체 윤곽: **둥글거나 살짝 넓은 원형~계란형**
   - 이마: **넓고 높은 편**
   - 눈: **크고 둥글며 눈과 눈 사이가 넓음**, 눈빛이 **깊고 차분**
   - 눈썹: **굵고 곧거나 약간 아치, 눈썹 사이가 여유로움**
   - 코: **짧거나 중간, 콧대는 곧음**
   - 입: 작거나 중간, 정제된 편
   - 턱: **둥글고 약간 짧은 편**
2. **인상 키워드**: 관조·지성·신비·고요·통찰
3. **관상학적 해석 방향**
   - 넓은 이마 + 큰 둥근 눈 + 넓은 미간의 조합은 **통찰·관조·넓은 시야**의 기운. 관상학의 **상정 발달 + 명궁 안정형** — 작은 소란에 흔들리지 않고 전체를 보는 기질.
   - 단점: 행동보다 관찰에 머물기 쉬움 → 행동 조언은 "관찰한 것을 24시간 안에 한 가지 실행".
4. **AI 분류 시각 가이드**
   - "크고 둥근 눈 + 넓은 미간 + 넓은 이마 + 차분한 눈빛" 조합. **미간의 여유로운 넓이**가 사슴상과의 차이(사슴=길고 갸름한 얼굴, 부엉이=짧고 둥근 얼굴).
5. **충돌 가능성**
   - **vs 사슴상**: 위와 같음. **부엉이=둥글고 짧은 얼굴**, **사슴=세로로 긴 얼굴**.
   - **vs 고양이상**: 부엉이=큰 둥근 눈·넓은 미간, 고양이=아몬드형 올라간 눈·좁은 미간.

---

#### 12) 원숭이상 (재치·영리·사교)

1. **얼굴형 특징**
   - 전체 윤곽: **중간 크기의 다이아몬드·역삼각** 또는 작은 계란형
   - 이마: 중간~넓은 편, **살짝 튀어나온 느낌**도 있음
   - 눈: **중간 크기, 움직임이 많고 반짝**, 눈빛이 빠르고 생동감
   - 코: **짧거나 중간, 콧방울이 또렷**
   - 입: **크거나 중간, 입꼬리가 표현이 풍부**
   - 광대: **도드라진 편**
   - 전체 인상: **표정 변화가 풍부**
2. **인상 키워드**: 재치·영리·사교·표현·적응
3. **관상학적 해석 방향**
   - 다이아몬드 얼굴형 + 또렷한 광대 + 풍부한 표정은 **사교·적응력·순발력의 기운**. 관상학의 **천이궁 활발형** — 환경 변화에 강하고 대인관계에서 기회를 만든다.
   - 단점: 주의 분산, 한 우물 파기 어려움 → 행동 조언은 "하루 한 가지에만 집중".
4. **AI 분류 시각 가이드**
   - "다이아몬드/역삼각 얼굴 + 또렷한 광대 + 풍부한 표정 + 움직임 있는 눈빛" 조합. **표정의 생동감**(정적 사진이라도 미세 표정에서 드러남)이 핵심 지표. 관상학의 "골격 우선" 원칙과 충돌할 수 있으므로 **골격적 지표(광대·얼굴형)를 우선 근거**로 쓰고 표정은 보조로만.
5. **충돌 가능성**
   - **vs 여우상**: 둘 다 역삼각/다이아몬드. **여우=차분한 영민함, 가는 눈매**, **원숭이=활발한 움직임, 풍부한 표정, 눈매가 둥근 편**.
   - **vs 고양이상**: 고양이=차분·올라간 눈꼬리·정제된 입, 원숭이=활발·풍부한 표정·큰 입.

### 혼동 쌍 매트릭스 (AI 분류 시 tie-breaker 기준)

| 혼동 쌍 | 공통점 | 결정적 구분 기준 |
|---|---|---|
| 고양이 ↔ 여우 | 하관이 좁음, 올라간 눈꼬리 | **눈매 길이**: 고양이=아몬드형, 여우=가늘고 찢어짐. 보조: 입 크기(고양이=작음, 여우=중간~입꼬리 장난기) |
| 강아지 ↔ 곰 | 둥근 얼굴, 둥근 코끝 | **이목구비 굵기**: 강아지=부드럽고 가벼움, 곰=굵고 두꺼움. 보조: 턱 두께 |
| 강아지 ↔ 햄스터 | 둥근 얼굴, 귀여운 인상 | **볼의 도드라짐**: 햄스터=볼 통통·이목구비 중앙 집중, 강아지=얼굴 균등 |
| 사슴 ↔ 토끼 | 큰 눈, 여린 인상 | **얼굴 세로 길이 + 인중**: 사슴=긴 얼굴·긴 인중, 토끼=둥근 얼굴·짧은 인중 |
| 사슴 ↔ 말 | 세로로 긴 얼굴 | **눈 크기와 에너지**: 사슴=크고 둥글고 여림, 말=중간·강한 에너지 |
| 사슴 ↔ 부엉이 | 큰 눈, 넓은 미간 | **얼굴 세로 길이**: 사슴=세로 장형, 부엉이=짧고 둥근 원형 |
| 곰 ↔ 호랑이 | 크고 굵은 이목구비 | **눈빛 + 광대**: 곰=순한 눈빛·부드러운 광대, 호랑이=강한 눈빛·솟은 광대 |
| 호랑이 ↔ 늑대 | 날카롭고 강한 인상 | **얼굴 기조**: 호랑이=넓고 각짐, 늑대=좁고 길며 V턱 |
| 여우 ↔ 늑대 | 영민·날카로움 | **얼굴 선**: 여우=가는 선 중심, 늑대=각진 선·진한 눈썹 |
| 여우 ↔ 원숭이 | 역삼각 얼굴 | **표정 움직임**: 여우=차분·가는 눈매, 원숭이=활발·둥근 눈 |
| 토끼 ↔ 햄스터 | 둥글고 작은 이목구비 | **눈 크기**: 토끼=눈이 상대적으로 큼, 햄스터=눈이 작음·볼 통통 |
| 고양이 ↔ 부엉이 | 차분한 인상 | **눈 모양 + 미간**: 고양이=아몬드·좁은 미간, 부엉이=둥근 눈·넓은 미간 |

### 매칭 확신도 가이드 (AI에 지시할 규칙)

flash-lite가 단일 동물상을 강제로 선택하면 오차가 크다. 다음 구조를 권장한다.

```
primaryAnimal   : 가장 많은 부위가 매칭되는 1종 (3개 이상 부위 일치 필수)
secondaryAnimal : 그 다음으로 많은 부위가 매칭되는 1종 (2개 이상 부위 일치)
confidence      : primary에만 부여. 기준:
                  - "3부위 일치, 혼동 쌍 없음"           → high
                  - "3부위 일치하나 혼동 쌍과 경합"       → medium
                  - "2부위만 일치"                      → low (이 경우 secondary를 primary와 비중 비슷하게 제시)
matchedRegions  : primary 매칭 근거가 된 부위 2~4개 배열 (예: ["얼굴형", "눈꼬리", "콧대"])
```

## 3. Phase 2 권고사항 (기획/스키마 재설계 단계로 넘김)

### 3-1. 프롬프트 모듈 재구성

Phase 2에서 `text-report.ts`를 다시 설계한다면 다음 6개 모듈로 재조직할 것을 권장한다.

1. **FORBIDDEN_RULES** (기존 유지 + §1-2-F의 4개 항목 추가)
   - 표정 단정 금지
   - 화장·보정·필터 예외 처리
   - 성별·젠더 추정 금지
   - 동물상 ↔ 인종 연관 금지
2. **INTERPRETATION_PRINCIPLES** (기존 유지 + §1-2-E 1,4번 완화 규칙)
   - "6단락 중 1개는 조건 없는 긍정 허용"
   - "headline 문법 구조는 최소 3종 이상" (6종 강제 제거)
3. **OBSERVATION_PROTOCOL** (확장)
   - 현재 12개 항목 → **18~20개로 확장**: 인당, 산근, 와잠(애정 표현), 법령(결단 선명도), 천창, 턱 양쪽 라인, 눈썹 결의 정돈성, 눈썹-눈 거리, 미간 거리 추가
   - 한자 용어는 가이드 내부 주석에만, 프롬프트 본문은 일상 표현
4. **FACE_PHYSIOGNOMY_GUIDE** (구조 변경)
   - 부위별 **3~5개 독립 축 × 3단계 값** 구조로 재편
   - 관상학 12궁과 섹션(personality/career/wealth/relationship)의 매핑을 명시적 주석으로 병기
   - **비활성 궁 명시**: "질액궁·남녀궁·부모궁은 건강·자녀·가족 추정 위험으로 해석에서 제외"
5. **COMBINATION_PATTERNS** (신설)
   - 10~15개 부위쌍 조합 예시를 **방향 일치형 / 충돌형 / 3부위 상승형** 3가지로 분류
   - flash-lite의 few-shot anchor 역할
6. **ANIMAL_MATCHING_RULES** (신설 — 동물상 도입 시)
   - §2의 12종 매핑 테이블
   - primary/secondary + confidence 규칙
   - 혼동 쌍 tie-breaker
   - 윤리 전제 ("동물상은 시각적 은유, 인종·등급과 무관")
7. **STYLE_GUIDE** (기존 유지)

### 3-2. 스키마 확장 방향 (`types.ts`)

planner/fullstack이 Phase 2에서 확정할 제안. 본 문서는 방향만 제시한다.

```ts
export interface FaceReportData {
  // 기존 필드 유지 (profile, observation, personality, career, wealth, relationship, actions, shareLine)

  // 신설: 구조화된 관찰 데이터
  observation: {
    headline: string;
    content: string;
    // 신설: 12~18개 부위 관찰 결과를 구조화해서 저장
    // UI에서 "관찰된 특징" 배지, 재해석, 캐릭터 이미지 프롬프트 등에 재사용
    features?: Array<{
      region: PhysiognomyRegion; // "forehead" | "eyebrow" | "eye" | ...
      axis: string;              // "width" | "shape" | "density" | ...
      value: string;              // "넓은 편" | "각진 편" | ...
      confidence: "high" | "medium" | "low";
    }>;
  };

  // 신설: 동물상 매칭
  animalMatch?: {
    primary: AnimalType;         // "dog" | "cat" | "fox" | ...
    secondary: AnimalType;
    confidence: "high" | "medium" | "low";
    matchedRegions: string[];    // 매칭 근거가 된 부위 2~4개
    rationale: string;           // 120~180자: 왜 이 동물상인지 부위 조합 설명
  };
}

type PhysiognomyRegion =
  | "faceShape" | "forehead" | "brow" | "browSpacing"
  | "eye" | "eyeSpacing" | "eyeCorner" | "underEye"
  | "noseBridge" | "noseRoot" | "noseTip" | "nostril"
  | "mouth" | "lipThickness" | "mouthCorner"
  | "philtrum" | "cheekbone" | "chin" | "jaw" | "ear";

type AnimalType =
  | "dog" | "cat" | "fox" | "deer" | "rabbit" | "bear"
  | "tiger" | "wolf" | "horse" | "hamster" | "owl" | "monkey";
```

⚠️ **관상 12궁 용어 사용 금지**: 자미두수 12궁과의 혼동을 막기 위해 face-spoiler 쪽 타입/변수명은 **"PhysiognomyRegions" 또는 "FaceRegions"** 로 통일. "twelvePalace" 같은 이름은 사용하지 말 것.

### 3-3. 결과 페이지 UX 권고

Phase 2의 결과 페이지 PRD 작성 시 다음을 반영 권장.

1. **동물상 대표 영역 신설**: primary 동물상을 상단에 시각적으로 강조. secondary는 보조로 "~의 기운도 섞여 있어요" 형태.
2. **관찰된 부위 배지**: `observation.features` 를 기반으로 "넓은 이마", "올라간 입꼬리" 같은 배지 리스트 렌더링. 사용자가 "AI가 뭘 보고 이렇게 해석했는지"를 시각적으로 확인할 수 있어 신뢰도 상승.
3. **혼동 쌍 힌트**: confidence가 medium 이하일 때, 결과 페이지 하단에 "~상과의 경계에 있어요. ~에서는 ~의 기운도 함께 드러나요" 문구 노출.
4. **비교형 공유 카드**: `shareLine` + primary 동물상 아이콘을 결합한 SNS 공유 이미지 별도 생성. 바이럴 장치.
5. **윤리 고지 고정**: 결과 페이지 하단에 "엔터테인먼트 목적. 의료·법적·재무적 판단의 근거가 아님. 동물상은 시각적 은유이며 인종·외모 등급과 무관."을 **작게라도 항상 표시**.

### 3-4. Phase 3 구현 시 회귀 검증 포인트

ai-dev/fullstack이 Phase 3에서 구현을 마친 후 반드시 샘플 사진 5~10장으로 다음 항목을 검증해야 한다.

1. `FORBIDDEN_RULES`의 7개 카테고리 위반 여부 (미추/인종/나이/체형/건강/정신/범죄)
2. 출력에 한자 용어가 새어나왔는지 (`면상`, `오관`, `삼정`, `와잠` 등 grep)
3. "이 분은", "당신은" 같은 지칭어가 재등장했는지
4. score가 70~85 구간에 몰리는지 (분포 가이드 효과 측정)
5. 동물상 매칭이 **혼동 쌍에서 얼마나 안정적**인지 (특히 고양이↔여우, 곰↔호랑이, 사슴↔토끼 쌍)
6. `observation.features`와 본문 해석이 일치하는지 (구조화 데이터와 자연어가 따로 노는 경우 방지)
7. 단일 부위 근거 해석이 섞여 있는지 ("눈이 커서 ~" 같은 단독 서술 찾기)
8. 동물상 설명에서 인종·국적 연상 어휘가 있는지 (`이국적`, `서양적`, `동양적`, `야생적` 등 grep)
9. 캐릭터 이미지 프롬프트(`character-image.ts`)와 텍스트 리포트의 부위 묘사가 일치하는지 (분리된 두 모델이 다른 얼굴을 그리는 문제 방지)
10. primary 동물상 분포가 특정 1~2개에 쏠리지 않는지 (예: 70% 강아지상이면 프롬프트 편향)

## 최종 요약

1. **현재 프롬프트는 구조적으로 견고**하지만, 룩업 테이블이 2분법에 머물러 있고 핵심 부위(印堂·山根·臥蠶·法令·地閣)가 누락되어 있다.
2. **윤리 가드레일은 강하나 4개 공백**(표정 단정, 화장/보정, 성별 추정, 동물상 인종 연관)이 존재한다.
3. **관상학 12궁 프레임은 자미두수와 이름 충돌** 위험이 있어 face-spoiler 쪽은 `PhysiognomyRegions` 같은 중립 이름을 써야 한다.
4. **동물상 12종 매핑**은 관상학 전통의 "수상·물형상법"과 자연스럽게 결합 가능하며, 본 문서의 §2 테이블을 Phase 2 스키마와 Phase 3 프롬프트에 그대로 이식할 수 있다.
5. **필수 원칙**: 모든 매칭은 최소 2개 부위 조합, primary + secondary + confidence 구조, 혼동 쌍 tie-breaker 명시.
6. **Phase 2 산출물**: 스키마 재설계 + 결과 페이지 PRD. Phase 3 산출물: 새 프롬프트 + 동물상 추출 + UI 마이그레이션 + 회귀 검증.
