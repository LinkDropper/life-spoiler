## 1. 현재 카피 분석 및 진단

### 1.1 현재 강점
- **히어로 타이틀** "내 전성기, 20대일까 30대일까?" - 구체적 질문형으로 호기심 유발
- **가격 앵커링** 9,900원 → 990원 (90% OFF) - 할인폭 명확
- **FBI WARNING 섹션** - 유머러스한 면책 조항으로 브랜드 톤 확립

### 1.2 개선이 필요한 부분
- **히어로 서브카피**: 기능 나열 중심으로 감정적 후킹이 약함
- **프로모션 카피**: "노력은 하는데 왜 안 풀릴까?" - 부정적 프레이밍이 행동 전환과 연결이 약함
- **CTA 버튼**: "990원에 내 인생 스포 받기" - '스포'의 가치가 불명확
- **ProductPreview**: 리스트만 나열, 각 항목의 가치 전달 부족
- **궁합 콘텐츠 부재**: 신규 상품임에도 랜딩에서 노출 없음
- **크로스셀링 없음**: 인생운세 → 궁합, 궁합 → 인생운세 연결 카피 없음

## 2. 기존 섹션 카피 개선안

### 2.1 히어로 섹션 (MainHero)

#### 현재
```
title: "내 전성기, 20대일까 30대일까?"
subtitle: "114개 별로 읽는 당신의 타이밍"
subtitleLine2: "12궁에 펼쳐진 별이 말하는 운의 타이밍"
subtitleLine3: "나에게 맞는 돈·직업·인연 패턴"
subtitleHighlight: "1,000년 역사 동양 점성술의 정밀 분석"
```

#### 개선안 A (호기심 극대화)
```
title: "내 전성기, 아직 안 왔을 수도 있다"
subtitle: "10년 단위 운의 타이밍 분석"
subtitleLine2: "돈이 모이는 시기 vs 새는 시기"
subtitleLine3: "나한테 맞는 직업·인연·건강 패턴"
subtitleHighlight: "자미두수 114개 별의 정밀 분석"
```

**변경 근거:**
- 타이틀을 "아직 안 왔을 수도 있다"로 변경 → 희망 + 긴박감 동시 자극
- 서브카피에 '돈이 모이는 시기 vs 새는 시기' → 구체적 이익을 암시
- 하이라이트에서 '1,000년 역사' 수식어 대신 핵심 가치(114개 별)를 전면 배치

#### 개선안 B (공감 + 행동 유도)
```
title: "노력만으론 부족한 이유, 타이밍이었다"
subtitle: "재물이 터지는 나이 vs 조심할 나이"
subtitleLine2: "올해 가장 신경 써야 할 달"
subtitleLine3: "나의 직업·인연·건강 맞춤 패턴"
subtitleHighlight: "자미두수 114개 별 기반 AI 분석"
```

**변경 근거:**
- 타겟 페인포인트("노력만으론 부족") 직접 터치
- '재물이 터지는 나이' → 가장 궁금한 정보를 미끼로 제시

### 2.2 프로모션 배너 (PromotionBanner)

#### 현재
```
badge: "런칭 기념 90% OFF"
text: "노력은 하는데 왜 안 풀릴까? 타이밍을 확인해보세요"
```

#### 개선안
```
badge: "오픈 기념 90% 할인"
text: "커피 한 잔 값으로, 내 인생의 골든타임을 확인하세요"
```

**변경 근거:**
- "노력은 하는데 왜 안 풀릴까?"는 부정적 프레이밍 → 긍정적 기대("골든타임")로 전환
- "커피 한 잔 값" → 990원의 가격 저항을 직관적으로 낮춤
- "런칭 기념" → "오픈 기념"으로 더 자연스러운 표현

### 2.3 CTA 버튼 (CTAButton)

#### 현재
```
button: "990원에 내 인생 스포 받기"
subtext: "3분 입력, 바로 결과 확인"
```

#### 개선안 A (가치 중심)
```
button: "990원에 내 운명 시나리오 받기"
subtext: "생년월일 입력 3분, 결과 즉시 확인"
```

#### 개선안 B (행동 유도 강화)
```
button: "내 골든타임 확인하기 (990원)"
subtext: "3분이면 충분해요"
```

**변경 근거:**
- "인생 스포" → "운명 시나리오" 또는 "골든타임" → 더 명확한 가치 전달
- 가격을 괄호 안에 넣어 행동("확인하기")이 먼저 눈에 들어오게 함
- subtext를 더 부드러운 톤으로 변경

#### Feature 1 - 개선안

- 타이틀을 질문형으로 변경 → 사용자의 자기 투영 유도

- description에 "전성기가 언제인지 미리 확인" → 구체적 기대 효과 명시

## 3. 궁합 섹션 신규 카피

### 3.1 궁합 섹션 메인 카피

#### 위치: FeatureSection 다음 또는 ProductPreview 전

```json
{
  "compatibility": {
    "badge": "NEW",
    "title": "그 사람과 나, 진짜 맞는 걸까?",
    "subtitle": "자미두수가 분석하는 두 사람의 운명 궁합",
    "description": "연인, 친구, 동료... 관계마다 다른 궁합 시나리오",
    "features": {
      "score": "0~100점 궁합 점수",
      "subScores": "소통 · 성장 · 신뢰 · 위기극복 4대 지표",
      "scenarios": "실제 상황별 핵심 시나리오",
      "advice": "두 사람만을 위한 맞춤 조언"
    },
    "cta": "궁합 무료 체험하기",
    "freeBadge": "오픈 기념 무료"
  }
}
```

**카피 전략:**
- 타이틀: "그 사람과 나, 진짜 맞는 걸까?" → 누구나 한 번쯤 하는 질문
- 서브타이틀: "운명 궁합" → 단순 성격 매칭이 아닌 자미두수 기반임을 강조
- 피처 리스트: 실제 AI 결과에 있는 것만 나열 (score, subScores, coreScenarios, advice)
- CTA: "무료 체험" → 가격 저항 제거

### 3.2 궁합 프리뷰 카드 (ProductPreview에 추가)

```json
{
  "compatibilityTitle": "궁합 분석도 받아보세요",
  "compatibilityBadge": "무료",
  "compatibilityItems": {
    "score": "궁합 점수 (0~100점)",
    "insights": "8가지 궁합 인사이트 분석",
    "scenarios": "핵심 시나리오 (실제 상황 예측)",
    "categories": "소통·성장·감정·위기 4대 카테고리"
  }
}
```

### 3.3 궁합 섹션 서브 카피 (인사이트 상세 설명)

실제 AI 결과 데이터에 있는 8가지 인사이트를 활용:

```
"두 사람의 띠 궁합부터 오행 상성,
성격 케미, 소통 방식, 성장 시너지,
신뢰 지수, 위기 극복력까지.
8가지 관점에서 입체적으로 분석합니다."
```

### 3.4 궁합 카테고리 설명 카피

실제 결과의 4대 카테고리를 반영:

| 카테고리 | 레이블 | 한 줄 설명 |
|----------|--------|------------|
| communication | 소통 & 갈등 | 대화가 통하는 사이인지, 갈등은 어떻게 풀어야 하는지 |
| growth | 재물 & 성장 | 함께 성장할 수 있는 관계인지, 재물운은 어떤지 |
| emotion | 감정 & 신뢰 | 서로를 얼마나 믿을 수 있는지, 감정적 안정감은 |
| crisis | 위기 & 극복 | 위기가 왔을 때 함께 넘길 수 있는 관계인지 |

## 7. 전환율 최적화 전략 요약

### 7.1 심리적 트리거 활용
| 트리거 | 현재 | 개선안 |
|--------|------|--------|
| 호기심 | O (질문형 타이틀) | O+ (더 구체적 질문) |
| 긴박감 | O (타이머) | O (유지) |
| 사회적 증거 | X | 추후 추가 검토 (리뷰, 이용자 수) |
| 가격 앵커링 | O (9,900→990) | O+ ("커피 한 잔 값" 추가) |
| 손실 회피 | X | O ("아직 안 왔을 수도 있다") |
| FOMO | X | O (궁합 "무료 체험 기간 한정") |

### 7.2 카피 톤 가이드라인
- **친근하지만 진지한 톤**: 반말은 쓰지 않되, 딱딱하지 않게
- **구어체 선호**: "분석합니다" → "분석해드려요" (문맥에 따라)
- **구체적 숫자 활용**: "114개 별", "12궁", "4가지 영역", "0~100점"
- **질문형 헤드라인**: 사용자가 스스로 답을 찾고 싶게 만드는 구조
- **가치 > 기능**: "10년 단위 운 분석" → "내 전성기가 몇 살인지"

### 7.3 궁합 섹션 배치 우선순위
1. **FeatureSection 바로 아래** (추천) - 기존 3개 피처 카드 → 궁합 소개 → 자연스러운 흐름
2. **PromotionBanner 바로 위** - 궁합(무료) → 인생운세(990원) 순서로 가격 저항 낮춤
3. **ProductPreview 내부에 통합** - 기존 리스트에 궁합 항목 추가

### 7.4 A/B 테스트 제안
다음 카피 변형을 A/B 테스트할 것을 권장합니다:

1. **히어로 타이틀**: 현재 vs 개선안 A vs 개선안 B
2. **CTA 버튼**: "990원에 내 인생 스포 받기" vs "내 골든타임 확인하기 (990원)"
3. **프로모션 카피**: 현재(부정적 프레이밍) vs 개선안(긍정적 프레이밍)
